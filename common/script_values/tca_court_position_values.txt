# 本文件维护天朝与官署系统通用的宫廷差遣数值，供文武各类差遣官职（包括文官差遣、军事差遣、科举与专门使职等）共享复用。
# 仿照原版 00_court_position_values.txt 架构，提供统一阶梯的影响力成本与豁免体系。

# -------------------------------------------------------------------
# 一、宫廷差遣撤职影响力成本（Influence Revoke Cost）
# 作用域：雇主领主（Root / Liege / Employer）
# 阶梯划分：
# - 初级差遣（minor）：30 影响力（如兵马监押、基层文职佐理等）
# - 中级差遣（medium）：60 影响力（如诸州都监、州级文官差遣等）
# - 高级差遣（major）：100 影响力（如行营都监/都虞候、各路使职长官等）
# -------------------------------------------------------------------

tca_minor_court_position_influence_revoke_cost = {
	value = minor_influence_value
	if = {
		limit = {
			exists = this
			has_character_flag = temporary_court_position_cost_removal
		}
		multiply = 0
	}
}
