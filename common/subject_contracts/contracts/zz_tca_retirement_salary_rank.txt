# 原版薪俸等级覆盖：退休公国使用按官品与身份确定的独立契约，排除退休身份以免重复取得普通等级基础额。
# 县级另压低头衔兵士规模并抵消军制省的军事预算费率，只计契约基准，不抵后续法律／科技／文化加成。
# 其余数值、原版等级条件与自动选档规则保持不变；基线保存完整原版对象。
celestial_salary_rank = {
	display_mode = hidden

	defaults_to_highest_valid_level = yes

	can_be_changed = {
		always = no
	}

	obligation_levels = {
		celestial_salary_rank_none = {
			position = { 0 0 }
			default = yes

			ai_liege_desire = 0
			ai_subject_desire = 0
		}

		celestial_salary_rank_county = {
			position = { 1 0 }

			parent = celestial_salary_rank_none
			is_valid = {
				scope:subject = {
					NOR = { has_trait = tca_fengci has_trait = tca_retired }
					highest_held_title_tier = tier_county
					primary_title = {
						is_noble_family_title = no
					}
				}
			}

			ai_liege_desire = 2
			ai_subject_desire = 2

			subject_modifier = {
				monthly_treasury_from_salary_budget_base = 0.3

				# 抵消军制省契约的 +1.0，使伯爵级知军不从中央军事预算领取经费。
				monthly_treasury_from_military_budget_base = -1.0
				# 军团数沿用原版 -1（2-1=1）；规模按 3 级基准压到 1 级。
				men_at_arms_title_cap = -1
				men_at_arms_title_limit = -2
			}
		}

		celestial_salary_rank_duchy = {
			position = { 2 0 }

			parent = celestial_salary_rank_county
			is_valid = {
				scope:subject = {
					NOR = { has_trait = tca_fengci has_trait = tca_retired }
					highest_held_title_tier = tier_duchy
				}
			}

			ai_liege_desire = 3
			ai_subject_desire = 3

			subject_modifier = {
				monthly_treasury_from_salary_budget_base = 0.75

				monthly_treasury_from_military_budget_base = -0.3 # (only relevant if Military Gov)
				men_at_arms_title_cap = -1
			}
		}
		celestial_salary_rank_kingdom = {
			position = { 3 0 }

			parent = celestial_salary_rank_duchy
			is_valid = {
				scope:subject = {
					NOR = { has_trait = tca_fengci has_trait = tca_retired }
					highest_held_title_tier = tier_kingdom
				}
			}

			ai_liege_desire = 4
			ai_subject_desire = 4

			subject_modifier = {
				monthly_treasury_from_salary_budget_base = 1.0
			}
		}
		celestial_salary_rank_empire = {
			position = { 4 0 }

			parent = celestial_salary_rank_kingdom

			ai_liege_desire = 5
			ai_subject_desire = 5

			is_valid = {
				scope:subject = {
					NOR = { has_trait = tca_fengci has_trait = tca_retired }
					highest_held_title_tier = tier_empire
					is_landless_ruler = no
				}
			}
			subject_modifier = {
				monthly_treasury_from_salary_budget_base = 2.0
			}
		}
		celestial_salary_rank_minister = {
			position = { 0 2 }

			parent = celestial_salary_rank_kingdom

			ai_liege_desire = 6
			ai_subject_desire = 6

			is_valid = {
				scope:subject = {
					NOR = { has_trait = tca_fengci has_trait = tca_retired }
					highest_held_title_tier = tier_empire
					is_landless_ruler = yes
				}
			}
			subject_modifier = {
				monthly_treasury_from_salary_budget_base = 3
			}
		}
	}
}
