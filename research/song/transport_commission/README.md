# 转运司副贰：转运副使与转运判官的先后

## 问题与范围

判断：北宋中前期（以仁宗末至神宗初为参照），一路转运司的副贰官称中，转运副使位在转运判官之上；二者高下主要依资序浅深而定，并非两个职掌不同的固定台阶。目标时点：1066-09-15（治平三年八月二十四日）。对象：北宋诸路转运司，不含发运司及南宋制度。

本条只为[公爵级文官称号是否按资序分等](../../../docs/court/duchy_naming.md)提供最小史实依据，不考证具体任职者，也不主张宋代官品与游戏功绩等级一一对应。

## 当前判断

- **CLM-SONG-TRANSPORT-01（A）**：《宋史·职官志》把转运司长官序列写作"都转运使、转运使、副使、判官"，并在南渡后的叙述中明言"若副使，若判官，皆随资之浅深称焉"。这是该志自身的排列与说法，可以直接引用；但它是否等同治平三年的现行序位，须由下条补足。
- **CLM-SONG-TRANSPORT-02（B）**：综合 1066 前后的实际仕历，治平—熙宁间转运副使位在转运判官之上，判官是进入监司的较低一阶。由运判迁提刑、由运判迁运副、由运副迁运使均有实例，与上条方向一致；但仕历先后不等于序位令，仍不能排除个别越次。
- **CLM-SONG-TRANSPORT-03（A）**：转运判官始置于开宝六年；太平兴国初同时置副使与诸路判官，副使一度罢废，判官亦曾因与转运使争权而罢、嘉祐中复置。治平三年夏秋张林宗自夔州运判移梓州提刑，治平中谢景温亦任江东运判（E-04），说明开局时点判官确在行用。

## 证据记录

### E-SONG-TRANSPORT-01

- 出处：[SRC-0199](../../sources.md#src-0199)：脱脱等《宋史》卷167，志第一百二十《职官七》"转运司"条。
- 性质与核验状态：元代官修正史职官志，已核完整录文，未校影印；核读 2026-10-25。
- 原文逐字摘录："都轉運使、轉運使、副使、判官，掌經度一路財賦，而察其登耗有無，以足上供及郡縣之費。"；"隨軍及都運廢置不常，而正使不廢。若副使，若判官，皆隨資之淺深稱焉，其屬有主管文字、幹辦官各一員……"
- 可证：该志把副使列在判官之前，并把二者的差别归为"资之浅深"。
- 不可证：该段"随资浅深"语在南渡后叙述内，不能直接当作治平三年的成文令；也不能证明判官必然由某品寄禄官充任。

### E-SONG-TRANSPORT-02

- 出处：[SRC-0200](../../sources.md#src-0200)：元·马端临《文献通考》卷六十一《职官考十五》"转运使"门。
- 性质与核验状态：宋元之际政书，汇述唐宋沿革，已核该门完整录文，未校影印；核读 2026-10-25。
- 原文逐字摘录："開寶六年，廣南平，除徐澤為判官，蓋轉運判官始此。"；"太平興國初皆曰使，兩省以上則為都轉運使，又置副使與諸路判官焉……俄罷諸路副使。"；"先是，判官與轉運爭權而罷。至嘉祐中復置。"；"熙寧二年，詔轉運使用本資序人即充，資序下一等為權，二等為權發遣。"；"中興以來……惟使、副、判官常置。……舊制，轉運司除授皆命詞給誥，渡江已後，例給敕命……轉運使、副命詞，運判則否。"；"光宗紹熙以來，使副、運判不雙除。"
- 可证：判官始置年代、副使与判官的置罢、熙宁二年以资序差遣的办法、运判在命词礼遇上低于使副，以及绍熙以来使副与运判不双除。
- 不可证：政书汇述跨唐宋，逐句不能当作北宋现行条令；"副使俄罢"与后文复置之间缺少完整年表。

### E-SONG-TRANSPORT-03

- 出处：[E-SONG1066-KUIZHOU-14](../1066_tidian_xingyu/circuits/kuizhou.md)（SRC-0113《宋史》卷331《张诜传》）。
- 性质与核验状态：正史列传，已核该传相关录文；转引本主题既有考证。
- 原文逐字摘录：张诜"知襄邑縣擢夔路轉運判官錄辟土之功加直集賢院改陝西轉運副使"。
- 可证：同一人由夔路运判改陕西运副，运判在运副之前。
- 不可证：单条仕历不能证明所有路分的迁转次序，也不能定该次迁转的具体年月。

### E-SONG-TRANSPORT-04

- 出处：本主题既有分路考证，[E-SONG1066-DONGCHUAN-01](../1066_tidian_xingyu/circuits/dongchuan.md)、[E-SONG1066-HUAINAN-09](../1066_tidian_xingyu/circuits/huainan.md)。
- 性质与核验状态：宋人文集自注与正史列传，已核相关条目；转引本主题既有考证。
- 原文逐字摘录：文同《丹渊集》卷20挽诗自注"司勋自夔州运判移梓州路提刑"；《宋史·谢景温传》"江东转运判官……提点江西刑狱"。
- 可证：运判常为提刑之前一阶。
- 不可证：提刑与转运司并非同一官署，此链只说明迁转次序，不能读成同一司内的上下级。

### E-SONG-TRANSPORT-05

- 出处：[SRC-0153](../../sources.md#src-0153)、[SRC-0154](../../sources.md#src-0154)：范纯仁《范忠宣集》卷十六张景宪行状；王安石《临川集》卷五十《淮南转运副使张景宪金部郎中制》。
- 性质与核验状态：北宋一手传记与外制制词，已核相关条目；转引本主题既有考证。
- 原文逐字摘录：行状"出为淮南转运副使，两浙京西河北都转运使"。
- 可证：运副之后可迁都转运使，运副是监司内的资深副贰。
- 不可证：行状不系逐年月，不能据此排定任次。

## 推理、反证与异说

序位方向有三层依据：职官志的排列与"随资浅深"明文、政书所记命词礼遇差异、以及治平前后的实际迁转链。三层同向，故对 1066 判断"副使在判官之上"取 B。主要反证与限制如下：

1. **"随资浅深"属南渡后叙述。** 北宋的副使、判官是两种差遣，且副使曾罢废，不能把二者当成同一职位的两个等级。游戏若以同一头衔显示两种官称，是对"以资序择差遣"的近似，不是复原原制。
2. **南宋不宜套用。** 《文献通考》记光宗绍熙以来使、副、运判不双除，运判因而可单独掌一路漕司；"判官低于副使"只适用于本条所限的北宋中前期。
3. **判官与提刑不同司。** 运判迁提刑是迁转次序，不是同一转运司内的层级；不能据此说提刑是运判的上司。
4. **判官的实权不低。** 政书明记判官曾"与转运争权而罢"，说明其地位随人、随路浮动，不能以官称低即视为闲职。

## 游戏对应与采用

- 游戏现状：公爵级文官统一显示"转运副使"，见[中央、地方官名](../../../docs/court/README.md)。
- 本主题结论支持"以资序区分副使与判官"的方向，但**未采用**，也未据此改动任何游戏数据。方案、阈值与风险见[公爵级文官称号按资序分等](../../../docs/court/duchy_naming.md)。
- 游戏头衔级别不等于宋代实际品秩；本条不主张公爵级对应某一寄禄官，也不主张功绩等级等于资序。
