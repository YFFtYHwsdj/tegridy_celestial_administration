整理入库：2026-10-17；深化终审：2026-10-18；C/D 二轮扩查：2026-10-19；第三至五轮定向补证：2026-10-19；第六轮 D 级复核：2026-10-19。范围：18个游戏路，包括河北、关内、岭西三条军路。目标为CK3的1066.9.15（宋英宗治平三年八月二十四日）。

## 当前结论

按[考证规范](../../standards.md)评定“目标开局任职”，与“曾经任职”分开。
依用户最新指示（“如果能确认制度兼任，就找到是谁兼任，再按照标准判定ABCD”），考证形成**专任独立提刑**与**监司兼领司法**双轨成果：
- **口径一（专职独立提刑口径）**：A1、B10、C1、D6；
- **口径二（兼领监司确权口径）**：**A1、B15、C1、D1**（2026-10-19 第五轮后维持；山南兼领 B、专职 C，夔州 C，淮南 D；均未实装，详见下文）。

口径一 D6 之“缺位”指**未见具名任职者、题名空缺**，不是制度上必无宪司；口径二各兼领 B 均为制度推定，须并列“该路或有宪司失载”的替代解释（第六轮，见下）。

## 2026-10-19 剩余 C、D 路分第二轮史料扩查（山南、淮南、夔州）

> **第三轮修正提示（2026-10-19 晚）**：本节是第二轮当日记录。其中淮南“D→C”已被第三轮推翻（苏寀治平三年三月已在成都，回 D）；山南“刘述降睦州无据”已被第三轮恢复（确有据，但为治平元年正月盐法案）；河南刘述“待复核”已定为 C。以下保留原记录以见过程，当前结论以第三轮及总表为准。

针对口径二仅存的 1C+2D 三路，分别派出独立子代理扩大史料并复核目标日实际行使提刑／兼领司法职权者。结果：三路均有实质进展，但均止于 C 级候选，无一升 B、无一实装；15 个固定提刑机构的历史文件仍全部 `holder = 0`（三军路未开放固定机构），研究结论与游戏采用继续分开。

### 山南：维持 C（孔延之候任在途）

- **更正前稿误说**：《东轩笔录》卷十一只记刘述在荆南缣帛哗噪时“大惧，不知所为”，无贬责；《宋史》卷321 本传记其“改荆湖南北、京西路转运使……神宗立，召为侍御史知杂事”，《长编》卷209 治平四年闰三月又载“京西转运使刑部郎中刘述兼侍御史知杂事”，是升擢而非远贬。“刘述因哗变降知睦州”无原始依据，已从分路稿删除，断档论据改为“漕司任期仍有缺口”。
- **漕司序列**：新增 E-10—E-19，考出刘述（治平元年前后）→苏寀（字公佐，郑獬诗“苏刑部”“晚得苏公佐”，治平二年秋前移淮南）→“唐司勋”（治平三年末郑獬离荆南北归时在任，疑即唐诏）。苏寀已考定并排除；唯一可能覆盖目标日的“唐司勋”无姓名确考、无起讫系年，兼领口径仍为 C。
- 孔延之十月十七日浯溪题名“赴湖北提刑”的在途铁证不受影响，专职口径维持 C。

### 淮南：D → C（候选苏寀），机构 A 不变

- **新增证据 E-15—E-24**：苏寀确任淮南转运使，可能填补张刍迁发运副使之后、苏颂治平四年到任之前的空档，是其中唯一有姓名可考者。郑獬《苏刑部自湖北移漕淮南》与韩维《南阳集》卷23《缴还除苏寀辞头状》可将其淮南任框在治平二至三年；但韩维缴状显示其治平三年内已除侍御史知杂事，月份不明，八月二十四日是否仍在淮南无法判定，故列 C 不升 B。
- **新增排除与辨伪**：孙锡（王安石《孙公墓志铭》明系仁宗朝淮南提刑）、张景宪（《宋史》本传“仁宗朝为部使者”，治平间为京西、京东漕）、刘极（刘攽《彭城集》卷22 制词，同卷邻制皆元祐，辨伪）、陈枢（曾任淮南提刑而无纪年，待核）。
- 若后续考出苏寀知杂除命的月日：在八月后则可升 B；在八月前则应回退排除。游戏默认仍 `holder = 0`，若必须填人则以苏寀标 C／暂定。

### 夔州：兼领 D → C（候选：兵部郎中吴兴陈氏，名待考），专职 D 维持

- **新增证据 E-11—E-16**：蒲宗孟《重修至圣文宣王庙记》（治平四年六月庙成后撰，作者时任本路学官）载“治平三年，兵部郎中吴兴陈公由三司判官出领本路转运使，入境……是年冬，孔子四十六世孙以尚书员外郎来为转运判官”。据此可证：①治平三年夔州路确有陈姓转运使在路视事；②张林宗去任后运判空悬至冬，覆盖八月二十四日；③孔宗翰（据《宋史》卷297 推定）、张诜（《长编》卷219 熙宁三年二月已“任满再任”）、孙桷（同年权转运使）均晚于目标日。
- **不升 B 的三项缺口**：陈公名讳、到任月、八月二十四日是否已在任。若陈公九月后才“入境”，则目标日漕司仍无人，C 亦不能成立；此为最大反证。因缺具名，游戏仍 `holder = 0`，不得据 C 填人。
- 新增排除：孔宗翰（冬到任，晚于目标日，身份落点属推定）、张诜、孙桷、江中行；正德《夔州府志》宋名宦门无治平漕臣，只作“旧志失载”的证据，不作否定证据。

## 2026-10-19 第三轮定向补证（山南唐诏、淮南苏寀、夔州陈公、河南刘述）

> **第四轮修正提示**：第四轮已把山南兼领由 C 升 B（唐诏），夔州候选改为“陈经（推定）”但仍 C；淮南 D、河南刘述 C 不变。以下保留第三轮当日记录，当前结论以第四轮及总表为准。

第二轮把三路推到 C 级候选后，第三轮按各路的“唯一缺口”定向补证。结果：**山南维持 C、夔州维持 C、淮南由 C 回 D、河南刘述由 B 降 C（河南全路 B 仍由陈汝义支撑）**；第三轮当时口径二为 **A1、B14、C2、D1**，无一例升 B、无一人实装。

### 山南：维持 C，考定“唐司勋”即唐诏

- 周必大《文忠集》卷49《跋蔡君谟与唐诏帖》考定唐诏字彦范，唐肃之子、唐询之弟，钱塘人；文莹《玉壶清话》卷六直书“郑翰林公镇荆南，唐诏彦范漕湖北”，把第二轮仅属推定的“唐司勋”落到唐诏本人（E-20、E-21）。
- 唐诏确与知荆南郑獬同时在任，但郑獬离荆南、唐诏到任/去任均无月日，无法证明治平三年八月二十四日仍在湖北漕任，故兼领口径仍 C；孔延之专职口径亦仍 C。
- **刘述条再校正**：《宋会要辑稿》职官六五“黜降官”门载“英宗治平元年正月二十三日，荆湖北路转运使刘述降〔知〕睦州，坐擅支茶本租钱及令商人贴盐钞钱以乱盐法，而奏报不实故也”（SRC-0135）。第二轮“降知睦州无原始依据”更正过头；现恢复“确有降睦州”，但贬因是盐法案，不是缣帛哗变。刘述 1064 年初离湖北，漕司第一长官缺口提前，反而强化山南 C 的断档论据。

### 淮南：C → D，苏寀排除

- 赵抃《清献集》卷三《送苏寀刑部赴召》“不烦右蜀专飞挽，直为南台正纪纲……豸角风霜秋肃肃”、卷四《次韵苏寀游学射山》“上巳家家出郡城”，《成都文类》卷十三“苏侯亦继领将漕”，《宋史》卷316《赵抃传》“会荣諲除转运使，英宗谕諲”四条合成闭环：苏寀治平三年三月三日已在成都与赵抃游宴，同年秋自成都召入御史台。

- 这是本轮最重要的“反向修正”：新增证据没有把 C 抬成 B，而是证明原 C 候选不在目标日任上。苏寀仍是有姓名可考的一任淮南漕，但时点不符。

### 夔州：维持 C（陈公仍不具名）

- 陈公具名五路（籍贯谱牒、官衔交集、差遣除授、版本校勘、CBDB）均未成功；《全蜀艺文志》卷34 另存一本，两本均作“陈公”不名，排除“版本脱名”（E-17）。

- 陈公名讳、到任月、八月二十四日是否已在任三项缺口未补，故兼领 C、专职 D、`holder = 0` 均不变；若陈公九月后才入境，C 亦不能成立，此为本条最大反证。

### 河南：刘述京西兼领 B → C，陈汝义 B 不变

- 《宋会要辑稿》职官六五明载刘述治平元年正月二十三日以荆湖北路转运使降知睦州；职官一一又载治平四年九月“刑部郎中、兼侍御史知杂事刘述以久不磨勘，特命为吏部郎中”，坐实《宋史》“又十一年不奏课”是磨勘久次，与漕司无关（SRC-0135、0136）；《长编》卷183 嘉祐元年条只是磨勘迁兵部员外郎（SRC-0137）。

- 河南全路 B 级仍由开封府界陈汝义（E-01—E-03）支撑，未受影响；四库本《长编》卷209“陳汝義/羅愷”与点校本用字小异而纪事、月日、官衔全同，已校记。

## 2026-10-19 第四轮定向补证（山南唐诏、夔州陈公、淮南副贰、河南刘述）

### 山南：兼领 C → B（唐诏），专职 C 不变

- 史照（史怊）由“待核”改排除：《宋会要》蕃夷二·辽下载治平四年八月十八日史照尚以“光禄卿”奉使河北回，署衔未带淮南转运使；至熙宁元年六月始见“淮南转运使、光禄卿史照”降知单州。合苏颂治平四年七月到任，其淮南任必在目标日之后。
- CBDB 史怊 1065—1067 系 Hartwell 推定（`c_source=0`），不采用。张洞、马仲甫虽有“曾任淮南转运使”明文，但无移任月日，且张洞与江西稿“治平三年八月在江西”互斥，列待核，不升 C。
- 结论：机构 A、专职排除、个人 D 均不变；最大缺口仍是 1066.3—1067.4 之间的正使/副贰姓名。

### 河南：维持 C

- 新证：清邹柏森《严州金石录》卷上“竹阁诗刻”碑末“治平二年十月，知郡事刘述书”，小传“历荆州、湖南北、京西路转运使”；乾隆《严州府志》卷24《思范亭记》复录同条（多“尚书”异文）。刘述在睦州的下限由治平元年正月推到 **1065.10**。
- 万历《严州府志》卷9、乾隆《严州府志》卷10 宋知州表均无治平、无刘述（《浙江通志》同）；《严陵集》卷4 张伯玉诗“使君刘孝叔”“花意知君改外台”为同时人旁证，但无年月。
- 京西任可定区间收窄为 **1065.10 之后—1067.4 之前**，目标日落在区间内，“已到京西”与“尚在睦州/赴任途”两解仍不能排除；故维持 C，不改判排除。陈汝义府界 B 不动。

## 2026-10-19 第六轮：D 级（最低等级）六路定向复核

本轮只查口径一仍为 D 的六路（江东、兴元、江西、淮南、河南京西、夔州）与口径二唯一 D（淮南），分派七组互不通气的子代理，只求能改变等级的新证据或新排除。**结果：六路 D 级全部维持，无升级、无实装；但修正若干事实错误，并把“制度性专职缺位”的论据整体降格。**

### 制度前提：罢宪并非全线执行

- 治平元年闰五月“罢提点刑狱而委转运司”见于《职官分纪》卷47、《文献通考》卷61、SRC-0081、SRC-0192；然其执行明显有地域差：《长编》卷202 治平元年七月京东提刑王纲仍在任；《宋会要·瑞异三》同年六月、七月诏仍列提刑；《长编》卷204 治平二年正月河北提刑王靖；《宋会要·职官四七》考课院条 1065—1066 河北提刑沈扶；《华岳志》蔡延庆 1067 陕西提刑；《长编》卷221、227 熙宁四年江东范百禄、利州周约（SRC-0190、SRC-0191、SRC-0198）。
- 因此六路“制度性专职缺位”一律改为**“未见具名任职者，属题名空缺”**；“制度上应当归转运司兼领”不能再当作已证前提。口径二各兼领 B 保留（B 本就允许缺直接材料），但须注明系制度推定，替代解释（本路宪司失载、或武臣提刑在任）不能排除。

### 分路结果

- **淮南（唯一 D）**：雍正《扬州府志》卷19 三目俱全而无治平条；苏颂 1067.7.15 到任、1067.9 仍在任；张洞移淮南无年月，卒于 1067.7.12，正使断层下界由 1067.4 修正为 1067.7。王举元排除，马仲甫仍无年月。**个人 D 维持，holder 仍为 0。**
- **江西**：蔡挺任江西宪为 1062.2—1064.4，1065.3 改陕西运副（《长编》卷196 考异）；旧稿“治平元年起无专职提刑”“蔡挺治平二年十二月移庆州”均误。夏倚 1067.1 始除江西运判。**专职 D、兼领 B 维持**；“船七岁”倒推七年不再称铁证。
- **江东**：范百禄 1071.3（熙宁四年三月庚戌）始提点江东刑狱，纠正“熙宁五年后”。**专职 D 维持**；王皙兼领 **B 维持但降格**：其制词只证江东转运使，无提刑衔、无行刑狱事，若按严格证据标准应降 C。
- **兴元**：利州 1071 已有提刑周约；旧稿“韩璹治平二至三年任河北提刑”降为推定。**专职 D 维持**；杨宁兼领 B 维持，替代解释（利州或有宪司失载）并列。
- **河南京西**：京西提刑与漕的治平三年除授仍全缺；刘述区间仍为 1065.10—1067.4，无 1066 锚点。**专职 D、刘述 C、府界陈汝义 B 均维持。**
- **夔州**：《长编》全帙“夔”字 1064—1068 零见，“陈经”7 见而无一处与夔共现；乾隆《夔州府志·秩官》不设路级监司门（体例所致）。**专职 D、兼领 C（陈经·推定）维持，holder 仍为 0。**

### 事实更正

1. 江西蔡挺宪漕转换年份（据《长编》卷196 考异），见上。
2. 淮南“治平四年春移淮南”之“春”系推算，改为“1067 年上半年”；张洞卒日 1067.7.12。
3. 江东范百禄并非“熙宁五年后”，而是 1071.3 除江东提刑。
4. SRC-0079 所引“《长编》卷213 李焘考异‘四年三月庚戌淮南始除赵济’”四库本无此文；赵济“权发遣同提点刑狱”实见卷221，卷次应改，考异原文标**待复核**，“铁证”语气降为“制度记载＋首任年份”。
