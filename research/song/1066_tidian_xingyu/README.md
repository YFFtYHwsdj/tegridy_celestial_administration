# 1066.9.15宋朝提刑开局考证

整理入库：2026-10-17。范围：18个游戏路，包括河北、关内、岭西三条军路。目标为CK3的1066.9.15；史料宋历纪年另列，未逐项完成历法换算。

## 当前结论

按[考证规范](../../standards.md)评定“目标开局任职”，与“曾经任职”分开。**当前A1、B3、C7、D7，尚未完成全路定人。** 福建罗拯A、湖南程濬B、河东毋沆B、河北韩璹B分别可作固定史实依据和高可信选择，均未实施。C仅为有时段联系的候选，不表示高度可能；河南C只限府界适配，历史京西本任仍D。

## 等级调整与终审记录

2026-10-18 经 15 组独立考证员与 4 组核查员两轮交叉复核：
1. **河北升 B**：凭借王安石《乐安郡君翟氏墓志铭》与《宋会要·职官四七》考课院追记，确证前任沈扶六月前移知明州后因妻病留京佐三司，九月十日妻卒改知苏州；治平二、三年河北提刑仅沈、韩二人，韩璹在任逻辑闭环，由 C 升 B。
2. **山南驳回升 B、严守 C 级**：浯溪题名虽借随行子武仲、和仲与曾巩墓志考实“施□□”为孔延之之讹，但题名明确为治平三年十月十七日“赴湖北提刑”，开局目标日（八月二十四日）距此近两月，孔延之在道赴任尚未到任视事，开局在任前任待考，依据规范第 15、49 条坚决驳回冒进升 B，恪守 C 级。
3. **岭南确立晁宗恪首选**：曾巩撰《光禄少卿晁公墓志铭》与《永乐大典》引陈偁传互证晁宗恪治平提刑并“摄帅广州”，史料信度确凿，替代志怪小说《青琐高议》中的赵琪，因缺开局直接月日维持 C 级。
4. **两浙维持稳固 C 级**：元积中治平四年盐桥运河石刻确凿，单锷《吴中水利书》记治平中，排查排除夏倚、李惟宝，明志治平三年缺原始文牒，审慎维持 C 级。
5. **关内与青徐跨路互斥澄清**：蔡延庆四月青州云门山与十月长编英宗召试双端锚点确凿，剔除未核得之“九月丁未诏择”推论；一人不可两兼，双路均定 C 级，供游戏适配二选一取舍。
6. **七个 D 级路完成全面排查与伪候选肃清**：
   - 西川纠正“治平大水”传抄讹误，确认为“熙宁初河北大水”，彻底排除谢景初；
   - 东川依据出土邵雍撰《姚奭墓志》排除姚奭；
   - 兴元依据文同诗文内证确证景儒为熙宁后期褒斜入觐、李子忠为熙宁新规“散利目以万牍”特擢，全部排除；
   - 淮南核实赵济为熙宁四年常平转任、邵必1065内调编御集，并纠正韦骧《钱塘集》“元郎中、毛职方”路分错配；
   - 江西核实张颉熙宁三年奏议自述“七岁始易、法废五六”，排除连续在任假设，蔡挺大顺城督战御夏排除；
   - 夔州核实王居卿灵岩寺碑阴熙宁三年知齐州，排除作为 1066 候选。
   - 所有 D 级路坚决纠正“制度性空缺”之主观猜测，严格依规表述为“史料缺失待考”。
