- **兴元 D**：历史客观盲区。《长编》治平全卷利州/兴元出现0次，汉中褒斜宋代摩崖皆南宋，排除韩璹（移河北）、苏涣（嘉祐七年卒）等9人。[判断与证据](circuits/xingyuan.md)

## 本次 14 路专项子代理深化考证成果（2026-10-18）

本次通过并发 14 组专属历史考证子代理，针对原评级为 C、D 的全部 14 个路展开拉网式文献检索与对勘，获得重大突破与制度史厘清：

1. **重大突破与等级晋升**：
   - **两浙路升 B 级**：纠正元积中 CBDB ID `39228`、字子发；《行水金鉴》与《吴中水利全书》确证“治平三年浙西提刑元积中开运河”；南宋《宝庆会稽续志》解明题名缺载根源；排除夏倚等9人。
   - **岭南路升 B 级**：曾巩墓志确立仕历闭环；《永乐大典》引《了斋集·先君行述》确证晁宗恪治平三年春提刑摄帅广州与惠州知州陈偁班春互证；排除志怪小说《青琐高议》赵琪。
   - **关内路升 B 级**：考获清王昶《金石萃编》卷128《蔡延庆华岳题名》亲笔题刻“治平丁未领本路提点刑狱谒祠下”，十月英宗召试因帝疾搁置，次年在陕实任，前后锚点完备闭环；排查全陕无竞争对手。
   - **西川路重大突破（由 D 升 B 级 / 顶格 C）**：发掘赵抃《清献集》盛夏嘉阳按部送荔诗、海云山三月同游唱和；文同《祭提刑邢度支文》确证邢梦臣持节提刑并卒于官，排除谢景初、沈衡、苏寀，彻底终结西川空白。
   - **东川路重大突破（由 D 升 C 级）**：发掘文同治平三年秋知普州下车呈《谢提刑张郎中启》，与《丹渊集》卷20张林宗挽诗自注“夔州运判移梓州路提刑”时空闭合，弟张道宗仕历印证，排除姚奭等，打破无候选局面。
   - **河南开封府界适配升 B 级**：彻底澄清“治平三年二月转官”讹误，确证离任在治平四年三月丙辰（神宗召对），治平三年全年在任；排查排除范纯仁等12位京西提刑，京西历史本任严格维持 D 级。
2. **严守学术审慎、维持 C 级强候选**：
   - **山南路**：浯溪题名明确为十月十七日“赴湖北提刑”，开局八月二十四日处于在途状态，前任史料客观失考，恪守 C 级强候选，坚决不冒进升 B。
   - **岭西路**：校正伏波山题名为治平二年立夏，确立直接承接序列；余藻二年任期算至治平三年十一月且章岘十一月中旬始题诗，余藻候代在任掌印概率显著占优，维持 C 级双候选。
   - **青徐路**：四月青州云门山实任题名确凿，但十月召试名衔转陕西，后任失载，排除王居卿等12位疑似后任；与关内互斥，维持 C 级。
3. **查清制度史真相、坚守 D 级学术客观极限**：
   - **江西路**：考订治平元年闰五月罢提刑委转运司，张颉熙宁三年奏议自述“自挺去，船七岁始易……法十废五六”，确证蔡挺调离后数年处于转运司兼管之制度性空缺，维持 D 级；
   - **淮南路**：邵必治平元年内调，治平元年闰五月诏罢提刑委转运司，扬州漕司发运司坐镇，刑狱转归转运司（李复圭等）兼领，维持 D 级；
   - **江东路**：澄清《景定建康志》卷26实为南宋诸司寓治表，排查排除王安石（守制）、范纯仁等10人，确证史料客观阙载，维持 D 级；
   - **兴元路**：长编治平全卷利州/兴元出现0次，汉中褒斜宋代摩崖皆南宋，排除韩璹（移河北）、苏涣（卒于官）等9人，维持 D 级；
   - **夔州路**：《舆地纪胜》夔路核心八州郡题名全部散佚残缺，程师孟治平元年召还入朝任度支判官，排除王居卿、江中行等，维持 D 级。
