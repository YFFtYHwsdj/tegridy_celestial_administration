# 1066.9.15宋朝提刑开局考证

整理入库：2026-10-17。范围：18个游戏路，包括河北、关内、岭西三条军路。目标为CK3的1066.9.15；史料宋历纪年另列，未逐项完成历法换算。

## 当前结论

按[考证规范](../../standards.md)评定“目标开局任职”，与“曾经任职”分开。**当前A1、B1、C9、D7，尚未完成全路定人。** 福建罗拯A、湖南程濬B分别可作固定史实依据和高可信选择，均未实施。C仅为有时段联系的候选，不表示高度可能；河南C只限府界适配，历史京西本任仍D。

## 等级调整

旧口径A1/B1/C14/D2保存在[旧稿](archive/research_2026-10-17_legacy.md)。江东晏知止、淮南赵济、江西张颉、西川谢景初、夔州王居卿五路由C退D：现有材料不能把相关差遣与1066目标时点联系起来。撤回的是开局候选等级，不是否认其其他时期履历。

东川、兴元仍D。其余九处C的候选联系与缺口见分路开头；河南还有“府界适配C／历史京西D”的两个不同判断，不能只看汇总字母。减少D数量不作为研究质量目标。
