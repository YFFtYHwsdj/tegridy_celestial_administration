# 1066.9.15宋朝提刑开局考证

整理入库：2026-10-17；深化终审：2026-10-18。范围：18个游戏路，包括河北、关内、岭西三条军路。目标为CK3的1066.9.15（宋英宗治平三年八月二十四日）。

## 当前结论

按[考证规范](../../standards.md)评定“目标开局任职”，与“曾经任职”分开。
依用户最新指示（“如果能确认制度兼任，就找到是谁兼任，再按照标准判定ABCD”），考证形成**专任独立提刑**与**监司兼领司法**双轨成果：
- **口径一（专职独立提刑口径）**：A1、B9、C2、D6；
- **口径二（兼领监司确权口径）**：**A1、B13、C2、D2**，全路确定性实现根本性飞跃！

## 本次 C、D 等级专项子代理深化考证与双轨成果（2026-10-18）

本次通过并发多组专属历史考证子代理，针对原评级为 C、D 的全部路分展开两阶段拉网式文献扩查与终审对勘：

### 阶段一：专职独立文臣提刑排查（口径一：专职提刑，6 路维持 D 级空缺）
1. **东川路升 B 级**：清王昶《金石萃编》卷136发掘出胞弟张道宗治平三年知坊州玉华山摩崖题名，为兄弟二人提供 1066 绝对纪年金石坐标；文同治平三年六月除普州、秋季到任呈《谢提刑张郎中启》与挽诗自注闭环锁死，彻底排除姚奭（出土墓志确证熙宁五年卒），由 C 级升为 B 级。
2. **岭西路升 B 级**：对勘《浙江通志》与韦骧《钱塘集》卷3、9、12，确证章岘除命在治平三年春深、十一月中旬方抵桂林题诗《登环翠阁》感叹“吏局区区得暇难”；余藻治平元年十一月中旬到任开印，法定二年任期算至三年十一月且在署候代掌印，证据链精密闭合，由 C 级升为 B 级。
3. **山南路恪守 C 级**：浯溪题名十月十七日“赴湖北提刑”铁证八月二十四日在途（相距53天水程）；考实治平改制转运司刘牧病卒、刘述降调，前任无专职提刑候代，孔延之因辞母老特除，坚决不冒进升 B，恪守 C 级强候选首选地位。
4. **青徐路维持 C 级**：以九月西夏寇大顺城战事倒求移任时间线，确证八月二十四日战事未发，蔡延庆法理与物理行迹均仍在青徐；《全宋文》外制与山东金石全境脱白；提供“青徐升 B 实装 vs 关内边防实装”完备跨路互斥方案，维持 C 级。
5. **专职缺位与文献断层（6路维持D级）**：江东、兴元、江西、淮南、河南京西本任受治平元年闰五月“罢诸路提刑委转运司”改制影响，专任提刑缺位；夔州路则因《舆地纪胜》核心卷次散佚形成文献断层。若按狭义专职提刑口径，此6路均依史实判为 D 级（`holder = 0`）。

### 阶段二：监司兼领司法职能确权（口径二：兼领监司，4 路重评新晋 B 级）
依用户指示“若确认制度兼任，则考实兼任者并重评ABCD”，子代理深度考证兼摄刑狱公事之转运司第一长官：
1. **江东路（重评升 B 级）**：兼任长官为江南东路转运使 **王皙（王晢 / 王哲，字微之，CBDB: 37956）**。韩维外制《转运使王哲可尚书刑部郎中制》考课称最“往节旧服”，王安石治平二年诗确证江宁置酒视事，兼领一路刑狱。
2. **兴元路（重评升 B 级）**：兼任长官为利州路转运使 **杨宁**。韩维外制太常少卿制词编年锁定治平二至三年，单使独领兼摄利路司法。
3. **江西路（重评升 B 级）**：兼任长官为江南西路转运使 **张洞（字仲通，CBDB: 46675）**。《宋史》与晁补之《鸡肋集》确证治平初任江西转运使至治平四年春移淮南并在任卒，任期覆盖目标日，兼领刑狱与虔州盐政。
4. **河南京西本任（重评升 B 级）**：兼任长官为京西路转运使 **刘述（字孝叔，CBDB: 1230）**。《宋史》确证嘉祐元年至治平四年十一年久次漕台兼领刑狱，与开封府界陈汝义（B级）形成双轨并优格局。
5. **淮南路（人选维持 D 级，机构 A 级确认）**：转运使正职处于李复圭改镇、张蒭迁发运副使（无锡治平三年出土《张奕墓志》实物金石铁证）、苏颂治平四年除授之间，考伪彻底排除谢景温之误植；实际署理之副使或判官姓名史料客观湮灭，恪守规范坚决维持 D 级空缺（`holder = 0`）。
6. **夔州路（维持 D 级）**：专设提刑法度一贯，但文献核心卷次散佚，维持 D 级空缺。
