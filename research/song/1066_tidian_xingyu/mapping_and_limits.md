## 历史十九辖区至游戏十八路的主对应

以下从初审保留地理对应与差异提示，只是核心适配，不是1066逐县边界重建；《宋史》地理志兼叙多时期沿革，须剔除晚出改名。

1. **开封府界 → 河南 `k_henan` 内的汴州 `c_bianzhou` 一带。** 没有独立府界王国级路。

2. **京东路 → 青徐 `k_qingxu` 为主。** 青、齐、兖、郓、曹等核心在此；但游戏把宋、单等放河南，又把宿、泗、海等淮南地放青徐。

3. **京西路 → 河南 `k_henan` ＋ 山南 `k_shannan` 的襄邓部分。** 河南有洛阳、汝、郑、陈许等，山南的 `d_xiangdeng` 有襄、邓、唐、均、房、郢、随。

4. **河北路 → 河北 `k_hebei` 为主。** 大名所对应魏州、真定所对应镇州等在此，但边缘划分与宋制不同。

5. **河东路 → 河东 `k_hedong` 为主。**

6. **陕西路 → 关内 `k_guannei` 为主。** 核心为京兆、凤翔、邠宁、鄜延、环庆、泾原、秦州等；游戏边界仍非宋代陕西路原样。

7. **两浙路 → 两浙 `k_liangzhe` ＋ 江东 `k_jiangdong` 的苏、润、常。** 不能只挂两浙王国便声称复原历史两浙辖境。

8. **淮南路 → 淮南 `k_huainan` 为主，并涉及青徐、河南、山南的部分州。** 游戏宿、泗、海在青徐，亳在河南，黄、蕲在山南。

9. **江南东路 → 江东 `k_jiangdong` 为主，饶、信、南康在江西 `k_jiangxi`。** 同时游戏江东内的苏、润、常在历史上是两浙地。

10. **江南西路 → 江西 `k_jiangxi` 为主。** 须排除游戏江西中属于历史江东的饶、信、南康等。

11. **荆湖南路 → 湖南 `k_hunan` 为主。** 潭、衡、永、邵、道、郴等核心在此；游戏另包含连州，不代表宋制原样。

12. **荆湖北路 → 山南 `k_shannan` 的荆南、鄂岳部分，另有辰州等落在夔州 `k_kuizhou`。** 山南同时包京西襄邓及淮南黄蕲，不能整路等同湖北。

13. **福建路 → 福建 `k_fujian`。** 是较清楚的主对应。

14. **广南东路 → 岭南 `k_lingnan` 为主。** 但游戏岭南还收入历史广南西路的雷州、海南等；连州又在游戏湖南。

15. **广南西路 → 岭西 `k_lingxi` 为主，另含岭南 `k_lingnan` 中雷州、海南等。**

16. **成都府路 → 西川 `k_xichuan` 为主。** 游戏绵州位于东川等边缘差异仍须考虑。

17. **梓州路 → 东川 `k_dongchuan` 为主。** 游戏东川还含历史夔州路的渝州，历史梓州路果、渠等又可落游戏兴元。

18. **利州路 → 兴元 `k_xingyuan` 为主。** 兴元、洋、利、阆、文、巴等核心在此；游戏兴元也含历史其他路的部分州。

19. **夔州路 → 夔州 `k_kuizhou` 为主，但渝州在东川、开州在兴元。** 游戏夔州又收入湖北辰州及五溪部分地区。


## 制度与日期限制

军路是游戏契约分类，不证明宋代不存在文臣司法监司。历史宪区、游戏de_jure与de_facto关系分别讨论；路主不等于提刑。同一个人不能为凑齐名单同时安排两个游戏路。

府界与京西分开；河南、山南包含多个宪区，江东两浙江西、四川四路及岭南岭西存在边界错合。人物采用时另写适配理由，不宣称辖境完全还原。

宋历月份保留原纪年，治平三年十二月可能落在西历1067年；未完成换算，不把宋历月份当同名公历月份，也不使用混合的“儒略历公历”。游戏1066.9.15是研究目标，其与史料日期的精确换算需明确方法。

《职官分纪》卷47记治平元年闰五月罢提刑、委转运司，与1065—1066多路实际署衔存在待解抵牾。实施范围、文本及是否恢复仍待核；不能据此把未知判为缺官，也不能无条件沿用原稿“19司始终齐备”。出处见[旧稿第五节](archive/research_2026-10-17_legacy.md#五尚未解决会影响进一步定人的问题)。
