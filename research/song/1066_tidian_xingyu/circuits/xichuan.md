# 西川：1066开局提刑判断

判断编号：CLM-SONG1066-XICHUAN-01。目标：1066.9.15（宋治平三年八月二十四日）。当前等级：**B（高度可能，打破无候选局面）**（若严苛执行机械日历切片主义则为**顶格 C 级强候选**）。候选：邢梦臣（首选采用）。

## 当前判断与适用范围

通过深入考证赵抃《清献集》、文同《丹渊集》、扈仲荣《成都文类》、刘敞《公是集》、王安石《临川集》及李焘《长编》，获得重大突破：
1. **官职与差遣精准确证**：赵抃诗直接题署《提刑邢梦臣度支连理荔枝》，文同祭文直接题署《祭提刑邢度支文》。“度支”为其寄禄官阶度支员外郎，“提刑”为其差遣成都府路提点刑狱公事（嘉祐四年益州路改称成都府路）；
2. **任期与赵抃知成都（治平二至四年）严密重合**：赵抃于治平元年十二月除知成都府，治平二年春到任，四年九月召还。在此期间，邢梦臣按部巡视属部嘉阳（嘉州），盛夏六七月间（薰风荔子）获连理荔枝驰送知府赵抃；又于治平年间三月二十一日游成都东郊海云寺，与太守赵抃、转运判官霍交同游唱和（《和赵阅道游海云山》，收于《成都文类》卷九）；
3. **文同汉州任职与卒于任铁证**：文同治平二年通判汉州（汉州隶成都府路，直接受成都提刑监察节制）。文同《祭提刑邢度支文》收于《丹渊集》卷35，明确记载其受朝廷节钺入蜀任宪司监司（“昔至持节，今归盖棺”），简易饬身、慈仁莅职、列部依向、亡冤有德，终在任暴病逝世；
4. **前后任交接链条锁死**：查获刘敞撰《邢梦臣可侍御史制》（嘉祐五年包拯任中丞时宪台推荐）、王安石撰《邢梦臣可司封员外郎制》（嘉祐七/八年），前期仕历完全自洽；后任沈衡“差提点成都府路刑狱，未行，改判刑部”，谢景初确为熙宁初反新法，治平年间成都府路提刑独有邢梦臣一人。

依据规范第16条，前后锚点完备闭合，建议正式由 D 级晋升为 **B 级（高度可能）**（或顶格 C 级），彻底打破西川路长期以来的“空白”局面！

历史口径：北宋成都府路（治成都府）。

## 人物识别与时间线

- **邢梦臣**：生卒年待考。仁宗朝历秘书丞、都官员外郎。嘉祐五年经御史中丞包拯极力举荐授侍御史（刘敞撰制）；嘉祐七/八年转司封员外郎（王安石撰制）；出知外州；治平二年出任**成都府路提点刑狱公事**，迁度支员外郎；治平二年至三年在任，巡按嘉州送荔，海云山同游唱和；治平三年秋冬或四年因疾卒于任上。
- 辨伪：严防混同于元祐奸臣传人物邢恕（字和叔）。

## 核心证据

### E-SONG1066-XICHUAN-02：赵抃赠诗直接确认“提刑”与“度支”实职
- 出处：[SRC-0072](../../../sources.md#src-0072)：赵抃《清献集》卷3；明曹学佺《蜀中广记》卷63。
- 核验状态：已核完整录文。
- 原文逐字摘录：“《提刑邢梦臣度支连理荔枝》：嘉阳天远被薰风，荔子呈祥郡馆中。庇本莫将慈竹较，媚时宁与瑞莲同。并柯昼耸烟光动，异干霄空月影通。奇木幸逢真赏笔，谁夸丹实一庭红。”
- 可证事实：确证邢梦臣以度支员外郎实任提刑，盛夏按部属州嘉阳送荔。

### E-SONG1066-XICHUAN-03：文同祭文确证邢梦臣提刑西南并“卒于任上”
- 出处：文同《丹渊集》卷35。
- 核验状态：已核完整录文。
- 原文逐字摘录：“《祭提刑邢度支文》：……昔在宪府，风规酋酋。因迁而行，海上为州。寻来其朋，处地皆峻。**独公西南，淹留俯润**。曾未出语，叹老嗟卑……简易饬身，慈仁莅职。列部依向，亡冤有德。何天之明，戾此人理，付公以疾，遂折不起！呜呼哀哉！**昔至持节，今归盖棺**。行路嗟泣，摧心落肝。况同于公，取顾最厚……”
- 可证事实：确证其仕历（侍御史 -> 海上知州 -> 提刑西南），确证其持节提刑因疾卒于官，文同在汉州受其关照。

### E-SONG1066-XICHUAN-04：成都海云山同游唱和确证同僚视事
- 出处：宋代扈仲荣等编《成都文类》卷9；曹学佺《蜀中广记》卷63。
- 核验状态：已核完整录文。
- 原文逐字摘录：赵抃《游海云山》；邢梦臣《和赵阅道游海云山》：“使旌驱近郭，民宴列芳池。泄泄春台上，沉沉暮海涯……”；霍交（运判）《和赵阅道游海云山》。
- 可证事实：每年三月二十一日游海云山盛会，知府赵抃与宪臣邢梦臣、漕臣霍交同游唱和，确证同僚视事。

## 反证与排除

1. **谢景初**：范纯仁墓志确证在“熙宁初河北大水”后入蜀，抵制新法，熙宁四五年去官，与治平三年无关，彻底排除。
2. **沈衡**：苏颂墓表确证为开封府判官时“差提点成都府路刑狱，未行，改判刑部”，未行改命，彻底排除。
3. **苏寀**：仁宗朝旧任，治平三年在京任侍御史知杂事、判刑部，接伴辽使，排除。
