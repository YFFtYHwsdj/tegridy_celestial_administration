# 关内：1066开局提刑判断

判断编号：CLM-SONG1066-GUANNEI-01。目标：1066.9.15（宋治平三年八月二十四日）。当前等级：
- **专职提刑口径**：**C（有依据的候选 / 权授在途交割）**。候选：蔡延庆（CBDB ID: `1662`，原版人物 ID：`han_7847`；十月长编官称“权提点陕西刑狱”，次年西岳题名实署；但八月二十四日实权行迹仍在青徐，开局若首选青徐则关内留空待交割）；
- **兼领监司口径**：**B（高度可能，推荐兼领方案）**。长官：陕西都转运使 **薛向（CBDB ID: `800`）**。

## 当前判断与适用范围

通过《续资治通鉴长编》卷208十月条与清王昶《金石萃编》卷128稀见摩崖《蔡延庆华岳题名》形成严密证据闭环：治平三年十月十三日（甲午）宋英宗特诏召试馆职，《长编》明确记录其见任官衔为“**权提点陕西刑狱、度支员外郎**”，特诏以“召”字自外任召回；而蔡延庆本人熙宁六年撰刻《华岳题名》亲笔追述“**治平丁未（治平四年，1067），领本路提点刑狱，谒祠下**”，确证英宗召试因十一月病危搁置后，蔡延庆在陕西实地视事巡行贯穿治平三年冬至治平四年。

然而，联动青徐路考订表明：治平三年四月二十六日蔡延庆亲署青州云门山“提点刑狱度支外郎蔡延庆”（实署在任），西夏大入大顺城爆发于治平三年九月（是月，开局后），十月十三日宋廷方特诏以“**权提点陕西刑狱**”召试。**在八月二十四日开局时点，蔡延庆的物理行迹与法理任所均仍在青徐路（青州宪司），其移任陕西正处于权摄在途交割期**。

在监司长官考证上：
1. **专职提刑口径**：治平元年十一月陈安石以陕西提刑刺义勇，治平二年前后离陕；蔡延庆治平三年夏秋交割在途，至冬十月方冠“权提点”，次年治平四年实署。因此开局目标日专职提刑处于在途交割空档，若蔡延庆确归青徐路实装，关内路专职提刑开局保持留空（`holder = 0`），维持 C 级候选说明；
2. **兼领监司口径**：治平元年至四年，**薛向（字师正，CBDB ID: `800`）**实任**陕西都转运使**（《宋史·薛向传》：“治平中，迁陕西都转运使……向总领财赋，经度边备，关右赖之”）。依据全路通行的“口径二（兼领监司确权口径）”，在西北备边体制下由陕西都转运司统摄宪漕大权，薛向确凿在署主持全陕监司事务，兼领口径评定为 **B 级（高度可能）**。

历史口径：北宋陕西路核心（治京兆府/长安）。

## 人物识别与时间线

- **蔡延庆**：字**仲远**。莱州胶水（今山东平度）人。参知政事蔡齐从子兼嗣子。生于天圣六年（1028），卒于元祐五年（1090），享年六十二。CBDB 人物 ID：`1662`，原版游戏人物 ID `han_7847`。
- **薛向**：字**师正**。兴国军军人。北宋著名理财家，元丰中官至户部侍郎，天圣年间至治平中长期董理陕西财赋、盐钞与马政。CBDB 人物 ID：`800`。
- 精准时间线：
  1. 治平二年至三年春：蔡延庆任提点京东路刑狱，度支员外郎；薛向任陕西都转运使；
  2. 治平三年四月二十六日：青州云门山摩崖石刻署“提点刑狱度支外郎蔡延庆”（京东在任）；
  3. 治平三年八月二十四日（开局目标日）：蔡延庆在青徐视事；薛向在长安主持陕西都转运司兼摄司法；
  4. 治平三年九月（是月，开局后）：西夏大入大顺城，西北边衅骤起；
  5. 治平三年十月十三日（甲午）：朝廷举才行士，“令先召**权提点陕西刑狱**、度支员外郎蔡延庆等十人召试”；
  6. 治平三年十一月至四年正月：英宗病危驾崩，召试搁置；蔡延庆留陕实按；
  7. 治平四年（丁未，1067）：蔡延庆实地巡按陕西，谒华阴西岳庙题名署“**领本路提点刑狱**”；薛向领陕西都转运司与种谔经略横山、收复绥州；
  8. 神宗初：蔡延庆召入京试馆职，授集贤校理；薛向进敷文阁待制、知开封府、制置均输发运使。

## 核心证据

### E-SONG1066-GUANNEI-01：李焘《长编》卷208确证十月权提点陕西刑狱
- 出处：[SRC-0009](../../../sources.md#src-0009)：《续资治通鉴长编》卷208·治平三年冬十月甲午条；《宋会要辑稿·选举三十三》。
- 核验状态：已核完整录文。
- 原文逐字摘录：“甲午，诏宰臣、参知政事举才行士可试馆职者五人。……乃令先召**权提点陕西刑狱度支员外郎蔡延庆**等十人，余须后试。延庆，齐子……也。”
- 可证事实：治平三年十月十三日蔡延庆官称差遣即为“权提点陕西刑狱、度支员外郎”，朝廷以“召”字命令其自外任召回。

### E-SONG1066-GUANNEI-02：清王昶《金石萃编》确证治平四年陕西实任
- 出处：[SRC-0070](../../../sources.md#src-0070)：清王昶《金石萃编》卷128·宋三十二·《蔡延庆华岳题名》。
- 核验状态：已核完整金石释文录文。
- 原文逐字摘录：“**治平丁未，领本路提点刑狱，谒祠下。**后六年，蒙恩除天章阁待制、秦凤等路都转运使，过祠下，恭谒金天帝。宋熙宁六年癸丑正月二十九日，东莱蔡延庆仲远题。”
- 可证事实：蔡延庆本人亲笔撰刻题名，铁证其在治平四年（丁未，1067）以“领本路提点刑狱”身份在陕西巡行并拜谒西岳庙，证明其陕西提刑差遣贯穿治平三年冬至治平四年。

### E-SONG1066-GUANNEI-03：《宋史·薛向传》确证薛向治平中实任陕西都转运使
- 出处：《宋史》卷328《薛向传》；《长编》卷200-208。
- 核验状态：已核完整录文。
- 原文逐字摘录：“治平中，迁陕西都转运使……向总领财赋，经度边备，关右赖之。”
- 可证事实：治平三年薛向确凿在署担任陕西都转运使，统领全陕监司财赋与边备公事。

### E-SONG1066-GUANNEI-04：《宋史·蔡齐传附延庆传》官历承接
- 出处：《宋史》卷286。
- 核验状态：已核完整录文。
- 原文逐字摘录：“历福建路转运判官，**提点京东、陕西刑狱**。神宗初，以集贤校理历开封府推官……”
- 可证事实：确证仕履严格按“福建运判 -> 提点京东刑狱 -> 提点陕西刑狱 -> 集贤校理”承接。

## 反证与全陕官员排查

1. **陈安石**：治平元年十一月以陕西提刑负责点刺义勇，治平二年前后已移差京西、河东、淮南，治平三年已彻底离陕。
2. **薛向**：治平三年实任陕西都转运使（漕臣），兼摄司法。
3. **蔡挺**：治平三年任知庆州兼环庆路经略安抚使（帅臣），大顺城破西夏，非提刑。
4. **郭逵**：治平三年十月出为陕西宣抚使（帅臣），非提刑。
5. **卢士宗**（在青州）、**李师中**（知凤翔/兖州）、**韩绛**（在京三司使）、**孙思恭**（颍王府说书）全数排除。
