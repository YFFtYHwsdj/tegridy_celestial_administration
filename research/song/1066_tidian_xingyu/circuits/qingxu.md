# 青徐：1066开局提刑判断

判断编号：CLM-SONG1066-QINGXU-01。目标：1066.9.15（宋治平三年八月二十四日）。当前等级：**C（史实八月在任，处于移陕交接期；跨路互斥决策候定）**。候选：蔡延庆（CBDB ID: `1662`，原版人物 ID：`han_7847`；四月在任实署，开局仍在青徐视事；若关内实装则青徐留空未定）。

## 当前判断与适用范围

经过专项子代理对西北边事时间线、《全宋文》外制词臣制草、山东金石摩崖及各州府志的四维深度扩查，青徐路取得关键性时间差考证突破：
1. **西北战事倒求移任时间线确证**：治平三年四月二十六日蔡延庆亲笔题名青州云门山“提点刑狱度支外郎蔡延庆”（《山左金石志》卷16），距开局不足4个月，确证实地在青州视事；《长编》卷208确证西夏毅宗谅祚大举围攻大顺城爆发于**治平三年九月（开局之后）**，十月初六朝廷方命郭逵宣抚陕西，十月十三日宋廷方诏试“**权提点陕西刑狱**蔡延庆”。“权”字铁证十月尚在移任权摄交割途中。**在八月二十四日开局时点，西北前线战事尚未爆发，蔡延庆的法理职任与物理行迹均仍在青徐路（青州宪司）**；
2. **两宋词臣外制排查无接任者制词**：排查《全宋文》中王珪、韩维、刘敞、司马光、祖无择、邵必等两宋词臣全部外制草，治平三年下半年至四年**无任何一篇除授“京东提点刑狱”之制词**；
3. **金石与方志排查全境脱白**：排查青州云门山、驼山、泰山（含岱庙白龙潭）、长清灵岩寺、崂山石刻，以及《青州府志》《益都县志》《兖州府志》《济南府志》《山东通志》，除治平三年四月蔡延庆云门山题名外，全境金石与方志监司表在治平三年下半年至四年完全空白；
4. **后任失载与跨路互斥**：史实考证确证开局日蔡延庆实权在青徐；但因游戏机制禁止同一人物（`han_7847`）跨路双装，若关内路实装蔡延庆（治平四年华岳实任碑刻为证），青徐路开局保持留空未定（`holder = 0`），维持 C 级说明。

历史口径：北宋京东东路、京东西路（治青州、兖州等）。

## 核心证据

### E-SONG1066-QINGXU-01：四月青州云门山石刻直接自署在任
- 出处：[SRC-0069](../../../sources.md#src-0069)（亦见 [SRC-0010](../../../sources.md#src-0010)）：清毕沅、阮元《山左金石志》卷16。
- 核验状态：已核完整录文。
- 原文逐字摘录：“治平丙午四月念六日，东路安抚使知青州卢士宗、**提点刑狱度支外郎蔡延庆**、太常少卿直史馆田谅、通判职方郎中杨申同游。”
- 可证事实：确证宋英宗治平三年（丙午）四月二十六日，蔡延庆以“度支外郎”官衔实任京东路“提点刑狱”，且在京东东路首府青州与帅臣卢士宗同僚视事。

### E-SONG1066-QINGXU-02：十月朝廷诏试官称权陕西提刑与西北战事时间差
- 出处：[SRC-0009](../../../sources.md#src-0009)：李焘《续资治通鉴长编》卷208·治平三年九月辛卯、十月甲午条。
- 核验状态：已核完整录文。
- 原文逐字摘录：“（九月辛卯）西贼大入大顺城……（十月甲午）乃令先召**权提点陕西刑狱、度支员外郎蔡延庆**等十人，余须后试。”
- 可证事实：九月西夏始攻大顺城，十月十三日蔡延庆名衔始转“权提点陕西刑狱”；开局八月二十四日战事未发，蔡延庆仍在青徐任上。

### E-SONG1066-QINGXU-03：长编考异确证王居卿熙宁四年始任
- 出处：李焘《续资治通鉴长编》卷220考异。
- 核验状态：已核完整录文。
- 原文逐字摘录：“**王居卿为京东提刑在四年二月十一日，不入长编。**”
- 可证事实：确证王居卿任京东提刑在熙宁四年（1071）二月十一日，绝非治平三年后任。
