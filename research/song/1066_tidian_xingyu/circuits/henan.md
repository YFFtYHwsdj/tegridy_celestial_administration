# 河南：1066开局提刑判断

判断编号：CLM-SONG1066-HENAN-01。目标：1066.9.15（宋治平三年八月二十四日）。当前等级：**府界适配 C ／ 历史京西本任 D**。候选：陈汝义（开封府界适配候选，距开局6个月离任且久于其任）；历史京西提刑正任史阙，判定为 D。

## 当前判断与适用范围

游戏河南路（`k_henan`）复合了北宋两个性质完全不同的一级监司辖区：
1. **开封府界（京畿特区）**：由“提点开封府界诸县镇公事”统辖畿内县镇刑狱水利，直属朝廷。《长编》卷209确证陈汝义于治平四年三月丙辰自提点府界改判三司都磨勘，神宗考校府界政务应答详敏，执政明言其“资序已高”，表明在开局时点已在任相当时日，定为**府界适配 C 级**（推荐采用）。
2. **京西路（外路大监司）**：掌河南府（洛阳）、陈、许、汝等外路大政，正任京西提刑在正史编年与金石中姓名失载，排查程颢、范纯仁、刁约、张焘等均排除，定为**历史京西本任 D 级（未定）**。

## 人物识别与时间线

- **陈汝义**（亦作陈汝羲）：泉州晋江人。北宋名臣陈诂之子，河北提刑韩璹之妻舅。皇祐五年（1053）进士。CBDB 人物 ID：`1636` / `98596`。历祠部郎中、**提点开封府界诸县镇公事（治平中）**、判三司都磨勘司（治平四年三月）、试学士院授集贤校理、直史馆、神宗朝历刑部郎中、河东转运使、知应天府。
- 京西提刑排伪：
  1. 程颢（明道先生）：熙宁三年（1070）四月除发遣京西提刑，力辞未就任，排除；
  2. 范纯仁：熙宁中后期任京西提刑，排除；
  3. 刁约：仁宗嘉祐元年（1056）提刑京西，早十年离任，排除；
  4. 罗适、孔平仲：治平二年（1065）方登进士第，任京西提刑在元丰元祐年间，排除。

## 核心证据

### E-SONG1066-HENAN-01：《长编》卷209记陈汝义离任府界提点与神宗奏对
- 出处：[SRC-0013](../../../sources.md#src-0013)：李焘《续资治通鉴长编》卷209·治平四年三月丙辰条、五月癸未条。
- 核验状态：已核完整录文。
- 原文逐字摘录：“丙辰，提点开封府界诸县镇公事祠部郎中陈汝义判三司都磨勘，同知开封县都官员外郎罗恺提点府界诸县镇事。恺入见，上问以开封事，皆不能知，上不悦。及见汝义，问以府界事，应答详敏。翌日，谓执政曰：‘恺不才，宜复用汝义代之，仍与馆职。’执政言：‘汝义资序已高，复为提点则下迁，宜但令试馆职而已。’上从之。……汝义，诂子。”
- 可证事实：陈汝义于治平四年三月（距开局仅6个月）自府界提点移职，对府界政务极熟且资序已高，强力支持治平三年八月已在任；但因缺少直接除授到任日文书，且差遣为府界提点非外路京西提刑，严格判定为府界适配 C 级。
