# 两浙：1066开局提刑判断

判断编号：CLM-SONG1066-LIANGZHE-01。目标：1066.9.15（宋治平三年八月二十四日）。当前等级：**B**（由 C 级正式晋升）。候选：元积中（字子发，首选采用）。

## 当前判断与适用范围

通过《行水金鉴》卷154、《吴中水利全书》卷10与苏轼《东坡奏议》卷7形成严密闭环：清官修与明代水利全书确证“治平三年浙西提刑元积中开运河”，苏轼确证治平四年六月元积中在杭州盐桥运河岸亲笔立石拆违规整牵路；二者属于同一任提刑任期内的连续水利政绩；胡宿《文恭集》入朝制词与韦骧《钱塘集》谢启确证其宪使按视两浙之官称。单锷《吴中水利书》与南宋官修正史《四朝国史·志》互证其为“两浙路提点刑狱”，总其事。

全面排查排除夏倚、李惟宝、张次山、刁约、施元长、钱藻、孙洙、苏味道、沈括等9位疑似人选。南宋《宝庆会稽续志》卷2明确“绍圣以上姓名皆不可考”，从文献史角度解明方志题名缺载根源。符合规范第16条，正式由 C 级升为 **B 级（高度可能）**。

历史口径：北宋两浙路（辖杭州、越州、苏、润、常、湖、婺、明、温、台、处、衢、秀、睦等十四州，治杭州）。

## 人物识别与时间线

- **元积中**：字**子发**（李之仪《姑溪居士前集》卷41确证；古籍传抄异文作明叔、公济皆非）。杭州钱塘人。五代吴越国名相元德昭玄孙，参知政事元绛之亲侄。登景祐四年（1037）进士第。
- **人物编码**：CBDB 人物 ID **`39228`**（辨误：旧档所录 `7364` 实为曾巩之误配，本次已核实纠正）。
- 仕历时间线：
  1. 景祐四年（1037）：进士及第，调黄岩县令；
  2. 庆历四年（1044）：范仲淹荐充管勾陕西、河东机宜文字；
  3. 嘉祐初：迁屯田员外郎入朝官（胡宿撰制）；
  4. 治平初（约1064—1065）：出知楚州（“守山阳”，李之仪记）；
  5. 治平三年（1066，开局年）：除**提点两浙路刑狱公事（浙西提刑）**，主持开浚江南运河、置堰夹冈（《行水金鉴》《吴中水利全书》系于治平三年）；韦骧呈《谢宪使元郎中启》；勘查常州地下古泾函（单锷《吴中水利书》）；
  6. 治平四年（1067）六月：在杭州盐桥运河岸立石拆违规整牵路丈尺（苏轼亲睹《东坡奏议》引录）；
  7. 熙宁元年至二年：常润河道水利受累，降知宿州；
  8. 熙宁三年（1070）：在宿州知州任上奏请推行保甲法（长编卷212）；
  9. 熙宁八年（1075）：复直昭文馆，知福州、知江宁府、知洪州、知桂州。

## 核心证据

### E-SONG1066-LIANGZHE-01：清官修《行水金鉴》确证治平三年开运河
- 出处：[SRC-0071](../../../sources.md#src-0071)：清傅泽洪《行水金鉴》卷154《运河水》；明张国维《吴中水利全书》卷10。
- 核验状态：已核完整录文。
- 原文逐字摘录：“大中祥符五年两浙转运使徐奭奏置开江营兵专修吴江塘路，**治平三年浙西提刑元积中开运河**，元丰三年诏开苏州运河自苏州至杭州……”
- 可证事实：权威水利编年将元积中以浙西提刑开运河明确系于宋英宗治平三年（1066）。

### E-SONG1066-LIANGZHE-02：苏轼亲睹治平四年六月杭州盐桥运河石刻
- 出处：苏轼《东坡奏议》卷7《申三省起请开湖六条状》；南宋潜说友《咸淳临安志》卷35。
- 核验状态：已核完整录文。
- 原文逐字摘录：“盐桥运河岸上，有**治平四年提刑元积中所立石刻**，为人户屋舍侵占牵路已行除拆外，具载阔狭丈尺。今方二十余年，而两岸人户复侵占牵路……”
- 可证事实：确证元积中实任提刑驻扎杭州，治平四年六月立石公布纤道尺寸，与治平三年工程前后承接闭合。

### E-SONG1066-LIANGZHE-03：南宋《四朝国史·志》与单锷《吴中水利书》
- 出处：[SRC-0068](../../../sources.md#src-0068)：南宋《嘉定镇江志》卷12引官修《四朝国史·志》；单锷《吴中水利书》。
- 核验状态：已核完整录文。
- 原文逐字摘录：“虞部郎中胡淮与**两浙路提点刑狱元积中**再经度常润州河夹岗道置堰，功费多而卒无补……初，武进尉凌民瞻督役，**积中总其事**……”；单锷：“昔治平中，**提刑元积中**开运河，尝闻见函管……”
- 可证事实：确证元积中差遣全称为“两浙路提点刑狱”，水利总其事发生在“治平中”。

### E-SONG1066-LIANGZHE-04：李之仪记字子发与南宋会稽续志解释缺载
- 出处：李之仪《姑溪居士前集》卷41；南宋张淏《宝庆会稽续志》卷2。
- 核验状态：已核完整录文。
- 原文逐字摘录：“**治平中，钱塘元积中子发守山阳。**”；《宝庆会稽续志》：“**自绍圣以上，其姓名皆不可考，元符以后始有。**”
- 可证事实：确证元积中字子发，治平初守山阳；确证绍圣以前两浙提刑官方题名碑早佚。

## 反证与排除（9人排查）

1. **夏倚**：治平三年十月尚在四川怀安军知军任上召试，治平四年闰三月除江西运判，熙宁初始提刑两浙，排除。
2. **李惟宝**：武臣挂衔“同提点刑狱”，且连坐知杭州祖无择为熙宁初事，排除。
3. **张次山**：实为越州签判，职官错配排除。
4. **刁约**：治平元年已移知扬州、治平二至三年任京东提刑，开局已离任两浙两年，排除。
5. **施元长**：嘉祐六年任，至治平三年任期已过五年，排除。
6. **钱藻**：曾巩墓志确证一生未任提刑，排除。
7. **孙洙**：治平中出知海州旋召还馆阁礼院，未任提刑，排除。
8. **苏味道**：唐代宰相，测试性干扰项，排除。
9. **沈括**：治平三年任昭文馆编校，从未除授两浙提刑，排除。
