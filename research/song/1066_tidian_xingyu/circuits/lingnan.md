# 岭南：1066开局提刑判断

判断编号：CLM-SONG1066-LINGNAN-01。目标：1066.9.15（宋治平三年八月二十四日）。当前等级：**B**（由 C 级正式晋升）。候选：晁宗恪（字世恭，开封祥符人，曾巩岳父，首选采用）。

## 当前判断与适用范围

通过曾巩《元丰类稿》卷46《光禄少卿晁公墓志铭》、明《永乐大典》卷3141收录陈瓘《了斋集·先君行述》、清翁方纲《粤东金石略》广州药洲九曜石治平三年二月十五日题名与王安石制词对读，形成严密闭环：
1. 晁宗恪仕历时间链条严密自洽：知通州 -> 知虔州（王安石《虔州学记》证治平元年二月蔡抗权知、十月元绛接任） -> **提点广南东路刑狱公事（治平中，摄帅广州）** -> 知信州（熙宁元年1068） -> 知泉州（熙宁二年1069卒于官，享年63岁）；
2. 《了斋集·先君行述》确证晁宗恪以“提点刑狱摄帅广州”，因海舶虚惊饬备发兵，与惠州知州陈偁（治平三年修筑西湖陈公堤、班春劝农）同僚共事，将晁氏提刑摄帅牢牢锚定在治平三年（1066）春；
3. 九曜石石刻与王安石制词确证卢士宏为知广州帅臣、吕元规为转运使（边漕），文臣提刑晁宗恪遇帅臣出缺摄帅广州完全合乎宋制；文言志怪小说《青琐高议》中虚构之“赵琪”被彻底排除。

满足规范第15—16条“可靠前后锚点与明确履历有力支持”，正式由 C 级推升为 **B 级（高度可能）**。

历史口径：北宋广南东路（治韶州，巡历广州）。

## 人物识别与时间线

- **晁宗恪**：字**世恭**。开封祥符人（澶州清丰晁氏望族）。太子少保晁迥之侄，晁遘之子。女婿为曾巩（曾巩元配夫人宜兴县君晁德仪之父）。大中祥符元年（1008）— 熙宁二年（1069），享年六十三虚岁。累官朝散大夫、守光禄少卿。CBDB 人物 ID `7121`。
- 仕历时间线：
  1. 真宗仁宗朝：恩荫补将作监簿，历知常熟、兰溪，通判安州、杭州；
  2. 嘉祐末至治平元年：知通州、知虔州，治平元年受代；
  3. 治平元年至三年（1064—1066）：**提点广南东路刑狱公事，其间“摄帅广州”**；
  4. 治平三年（1066）春：海舶虚惊误传海寇，晁宗恪摄帅广州闭门饬备，惠州知州陈偁班春湖上平息谣传；
  5. 治平三年八月二十四日（1066.9.15 开局目标日）：**在任广南东路提点刑狱公事**；
  6. 熙宁元年（1068）：移知信州；
  7. 熙宁二年（1069）：移知泉州，同年卒于官，四年与夫人闾丘氏合葬江都。

## 核心证据

### E-SONG1066-LINGNAN-02：曾巩撰《光禄少卿晁公墓志铭》确证宪司仕历
- 出处：[SRC-0062](../../../sources.md#src-0062)：曾巩《元丰类稿》卷46《光禄少卿晁公墓志铭》。
- 原文逐字摘录：“公讳宗恪，字世恭。……知通州、虔州，**提点广南东路刑狱公事**，又知信州、泉州。享年六十有三，熙宁二年月某甲子卒于官……及在广南，其用法常宽，而欲人自避……铭曰：于虔于泉，于岭之南，里安户扰，罔有不咸。”
- 可证事实：确证其单向仕历序列：知虔州 -> 提刑广东 -> 知信州泉州，且卒于熙宁二年（享年63），提刑广东是其治平年间唯一的监司差遣。

### E-SONG1066-LINGNAN-03：陈瓘《了斋集·先君行述》确证提刑摄帅广州与治平三年交集
- 出处：[SRC-0063](../../../sources.md#src-0063)：明解缙等修《永乐大典》卷3141引宋陈瓘《了斋集·先君行述》。
- 原文逐字摘录：“先君行述……知惠州。州有废湖方十余里……筑堤捍江，中设斗门……缘海之民相惊，有寇自海上来且至，**提点刑狱晁宗恪摄帅广州**，疑惧不知所为，闭门饬备，发兵旁郡，两路骚动……公（陈偁）班春于湖上，民恃以不恐，既而果非寇也。”
- 可证事实：陈偁知惠州在嘉祐五年至治平三年（治平三年筑西湖陈公堤、班春劝农），直接将晁宗恪提刑广东并摄帅广州定格在治平三年春。

### E-SONG1066-LINGNAN-04：广州药洲九曜石题名与王安石制词对读
- 出处：清翁方纲《粤东金石略》；王安石《临川集》卷50《比部员外郎吕元规可驾部员外郎制》。
- 原文逐字摘录：九曜石摩崖：“士宏子高昌衡平甫元规正叔安道子适丙午仲春十五日题”；王安石制词：“尔护军、籴、将、边、漕……”
- 可证事实：治平三年二月十五日广州帅臣为卢士宏、漕臣为吕元规，晁宗恪宪司官署常设于韶州，遇帅臣出缺兼摄广州，与帅漕各司其职完全相符。

## 反证与排除

1. **赵琪**：宋·刘斧文言志怪小说《青琐高议》前集卷9《荔枝诗题》所载“治平二年广东提刑赵琪”，正史长编、登科记、方志均无其人，纯系小说托名虚构，彻底排除。
2. **吕元规**：王安石制词确证为转运使（边漕），非提刑。
3. **周敦颐**（熙宁三年始除广东提刑）、**程之才**（绍圣二年提刑）、**陈倩**（熙宁六年权提刑）均严重晚于开局，全数排除。
