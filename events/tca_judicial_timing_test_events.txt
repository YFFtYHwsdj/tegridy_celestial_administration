# 普通延迟维护场景；先触发正式排队，等待后再检查修复，避免只验证直接调用效果。
tca_judicial_timing_test.1 = {
    type = character_event
    hidden = yes
    immediate = {
        if = { limit = { has_character_flag = tca_test_delayed_case_active } debug_log = "TCA_TEST CASE_BUSY" }
        else = {
        debug_log = "TCA_TEST BEGIN tca_judicial_timing_test.1 tca_test_judicial_delayed_maintenance"
        remove_character_flag = tca_test_case_failed
        if = {
            limit = { game_start_date = 1066.9.15 title:h_china = { exists = holder holder = { is_alive = yes is_imprisoned = no is_independent_ruler = yes government_has_flag = government_is_celestial tca_external_official_names_trigger = no any_vassal_or_below = { count >= 2 is_alive = yes is_imprisoned = no government_has_flag = government_is_celestial highest_held_title_tier = tier_kingdom NOT = { tgp_is_any_minister = yes } NOT = { vassal_contract_has_flag = celestial_province_military } NOT = { vassal_contract_has_flag = celestial_province_protectorate } any_held_title = { tier = tier_kingdom is_landless_type_title = no is_noble_family_title = no OR = { exists = title_capital_county exists = holder.capital_county } } } } } }
            title:h_china.holder = { tca_test_create_judicial_law_target_effect = yes } scope:tca_test_law_target = { add_character_flag = tca_song_local_names add_character_flag = tca_song_central_names tca_request_judicial_maintenance_effect = yes tca_request_judicial_maintenance_effect = yes }
            if = {
                limit = { scope:tca_test_law_target = { has_variable = tca_judicial_maintenance_pending has_character_flag = tca_song_local_names } }
                debug_log = "TCA_TEST CHECK_PASS tca_test_judicial_delayed_maintenance 1"
            }
            else = {
                add_character_flag = tca_test_case_failed
                debug_log = "TCA_TEST CHECK_FAIL tca_test_judicial_delayed_maintenance 1"
            }
            add_character_flag = tca_test_delayed_case_active
            debug_log = "TCA_TEST WAIT tca_test_judicial_delayed_maintenance 2 days"
            trigger_event = { id = tca_judicial_timing_test.1101 days = 2 }
        }
        else = {
            debug_log = "TCA_TEST PRECONDITION_FAIL tca_test_judicial_delayed_maintenance"
            if = { limit = { has_character_flag = tca_test_suite_running } change_variable = { name = tca_test_suite_skipped add = 1 } }
            remove_character_flag = tca_test_case_failed
            remove_character_flag = tca_test_delayed_case_active
            tca_test_continue_delayed_effect = yes
        }
        }
    }

# 关闭司法的跨日场景；检查正式法律路径及后续维护没有恢复已停用机构。
tca_judicial_timing_test.2 = {
    type = character_event
    hidden = yes
    immediate = {
        if = { limit = { has_character_flag = tca_test_delayed_case_active } debug_log = "TCA_TEST CASE_BUSY" }
        else = {
        debug_log = "TCA_TEST BEGIN tca_judicial_timing_test.2 tca_test_judicial_delayed_law_disabled"
        remove_character_flag = tca_test_case_failed
        if = {
            limit = { game_start_date = 1066.9.15 title:h_china = { exists = holder holder = { is_alive = yes is_imprisoned = no is_independent_ruler = yes government_has_flag = government_is_celestial tca_external_official_names_trigger = no any_vassal_or_below = { count >= 2 is_alive = yes is_imprisoned = no government_has_flag = government_is_celestial highest_held_title_tier = tier_kingdom NOT = { tgp_is_any_minister = yes } NOT = { vassal_contract_has_flag = celestial_province_military } NOT = { vassal_contract_has_flag = celestial_province_protectorate } any_held_title = { tier = tier_kingdom is_landless_type_title = no is_noble_family_title = no OR = { exists = title_capital_county exists = holder.capital_county } } } } } }
            title:h_china.holder = { tca_test_prepare_judicial_law_realm_effect = yes }
            # 正向对照：正式改法前，收集的官职均已在任，且出现在
            # 各路原生直接 de_jure 列表中。
            if = { limit = {
                scope:tca_test_law_sovereign = {
                    any_in_list = { variable = tca_test_law_circuits count >= 2 }
                    NOT = { any_in_list = { variable = tca_test_law_circuits NOT = {
                        var:song_judicial_title = { tca_is_valid_judicial_holder_trigger = yes de_jure_liege = prev }
                        any_direct_de_jure_vassal_title = { this = prev.var:song_judicial_title }
                    } } }
                }
            } debug_log = "TCA_TEST CHECK_PASS tca_test_judicial_delayed_law_disabled 1" }
            else = { add_character_flag = tca_test_case_failed debug_log = "TCA_TEST CHECK_FAIL tca_test_judicial_delayed_law_disabled 1" }
            scope:tca_test_law_sovereign = { if = { limit = { NOT = { has_realm_law = tca_judicial_institutions_enabled_law } } add_realm_law_skip_effects = tca_judicial_institutions_enabled_law } tca_refresh_court_system_realm_effect = yes remove_variable = tca_court_system_cooldown add_realm_law = tca_judicial_institutions_disabled_law }
            # add_realm_law 后不直接维护：先测试原生法律回调，
            # 避免排队的次日回调掩盖即时缺陷。
            if = { limit = {
                scope:tca_test_law_sovereign = { NOT = { any_in_list = {
                    variable = tca_test_law_circuits
                    var:song_judicial_title = { exists = holder }
                } } }
            } debug_log = "TCA_TEST CHECK_PASS tca_test_judicial_delayed_law_disabled 3" }
            else = { add_character_flag = tca_test_case_failed debug_log = "TCA_TEST CHECK_FAIL tca_test_judicial_delayed_law_disabled 3" }
            if = { limit = {
                scope:tca_test_law_sovereign = { NOT = { any_in_list = {
                    variable = tca_test_law_circuits
                    NOT = {
                        var:song_judicial_title = { tca_test_judicial_office_detached_trigger = yes }
                        NOT = { any_direct_de_jure_vassal_title = { this = prev.var:song_judicial_title } }
                    }
                } } }
            } debug_log = "TCA_TEST CHECK_PASS tca_test_judicial_delayed_law_disabled 4" }
            else = { add_character_flag = tca_test_case_failed debug_log = "TCA_TEST CHECK_FAIL tca_test_judicial_delayed_law_disabled 4" }

            if = {
                limit = { scope:tca_test_law_sovereign = { has_realm_law = tca_judicial_institutions_disabled_law has_variable = tca_court_system_cooldown } }
                debug_log = "TCA_TEST CHECK_PASS tca_test_judicial_delayed_law_disabled 2"
            }
            else = {
                add_character_flag = tca_test_case_failed
                debug_log = "TCA_TEST CHECK_FAIL tca_test_judicial_delayed_law_disabled 2"
            }
            add_character_flag = tca_test_delayed_case_active
            debug_log = "TCA_TEST WAIT tca_test_judicial_delayed_law_disabled 1 day"
            trigger_event = { id = tca_judicial_timing_test.1201 days = 1 }
        }
        else = {
            debug_log = "TCA_TEST PRECONDITION_FAIL tca_test_judicial_delayed_law_disabled"
            if = { limit = { has_character_flag = tca_test_suite_running } change_variable = { name = tca_test_suite_skipped add = 1 } }
            remove_character_flag = tca_test_case_failed
            remove_character_flag = tca_test_delayed_case_active
            tca_test_continue_delayed_effect = yes
        }
        }
    }
}
