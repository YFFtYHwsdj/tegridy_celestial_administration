# Tegridy的天朝行政重做

CK3 天朝行政体系重做 mod。普通文官路生成动态无地提刑官职，直接沿用持有者的原版天朝文官继承法及任命类型（允许同级升迁、启用原版任命冷却）；维护自动移除旧版提刑专属法。交接后校验专职无地资格，空缺或不合格持有者由补位流程另选或生成文官，随后恢复所属路关系、名称、纹章和销毁标记。提供只读诊断与维护测试决议，另有季度/年度维护。2026-10-10 已通过本次测试存档的死亡交接、异常补位及现任稳定性核对；同级调任、保存后重载等场景仍待验证。已接入请求批准拘捕、提刑辖区拘捕与公职囚犯交接脚本；刑事模块尚待游戏内完整验收。

首个设计模块：路级提点刑狱公事，包含刑事权限、举刺官吏、领主交互和功绩任命。

设计规格：[提点刑狱公事 Spec v0.1](docs/song_judicial_title_spec.md)。

实现说明与原版/mod 写法分析：[提刑官职头衔生命周期](docs/judicial_title_lifecycle.md)。
