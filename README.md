# 国是：东京梦华

太平日久，人物繁阜。灯宵月夕，雪际花时，乞巧登高，教池游苑。八荒争凑，万国咸通。集四海之珍奇，皆归市易；会寰区之异味，悉在庖厨。花光满路，何限春游；箫鼓喧空，几家夜宴。

汴河舟楫昼夜不绝，载来江淮岁粟；天街冠盖相望，尽是赴阙的官吏与应举士子。殿前唱名，牵动士林；西北边报，朝议不宁。新法与旧制取舍，边事与民生宽严，师友渊源与门生故吏，向来难有定论。一时正论，或已更迭尽易；一地治乱，系于数人进退之间。

朝议既定，诏行州县；郡国得失，章奏上闻。有人因言得进，有人坐事远黜；有人守其所学，不肯少易；有人阅尽世变，自成一说。数十年间，法令屡更，人物代谢，朋党聚散，边境安危随之消长。身在其间者，未必知后世所谓盛衰，只知眼前尚有未毕之事，明日仍有朝会要赴、州郡要治、章疏要陈、狱讼要决。

庶几开卷，得睹当时之盛；追念回首，岂非华胥梦觉。

所以言者，为国事耳。
知我罪我，其惟春秋。

以北宋为核心的 CK3 天朝内容模组，结合历史制度与游戏机制，展现天朝的制度运作与人物故事，着重呈现北宋的政治、经济与时代变迁，让朝政取舍、地方治理与人物际遇成为可参与、有后果的游戏体验。

## 本地加载

在 CK3 启动器中将“国是：东京梦华”加入播放集并启用。本地启动器描述文件为模组目录旁的 `tegridy_celestial_administration.mod`。

游戏版本声明见 [descriptor.mod](descriptor.mod)。版本声明不代表全部机制、界面或其他模组兼容性已经验证；具体限制与验收边界由对应模块文档维护。
