# 双边和约

## 规则与取舍

两个独立国家订立长期、平等和约，不建立领主、宗主、朝贡或军事同盟关系。同一对国家仅一约，一国可有多约。双方同意可和平解除，单方退出或违约立即解约；复用原版撕毁停战的威望与威望等级损失，不另叠好感、失信或缔约惩罚。

符合北疆范围时，新约生效、协商解除、不同原因的违约和成功制止边臣会追加整体局势催化；分值、国家限次及与原版撕停战的去重统一由[局势催化](design.md#同盟和约与制止边臣)维护。普通改约、继承、付款及自动清理不重复计分，和约主体规则不依赖局势存在。

记录双方代表头衔和当前君主；正常继位继续，换主头衔不解约。继承前已经持有同级或更高主头衔的继承人视为国家合并，旧约无责失效。合并、失独立或代表头衔消失亦无责结束。继承者的旧低级国家与被继承国家若各有同一对外和约，只保留较高代表头衔的一约，较低一约无责结束，不能重复岁币。

所有CB均受约束，君主主动开战、授意出兵或加入针对缔约国的进攻方立即违约；战争上的中央授意标记只作为主攻者的授意来源，不将后来参战的第三国边臣推定为奉其本国朝廷之命；边臣自主进攻或加入进攻方先由朝廷制止。加入盟友防守方不违约。听任、边臣明确抗命或交涉超时均为制止失败并解约；后续内部处分不恢复旧约。边臣作为援军时仅移除本人，不结束第三国的战争。制止交涉合计30天未完成同样失败；遵命退援后再次主动加入同战视为再次抗命，立即毁约。

岁币是可选条款，方向独立选择，年额为0／100／250／500／1000／2000／5000。第一笔满一年支付，之后固定年度结算；修改不重置日期。有国库者始终使用国库，无国库者使用个人金币；资金不足不透支、不部分支付，欠付有一次90天宽限；拒付或超期解约受罚。修改默认仅影响未来款项，现有欠款须另行同意减免。解约一并取消未付岁币，不继续追债。

双方本人或臣属已有敌对战争时不能新签和约。新提议只接受或拒绝，不多轮还价；旧约在提议期间继续。外交区自建和约条目及条款窗口，不假装新增原生DiplomacyItem。原版原生列表没有脚本注册入口；臣属契约必带从属身份，故均不作为主数据。

## 实施接口

- `tca_treaty` story：`tca_treaty_a/b`当前君主、`tca_treaty_title_a/b`代表头衔、`tca_treaty_amount`年额、`tca_treaty_payer`付款方代表头衔（无岁币时不存在）、`tca_treaty_due`年度日期、欠款与宽限。双方人物的`tca_treaties`列表仅是索引。
- `tca_treaty_proposal` story：`tca_treaty_from/to`收发者、`tca_treaty_from_title/to_title`新约提议时主头衔／旧约保存的代表头衔、`tca_treaty_amount`、`tca_treaty_direction`（0无／1发起者付／2接收者付）、`tca_treaty_mode`（0条款／1和平解除／2免除欠款），可选`tca_treaty_existing`引用现有和约。收发者索引`tca_treaty_proposals`，同一双方至多一份待回复提案。
- `tca_treaty_send_proposal_effect`人物作用域：输入`scope:actor/recipient`与数值`scope:tca_treaty_amount/direction/mode`，可选`scope:tca_treaty_existing`；输出`scope:tca_treaty_proposal`，不立即改旧约。
- `tca_treaty_accept_effect`提案作用域，最终复核双方、旧版本及战争，成功后消费一次。`tca_treaty_break_effect = { OFFENDER = 人物 }`和约作用域，处罚并销毁；`tca_treaty_close_effect`无责销毁。
- `tca_treaty_negotiate_trigger = { ACTOR = 人物 TARGET = 人物 }`：双方独立、非同人；新签要求两国及臣属无现存敌对战争，旧约可继续协商修改或和平解除。GUI只编辑人物私有草稿，正式业务仍重验。
- `tca_treaty_dispute` story负责一场战争的一名进攻者与一份和约；战争回调只登记一次。记录`tca_treaty_parent/officer/sovereign/war`，书信调用争端effect完成停止／退出或毁约。

## 当前实施与验证

核心、战争责任及独立GUI源码已实现。资金载体、30天制止期限、签约前无敌对战争及解约取消欠款均已确认。定向自动证据与GUI未验收边界统一见[验证页](verification.md#双边和约与岁币)；不将后台事务测试等同自然年度、完整玩家操作或长期AI平衡。AI目前按性格和提案支付方向处理收到的提案，首版不自动在各国之间发起和约谈判。

上述中央授意归责是规则要求；原版“召唤参战”的`influence_war_cb`尚未接通中央来源识别，可能进入边臣自主开战的制止流程，不能视为已完整实现。具体依据与兼容缺口见[原版召唤参战](ai.md#原版召唤参战)，剩余工作归[计划页](plan.md#兼容与行为缺口)维护。
