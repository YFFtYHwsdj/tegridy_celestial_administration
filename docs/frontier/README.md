# 没有防备的北方边疆

本模块围绕宋朝及类似中原政权的边疆军事、财政与外交困境展开设计，让地方进取、中央战略、防御动员和和平经营形成相互关联的选择。

当前代码已改为整体北疆局势，包含三组参与者、相邻三阶段、年度自然缓和、战争与人物催化，以及统一结束决议。赠礼、赎回和无条件释放接入原版成功事务。1066新局自动检查并创建，统一后休止；出现合格的新独立王国级国家时自动从边衅零点重启。三阶段修正已按组配置，正式寇边尚未完成。[验证页](verification.md)分别维护已验证范围、未解决问题与人工验收边界。

## 当前方向

一项Situation覆盖原11个法理王国的固定范围，不提供子区域切换。阶段为边靖、边衅、兵争，只能相邻转换，各方向门槛1000点；边衅两向分别积累、互不抵消。自然每年增加100点缓和，不要求没有战争，不另设全面和平催化或双边阶段与点数。

参与者依次为边疆领主、境内领主、相关人物，分别按首府法理公国实际国境、本人领地（含封臣）是否涉及北疆、直属无地官署关系判断；提刑和通判使用绑定治所。定义与实施边界见玩法设计和验证页。原生直辖修正的区域裁剪、迁都后的测试组切换与显式退出清理已有独立探针证据，但名单和数值并非总是立即同步。三组均承接北疆直辖县修正，境内与相关组使用同档区域基础，边疆组使用较强合计值且独享人物修正；有地参与者自动纳入与动态分组交给原生机制，无地官署仅做必要候选补入；原版修正底层行为不另列为完成门槛。

边境战争按通用机制设计，首版仅在北疆局势范围开放；地方领主和独立君主均可具有资格。拟用“发动边境战争”人物互动、原生选择界面与自定义CB，不再以自有宣战窗口为前提。有限战争依靠占领与战斗取胜须补足持续控制目标的进度，保留俘虏领袖满分的原生例外，议和沿用原版、暂不额外考虑承诺援军；地方失地后，沿真实上级链由最高已承诺者决定追讨，拒绝按政体分组递级。完整规则与未决边界见[玩法设计](design.md#寇边入口与战争类型)。当前按[A—F实施批次](plan.md#首版正式实施批次)推进：A分数用例已通过；B原生互动、四类CB和战果事务已实现为调试候选，验证范围见[互动与战果验证](verification.md#b阶段互动与战果验证)，正常游戏未开放；C1/C2已接入调试候选，范围与人工边界见[防御支援验证](verification.md#c阶段防御承诺与延迟加入)，和平倾向调整暂缓；D失地追讨已接入独立CB与原生书信，定向验证见[追讨验证](verification.md#d阶段失地追讨)；E季度AI已接入调试候选，按既定性格、财力、战事、收益及预计援军评估劫掠或征服，实际自然宣战与书信证据见[季度AI验证](verification.md#e阶段季度ai与预计援军)；F已完成本轮定向整合，数值保持，完整战争与剩余边界见[整合验证](verification.md#f阶段定向整合与平衡)；已有P0证据仅覆盖地方主防守者、单上级延迟加入、官军集结及原型窗口等既有路径。

边臣按自身与本辖利益判断战机，皇帝按全国军力、国库、其他战场与外交关系判断是否支持，双方都考虑性格，不预设皇帝总要维持和平。

界面草图只用于讨论大致信息组织，与原版风格仍有差距；自有宣战窗口方向已由原生互动方案替代，不再默认继续打磨。草图不作为功能、视觉或游戏内显示验收。

满足全范围土地统一且独立君主处于和平时，可执行统一结束决议。休止状态记录在局势之外，原国家按代表头衔续接；独立公爵不足以重启。自动检测与开局已统一的处理见[生命周期设计](design.md#生命周期开局与兼容)。1178及旧存档迁移不在当前自动初始化支持范围。
