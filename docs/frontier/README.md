# 没有防备的北方边疆

本模块围绕宋朝及类似中原政权的边疆军事、财政与外交困境展开设计，让地方进取、中央战略、防御动员和和平经营形成相互关联的选择。

当前代码已改为整体北疆局势，包含三组参与者、相邻三阶段、年度自然缓和、战争与人物催化，以及统一结束决议。赠礼、赎回和无条件释放接入原版成功事务。1066新局自动检查并创建，统一后休止；出现合格的新独立王国级国家时自动从边衅零点重启。阶段修正与正式寇边尚未完成。[验证页](verification.md)分别维护已验证范围、未解决问题与人工验收边界。

## 当前方向

一项Situation覆盖原11个法理王国的固定范围，不提供子区域切换。阶段为边靖、边衅、兵争，只能相邻转换，各方向门槛1000点；边衅两向分别积累、互不抵消。自然每年增加100点缓和，不要求没有战争，不另设全面和平催化或双边阶段与点数。

参与者依次为边疆领主、境内领主、相关人物，按首府法理公国实际国境、首府位置、相关国家与直属官署关系判断；提刑和通判使用绑定治所。定义与实施边界见玩法设计和验证页。较弱区域修正、较强边疆人物效果仍待P2验证范围并实施。

自定义寇边采用专属人物互动与接近原版宣战窗口的自有界面，允许按局势机制配置AI评分；开战后使用原生战争、军队和结算。地方主防守者、单上级延迟加入、原生官军集结及最小窗口流程已有P0证据，完整权限、费用和战略AI仍待后续阶段。

边臣按自身与本辖利益判断战机，皇帝按全国军力、国库、其他战场与外交关系判断是否支持，双方都考虑性格，不预设皇帝总要维持和平。

界面草图只用于讨论大致信息组织，与原版风格仍有差距；视觉打磨留到GUI开发阶段。草图不作为功能、视觉或游戏内显示验收。

满足全范围土地统一且独立君主处于和平时，可执行统一结束决议。休止状态记录在局势之外，原国家按代表头衔续接；独立公爵不足以重启。自动检测与开局已统一的处理见[生命周期设计](design.md#生命周期开局与兼容)。1178及旧存档迁移不在当前自动初始化支持范围。
