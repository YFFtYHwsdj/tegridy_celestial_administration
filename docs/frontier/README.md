# 没有防备的北方边疆

本模块围绕宋朝及类似中原政权的边疆军事、财政与外交困境展开设计，让地方进取、中央战略、防御动员和和平经营形成相互关联的选择。

当前只有设计文档与界面讨论草图，尚未实现局势玩法，也未开展本模块的引擎验收。设计确定不等于接口或游戏行为已经验证。

- [原版依据与技术边界](ai.md)：宣战入口、AI评分、军力估计、原生保护政策及自有GUI的可复用部分和待验证事项。

## 当前方向

一项Situation包含北境、西陲两个独立演化的子区域，通过通好、边衅、兵争表现边境秩序。地方战争可以带来土地和功绩，也会加重经济负担并提高更大规模战争的风险。

自定义寇边采用专属人物互动与接近原版宣战窗口的自有界面，允许按局势机制配置AI评分；开战后使用原生战争、军队和结算。目标是让局势相关战争中的地方主官先承担防御，上级随后决定支援，不要求玩家先切换原版保护政策。此路径仍需P0原型确认。

边臣按自身与本辖利益判断战机，皇帝按全国军力、国库、其他战场与外交关系判断是否支持，双方都考虑性格，不预设皇帝总要维持和平。

界面草图只用于讨论大致信息组织，与原版风格仍有差距；视觉打磨留到GUI开发阶段。草图不作为功能、视觉或游戏内显示验收。
