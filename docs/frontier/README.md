# 没有防备的北方边疆

本模块围绕地方进取、朝廷责任、防御动员、外交和平与长期边防经营组织玩法。北疆Situation提供整体环境；通用防御响应／收复与独立双边和约已成为共享功能，不以北疆局势存在为前提。

## 当前启用范围

- **整体局势**：1066新局自动检查，使用一个固定北疆范围、边靖／边衅／兵争三阶段和三个互斥参与组。阶段修正、年度缓和、战争／领土／人物／交易／外交催化、统一结束与合格国家出现后的重启已有实现。1178自动初始化与旧双区域存档迁移不在当前支持范围。
- **通用防御响应与收复**：16类已登记原版争地CB正常启用。保留原生主防守者和战果，追加地区支援、承诺继承及有条件的失地收复；不是所有原版战争都改为地方主防守。
- **双边和约**：独立国家之间的长期平等和约、外交条目、单轮提案、固定岁币和违约责任已接入普通入口。监测所有CB及主动进攻援军；不形成臣属或朝贡关系。玩家GUI实际显示与完整点击仍未验收。
- **自定义有限战争**：四类县／公国劫掠和征服、战果功绩、土地去向、天朝自主开战奏报／罢兵／问责及季度出兵AI已有实现和定向证据，但玩家入口与出兵AI仍要求独立调试授权，尚未对普通游玩开放。

这些范围不能合并称为“整个局势玩法已完成”，也不能因自定义宣战关闭就说通用响应或和约同样关闭。已通过的后台、原始书信AI与保存重载不代替玩家显示、前线军队或长期平衡验收。

## 尚未实现

当前未实现内容统一由[当前工作与验收](plan.md)维护，主要包括：

- **和约与开战的衔接**：原版召唤参战的中央归责、季度AI对和约责任的判断，以及玩家开战前的完整和约后果与预计援军预览。
- **开局配置**：1066宋辽初始和约与岁币、1178专门配置；旧双区域存档迁移未实现且当前不支持。
- **共和更新后再做的边防工程**：建设、升级、维护、效果及开局设施均未实现，明确留到共和更新后设计实施，不作为现有战争／和约功能的开放前置。

玩家流程未验收、长期平衡未观察及原因未明的测试波动另见验证页，不与未实现功能混列。已取消的自建中央出兵、旧自有宣战窗口和双区域玩法不算剩余任务。

## 保留原版的军事入口

最高领主仍可按原版规则直接宣战，不额外要求委托边臣或限制亲征。原版已有“召唤参战”，故不再另做旧P5中央资助与命边臣出兵系统。原版互动的战争与和约中央责任衔接尚有兼容缺口，见[剩余工作](plan.md#兼容与行为缺口)；这不代表恢复旧P5开发。

自有宣战窗口、旧双区域局势与相应探针只保留历史技术范围，不作为当前玩法或继续打磨的默认目标。边防工程明确留到共和更新后；当前尚缺的功能与验收分别见计划和验证页。
