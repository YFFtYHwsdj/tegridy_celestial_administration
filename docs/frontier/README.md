# 没有防备的北方边疆

本模块围绕宋朝及类似中原政权的边疆军事、财政与外交困境展开设计，让地方进取、中央战略、防御动员和和平经营形成相互关联的选择。

当前已开始P0，存在仅debug开放的地方战争、双区域Situation、自然互动AI及最小自有宣战窗口原型；正式生命周期、完整寇边玩法和完整宣战GUI尚未实现。实际验收范围与未完成项见验证页，设计确定不等于接口或游戏行为已经验证。

## 当前方向

一项Situation表现整个北疆的共同环境，保留总体安定、边衅、兵争的三阶段结构，首阶段名称待定（候选“边靖”）。不同国家之间的和平与冲突不再以固定东西分区承载；正式地理外缘、双边关系载体与催化接收对象仍待议。已有双区域Situation是技术原型，不代表新设计已经实现。

参与者按边疆领主、境内领主、相关君主依次分组，最后一组只补充未进入前两组的最高领主。保留较弱的区域经济负担与军事增益，主要效果集中于边疆人物；不另设接壤土地修正，也不因君主的北疆封臣参与便影响其江南直辖。原生土地修正的区外作用范围尚待验证。具体规则统一见玩法设计。

自定义寇边采用专属人物互动与接近原版宣战窗口的自有界面，允许按局势机制配置AI评分；开战后使用原生战争、军队和结算。目标是让局势相关战争中的地方主官先承担防御，上级随后决定支援，不要求玩家先切换原版保护政策。此路径仍需P0原型确认。

边臣按自身与本辖利益判断战机，皇帝按全国军力、国库、其他战场与外交关系判断是否支持，双方都考虑性格，不预设皇帝总要维持和平。

界面草图只用于讨论大致信息组织，与原版风格仍有差距；视觉打磨留到GUI开发阶段。草图不作为功能、视觉或游戏内显示验收。
