# 通判

通判以伯爵级无地官职参与州主管的常设分权，提供治理收益并增加部分行政行动费用。本页拥有适用范围、制度和数值；它不代表全部界面、继任与保存重载已验收。

查设置对象与挂靠关系，读[设置范围与绑定](#设置范围与绑定)、[法理与实际隶属](#法理与实际隶属)；查启停，读[法律与生命周期](#法律与生命周期)；查费用和评分，读[权力分享](#权力分享)及[治理效率](#称职度使命与治理效率)。代码位置、生成资产和未解决的生命周期差异集中在[实现与验证](implementation.md)。

## 关键决策与复核条件

**当前采用：预定义官职加预留池。** 保持伯爵级和同僚隶属，以复用对象完成启停；动态伯爵接口的旧版本失败属于历史依据，见[实验结论](../history/experiments.md#动态伯爵创建与通判方案)，不是对所有新版引擎的断言。

若新版在独立最小场景中允许动态创建伯爵，再评估是否值得更换。必须同时验证绑定持久性、原生任命、退出恢复、保存重载和扩展地图；单独创建成功不足以替换当前方案。

**当前采用：原生官职继任决定人选，分权跟随实际持有人。** 窗口读取官署头衔名单，不另建称职度继任排序。名单与实际继任的差异仍有未解决项；只有明确新的任命需求并验证候选、实际授职和界面一致性后，才重新评估此分工。

## 目的与范围

通判是天朝霸权下州级的专职文官。以独立、可任命继任的无地官职参与伯爵主管的常设权力分享，提供治理效率，并通过行动费用体现行政牵制。

当前包含法律开关、官职生命周期、文官任命与补位、常设权力分享、称职度治理加成，以及免附费档和四个收费档。

不做专属审批、否决、上诉、案件、腐败资源、周期使命事件、通判主动拘捕、特权转移获利或政变。撤换权留待统一调整天朝撤销头衔互动；特殊状态优先沿用原版权力分享处理，不新建代理体系。

## 设置范围与绑定

- 仅适用于宋这类天朝霸权政权实际统治下，以伯爵领为主头衔的适用天朝主管。这里的“天朝霸权”指实际政权与领主体系，不指霸权头衔的法理范围；实际属于该政权的法理范围外领土也可适用，法理属于该霸权但不受其统治的领土不适用。
- 一名主管只为其伯爵级主头衔设置一个通判。兼持伯爵领不另设。
- 公爵及以上主管不设通判，即使兼持伯爵领；独立伯爵不设。
- 通判官职是预定义的伯爵级无地头衔。不能成为同级伯爵主管的封臣。
- 官职永久身份绑定被监督伯爵头衔，不绑定现任主管人物。
- 主管换人时保留官职对象及现任通判；依新主管资格重新同步分权。主管不再合格时按退出流程处理。

## 法理与实际隶属

法理定位始终从被监督伯爵领出发，不按其他实际领主改选公国。法理层级用于确定官署归属和寻找挂靠对象，不用于判断是否属于适用的天朝霸权政权。

1. 通判头衔的法理归属为该伯爵领的法理公国。
2. 该公国有在任主管，且不是皇帝兼持时，通判实际直属该公国主管。
3. 公国未设、空缺或由皇帝兼持时，沿法理层级寻找路级主管。
4. 路级同样未设、空缺或由皇帝兼持时，实际隶属政事堂。

实际隶属回退到路或政事堂，不把通判的法理改到回退对象下。公国或路换任时更新实际领主；绑定的伯爵辖区不随原领主转移。

原版政事堂对应`e_minister_chancellor`，实际挂靠需解析所属朝廷的有效持有者。各候选须同属实际政权且官阶高于伯爵；没有有效挂靠对象时暂缺，不建立跨国隶属。跨政权与法理重划的完整玩法仍需验收。

## 法律与生命周期

通判采用皇帝控制的最高层级法律统一启停，作为天朝霸权专属制度。不是公国主管或伯爵各自决定的开关。费用、冷却与开局默认规则参考当前提刑法律：

- 启用、关闭双向改革均花费2000威望和1000影响力。
- 改革冷却十年。使用通判独立冷却，不与提刑法律互锁。
- 1066.9.15、1178.10.1原版开局的 `h_china` 持有者默认启用通判；其他适用天朝政权默认关闭。
- 默认值仅用于开局初始化，不按年份持续重设，不覆盖玩家已经作出的法律选择。开局默认启用不等于只允许该头衔或其法理范围使用本制度。

参考：`common/laws/tca_court_system_laws.txt` 的地方司法制度法律及 [朝廷官制](../court/README.md) 的默认初始化说明。通判独立使用十年冷却，避免与提刑法律互相锁定。

### 启用与维护

- 法律启用、辖区及主管符合资格时，创建或恢复绑定官职。
- 已存在有效绑定时复用对象，不能重复生成。
- 在任通判仍合格时保留，不因没有候选继承人而轮换现任。
- 无在任者或在任者不合格时执行补位。
- 官职、主管或隶属变化后同步身份、继任法、法理、实际领主、分权者与治理加成。
- 复用现有生命周期回调和低频维护思路，不增加每日全世界扫描。

### 退出与恢复

- 法律关闭、主管主头衔改变或升迁导致不合格、辖区脱离所属天朝霸权政权的实际统治时，停止分权并 destroy 官职；不以霸权法理归属变化作为脱离判据。
- 不 delete，保留头衔本身和伯爵绑定；静态定义设置 `delete_on_destroy = no`，不能对静态对象调用仅适用于动态头衔的运行时setter。
- 恢复时重新补位，不优先恢复旧任；复用原官职对象与绑定。
- 通判死亡应正常任命继任，不因继承销毁：`set_destroy_on_succession = no`。
- 退出须清理旧主管的治理加成及通判分权状态；维护不能越过法律开关重新启用。

已销毁对象的真实法理树表现和恢复方式，参考当前提刑退役流程验证；保存了绑定或退役父引用不等于仍在生效法理树内。

## 专职资格、契约与继任

- 通判为专职无地天朝文官，以通判为主头衔。
- 除家族头衔外，不得兼持其他官职或实地头衔。
- 官职身份、功绩和个人俸禄使用[无地官员契约](../office_funding/contracts.md)；办公经费使用通判独立五档契约，由对应州国库付款。不把通判塞进中央大臣名单。
- 正常继任优先沿用原版 `celestial_appointment_succession_law` 与 `celestial_civic_governor`，保留原生功绩、候选评分、任命冷却和调任资格。
- 原版产生候选或继任结果，不等于专职条件自动成立；交接后必须校验，不合格则补位，不能强制剥夺候选人原有的其他头衔来凑资格。
- 玩家失职后的家族延续沿用天朝玩法，不能把官职继任误作玩家切换到非家族新官。

### 首次与异常补位

参考提刑补位流程，但不套用提刑的公爵级及专属筛选条件：

- 排除历史人物。
- 排除除家族头衔外已持有其他头衔的人物。
- 按适用的原版文官任命评分作为加权抽选依据，不直接取最高分，也不复制提刑专属评分。
- 品级低于提刑，沿用原版伯爵级文官最低功绩等级1（九品）；原版`APPOINTMENT_MERIT_TIER`和`merit_level_expected_county_value`已核对。此前“从九品”称法修正为原版的九品，不自行新增正从品阶。

上述历史人物排除用于首次与纠错补位；不自动扩展到原版正常继任候选池。首次／纠错权重取原版实际官职候选评分，最低为1；空池按提刑惯例生成原版学者，给予伯爵级起始功绩并分配科举经历。

### 预定义目录与预留池

- `tools/build_tongpan_catalog.py`只生成头衔资产、索引和双语名称，不生成测试或原版基线。当前原版地图含3,442个有省份的伯爵领，各自预定义一个固定官职；家族与其他无地伯爵头衔不进入目录。
- 另预留128个无地伯爵头衔。地图扩展新增且不在固定索引的伯爵领，首次需要通判时才从空闲池绑定。
- 绑定双向保存，固定官职与池官职均在destroy后永久保留给原辖区；不回收分配给另一伯爵领。地图扩展删掉辖区也不重用旧绑定。
- 池耗尽时该辖区暂缺通判并写调试日志，不调用动态伯爵创建、不抢占现有官职。增大池容量需更新资产与目录初始化迁移；旧存档已有初始化标记，仅重新加载不会补入新增池位。
- 固定官职的名称读取对应原伯爵领名称；预留官职先显示通用“通判司”，资本、纹章和法理按实际绑定辖区同步。
- 法理公国、路、政事堂候选必须与该主管同属实际政权，且官阶高于伯爵。三者均无可用持有者时暂缺，不回退直属皇帝。

## 权力分享

### 原生框架与人员同步

新建独立通判分权类型，复用原生天平与推动天平机制。关闭独立分权继任（`succession = no`），避免再由分权候选池产生另一套接替人选。分权窗口直接读取被监督州绑定通判司头衔的`Title.GetLineOfSuccession`，按原生顺序显示前四名，采用原版分权继任栏的头像、忠诚度图标和天平评分样式，不另加编号或按钮。评分只展示原生官职任命分数，不用于重新排序。名单不另行评分、不缓存、不按继承法分支；继承法及原生任命变动由引擎计算，界面只读取结果。官职交接后的原生回调继续触发维护，将分权者同步为实际合格官职持有者；候选不符合任职资格时仍沿用现有资格校验与纠错补位。其他分权使用原版候选列表。

原生评分只传入候选角色，没有被监督州主管的参数；因此不把某一州的头衔前四顺位加分搬到所有州。已绑定在任者的1000分也不区分正在查看的州，最终身份以官职绑定和同步为准。GUI候选可见性、同僚候选池及旧存档表现需实机验收。

法律启用且双方合格时维持常设分权。缺失或人员不符时修复，正常状态不反复重启，不无故重置天平、任期。特殊状态先沿用原生规则，并验证实际直属领主与被监督主管不同的影响。

不直接使用 `grand_secretariat`：其中央使命、朋党、门生、任期影响力收益、中央继任加权、免职条件及中国霸权检查不适合直接继承。

### 通判侧界面入口

通判使用接入原版右下角自动排列队列的圆形天平按钮，明确打开绑定知州的原生权力分享窗口，圆环与档位读取同一知州。保留同僚隶属；覆盖`gui/hud.gui`插入入口，并覆盖`gui/window_diarchy.gui`提供玩家自身、直属领主、所辅佐知州三个关系标签。与其他替换这两个GUI文件的模组冲突。只对当前合格且已同步的通判显示，知州继续使用原生入口；具体位置与实际操作权限须实机验收。

### 档位与行动费用

天平向40回归。界面设0／20／40／60／80五个档位，0档对应免附费；以下为所在区间的最终附加费用，叠加原行动费用，四个收费档之间不累加：

- 低于20：0威望、0影响力。
- 20至不足40：25威望、10影响力。
- 40至不足60：50威望、20影响力。
- 60至不足80：100威望、40影响力。
- 80及以上：150威望、60影响力。

第一版对拘捕、处决、撤销头衔、收回封臣共用这组值。没有另设合法理由免除附加费的规则。天平达到高档只增加费用，不开放其他权限。

费用承担者是被监督的伯爵主管，不是通判的实际直属上级。应覆盖玩家与AI实际发送、费用可支付检查及正式结算；取消、无效或未发送不得产生额外扣款，同一行为不能被原生费用及适配重复收取。对现有模组司法入口，要核对能由该伯爵发起的对应行动，避免只改不可用的原版入口。

原版相应附加费用主要是威望，影响力不能直接借用另一套否决惩罚。实现需核对各费用入口，尽量复用；新增同名覆盖或追加定义须登记并保存已审阅基线。

这些费用体现行政牵制，不宣称实现了共同签署、通判批准或否决。

### 官员忠诚度

通判使用官员模型，评分为`60＋性格修正＋对被监督州主管的好感×0.25`，最终限制在0至100。好感最多影响±25分，实际直属上级的好感和关系不参与。人格是主要差异来源，不再照搬摄政的文化、宫廷职位、恐怖值和牵制等整套评分。

- 公正、诚实各+20；安于现状+15；谦卑、勤勉各+10；忠诚+30。
- 专断、狡诈、贪婪各−20；野心勃勃−25；傲慢、懒惰各−10；不忠−30。
- 保留原生显示门槛：75及以上“无私”，25及以下“自利”，中间“中立”。无相关性格且好感为0时60分；公正且诚实者100分；贪婪、野心勃勃且狡诈者0分。

## 称职度、使命与治理效率

第一版只设一个“协理州政”使命，不做使命切换、进度、奖励事件池。使命浮窗沿用原版效果列表，显示当前治理效率增量及指令称职度；静态使命描述说明每10点称职度增加5个百分点、上限50个百分点。行政附费提示使用“领主进行行政行动时额外支付……”并显示两种资源及图标，不再称“世俗行动”。使命资质与治理加成采用同一个称职度依据，避免界面评分与实际收益脱节。

参考原版使命称职度的“主要能力＋次要能力＋性格修正”结构，当前数值如下：

`称职度 = 管理×2＋外交＋学识＋军事×0.5＋谋略×0.5＋教育等级加分＋性格修正`，最终限制在0至100。

- 五类能力教育同级同分：一级+2、二级+4、三级+6、四级+8、五级+10，无教育特质为0。直接复用原版教育等级判定；异常多教育只取最高等级，不叠加，武艺教育不计入。教育本身的能力加成仍通过五维自然计入。
- 勤勉：+10；公正：+10。
- 懒惰：−10；专断：−10。
- 每点称职度使被监督主管的原生治理效率增加0.5个百分点，上限50个百分点。

例：管理15、外交10、学识15、军事8、谋略6、三级教育且公正，称职度78，治理效率增加39个百分点。这不是直辖税收直接增加39%。

加成不随天平改变；政治权力与治理能力分开。停用、换任、脱离或不再合格时更新或移除，不残留、不重复叠加。能力或性格变化后的刷新方式及时间须在实现文档明确。

不额外赋予宰相式影响力收入、朋党力量、门生或任期增长收益。个人俸禄沿用原版，办公经费复用[官署经费模块](../office_funding/README.md)，不另建第二套转账；实际入账及验收边界见该模块文档。

## 财政及派系讨论的边界

启用动机以治理效率收益为基础，成本为官员待遇与主管行动花费。财政余款去向、各层国库流转尚未做受控实验，不能将税率未达100%的余额定义为贪污，也不能把治理效率10个百分点等同于皇帝国库收入增加10%。

不增加通判对皇帝派系的直接减益：普通路以下非直属封臣没有据此越级加入皇帝派系的资格。此前讨论的额外税收、发展金压缩、派系贡献折扣均不属于第一版。
