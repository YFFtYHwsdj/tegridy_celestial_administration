# 中央、地方官名与独立司法制度

## 当前实现

官名与司法制度分为三个独立法律组。中央、地方官制均只有因便与宋制，纯名称选择各花费200威望，无影响力费用、无改名冷却、无数值修正。因便沿用原版。辖区名称不变，女性实际任官与男性同名，配偶称号不使用本次任官覆盖。

地方司法制度单独提供地方主官兼理／设立提刑监司。改革双向花费2000威望和1000影响力，冷却十年。关闭时撤销提刑任职并关闭本模组地方、中央司法审批，普通拘捕回到原有规则；启用时恢复原有机构创建、任命与审批。两组名称选择不改变司法制度。

## 宋式职名

中央：实际丞相头衔持有者称号显示同平章事，实际御史大夫头衔持有者称号显示御史中丞。内阁卡片及首辅控制法律沿用原版或外部模组名称，允许与角色称号不一致；单独加载时仍可能显示宰相、御史大夫。原版六部尚书、枢密使及独立的大将军职位保留。只改变角色称号，不改职责、任务、任命和权限。

地方：

- 王国级文官转运使，军制经略安抚使。
- 公爵级文官统一转运副使，军制兵马钤辖，不要求上面有对应正使。是否按资序把资浅者改称转运判官仍在评估，实现草案与待定选项见[公爵级文官称号按资序分等](duchy_naming.md)（未采用）。
- 伯爵级按原版天朝契约分类：州制知州、府制知府、监制知监、军制知军。
- 男爵级知县。
- 都护府、独立统治者、家族、专门无地官职不套用普通地方名称；提刑仍显示提点刑狱公事。

分类直接使用 celestial_province_standard/metropolitan/industrial/military。原版简中 government_l_simp_chinese.yml:708 起已分别将它们称为州、府、监、军，并非本模组另造分类。

## 外部名称管理

只检测 `orient_empires_loaded`、`hanfan_loaded` 全局加载标记；不引用可选模组的法律标记，避免缺失定义导致加载错误。任一加载标记成立，隐藏本模组两组名称法律，并移除普通官名替换的角色标记；不调用可选模组对象，不改写外部法律，也不重复其数值修正。独立司法法律继续有效。

加载标记可能留在移除了外部模组的旧存档中，因此目前不能把该检测视为可靠的卸载识别。这样的旧档仍可能退出本模组名称管理；需在实际组合测试后制定清理方案。外部初始化、GUI及角色名称缓存的更新时机也须组合加载验收。

角色称号通过独立 flavorization 匹配 e_minister_chancellor、e_minister_censor 官职头衔，优先级510，高于原版同官职规则的500；仅实际持有者使用，不改变配偶称号。中央宋制标记失效时回到原版或外部角色称号规则。

不为统一中央卡片和角色称号而覆盖原版内阁对象、内阁名称键或首辅法律名称；保留不同界面名称不完全一致的边界。称号按实际官职头衔匹配，不能按内阁席位给兼任的知州误套中央职名。其他模块的契约、任命和拘捕覆盖仍需独立审阅；组合兼容与旧存档加载标记清理仍待验收。

## 默认与旧存档迁移

法律分离、名称标记及迁移由 `events/tests/tca_court_test_events.txt` 的原生事件覆盖；以实际模块登记和冻结运行计划为准。

1066.9.15、1178.10.1 原版开局的 h_china 持有者默认两组宋式名称并设提刑；其他天朝政权默认两组因便并由地方主官兼理。只用于初始化，不按年份持续重设。

保留旧唐／宋法律标识及隐藏法律组，用于旧档解析。每位最高领主首次维护时：旧宋制映射为两组宋制和启用司法制度，旧唐制映射为两组因便和关闭司法制度，然后移除旧法并记录迁移标记。旧司法改革冷却沿用原变量。各路局部废置变量不清除。初版旧法律是否会在加载阶段提前失效、继承后法律保留情况及外部接管时隐藏法律的保存行为均待引擎验证。

## 维护与交接

改制回调以 hidden_effect 隐藏内部遍历。司法制度法律在原生 `on_after_pass`（法律替换后）立即维护本国角色、辖区和提刑，次日再次维护；`on_pass` 仅设置十年冷却。其他官名法律沿用其现有回调。已有季度、年度、头衔、政体及领主变化回调负责更新角色名称标记。

关闭司法制度时，沿用现有退任流程：先将登记的公职囚犯交给现任路主官并清除登记，再撤销提刑任职；保留机构对象和双向路绑定。重新启用时复用原ID。待审批和战后捕获重新检查独立司法法律，失效请求应取消而非继续拘捕或施加否决惩罚。

## 验证与待验收

自动测试通过[统一入口](../testing/README.md)选择 `court` 模块；模块名称先用 `--list` 核对。脚本添加法律验证回调，不证明玩家在法律界面的费用与交互已验收。

专用测试局依次检查：

1. 867／1066／1178默认选择；分别切换中央、地方名称，其他法律不联动。
2. 实际中央官职持有者与兼任内阁席位的知州分别显示正确称号；男女任官同名，配偶不套用任官称号。
3. 因便名称下启用司法、宋式名称下关闭司法，机构状态只服从司法法；法律窗口的名称、说明与费用正常。
4. 原制度存档迁移、君主继承与保存重载；与外部官名模组组合加载、移除后的标记残留另验。

已有官制断言及早期截图反馈不替代上述显示验收。司法启停、囚犯交接与同日法理变化由[司法模块](../judicial/README.md)维护，避免在两处维护同一套结果。
