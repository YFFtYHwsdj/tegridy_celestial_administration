# 国子监 GUI 方向与接线说明

本页描述最终可见功能和建议实现方向，不创建界面代码或原型。布局尺寸、资产及具体按钮尚未获最终确认；核心入口与使用者范围已确定。

## 玩家会看到什么

### 皇帝内阁中的中央官署

在三省六部所在的可滚动内容底部增加“中央官署”标题，首个官署为国子监。卡片显示判国子监事头像、姓名、官署名、头衔入口和国库摘要，空缺时明确显示空缺。点击“查看国子监”打开独立窗口，不在内阁继续折叠展开学生详情。

这是官署卡片，不要强制把判监变成原版六部中的一个固定职位。人物头像左键可看人物，右键正常菜单；任免仍调用合法的原有官职任命入口，卡片不偷偷直接授衔。

### HUD圆形入口

已有HUD允许放置圆形图标。建议同国学校存在且玩家有可查看关系时显示：判监、在籍学生、有在籍孩子或教育安排关系者、皇帝；其他同国人物是否也可浏览，作为可选范围待确认。

鼠标悬停只写“国子监”和必要状态，不塞入计算公式。学校空缺仍能打开，显示教学暂停；不能因为无判监导致学生无法查看自己的学籍。

### 独立窗口

建议上方是官署概况，中部为师资，下方或单独页签为可滚动监生名单。首版可用“概况／监生”两个页签，打开时判监默认监生、学生与家长定位本人／孩子；不要做必须逐层点击才能看到完整名单的学校经营界面。

概况包括：当前判监与官署国库；教学正常／空缺暂停；已开放学科及在任直讲；监丞／主簿头像；现行法律摘要。未开放教职显示未设，已开放无人显示空缺，区别于低适性教师。

监生一行建议包括：头像、姓名、年龄、在学时长、教育方向、当前教育等级、乡试／会试／殿试真实资格、居监／世族非迁宫。家世标签可选，不展示内部事务编号、随机种子或原生超时大数。

点选学生后可展示所属学校、专业与当前教师、儒家／武艺培养适用情况、本期最近收益摘要。上限说明用“学校已无法进一步提升这项修养”等简短语句，不把全部概率写进人物列表。没有学生的空态显示暂无监生，不生成假行。

列表筛选建议仅姓名、成年／未成年、教育方向、居监／非迁宫。排序按姓名／入学时间即可，不做总分排名或毕业评价。实际左右布局与尺寸以后制作时再验收。

## 少量操作与权限

- 判监可从窗口进入访求生徒、访求名师、原生教职任用；学生右键打开现有互动。窗口中的“录取”如存在，必须走正式申请／同意事务。
- 成年学生可退学；有教育安排权者可以为儿童提出退学。按钮使用与人物互动相同的trigger和effect，避免按钮允许、互动拒绝。
- 皇帝无需额外经营按钮，通过国家法律改变制度；可以查看，不在此窗口多造一套“直接通过改革”效果。
- 家长／学生可以查看不代表可以替判监解聘教师、扣国库或直接改法。头像右键菜单仍由原版权限决定。
- 窗口不用于课程选择、分配教师、逐季领取奖励或开关每名学生的训练；教学自动结算。

具体信息公开范围与谁可以看到其他孩子的详细信息尚待确认；首版建议同窗口共享公开名册，个人细节和操作仍按权限。这是建议，不是额外隐私系统。

## 已有源码可以怎样借鉴

本仓库可点击参考：

- [统计独立窗口](../../gui/tca_confucian_statistics.gui)：独立 `window`、滚动列表、`Scope` 数据和脚本GUI按钮。
- [独立窗口登记](../../gui/scripted_widgets/tca_confucian_statistics_widgets.txt)：如何注册窗口，避免仅创建 `.gui` 却从未实例化。
- [脚本GUI](../../common/scripted_guis/tca_confucian_statistics_guis.txt)：`is_shown`／`is_valid`／`effect` 的分工和显式scope传入。
- [已有HUD](../../gui/hud.gui)：`tca_tongpan_hud_button` 演示圆形入口的当前布局、可见条件和目标上下文；它打开通判分权窗口，学校不能照抄其 `GetDiarchy` 目标。

原版 `game/gui/window_council.gui` 的 ministry 部分已有滚动容器，具体席位通过 `CouncilWindow.GetCouncillor(...)` 固定枚举。新增学校不是往一个通用“所有中央官员列表”注册就自动出现。

建议在末尾追加独立的官署卡片模板，数据由当前内阁所属国家解析到学校头衔与持有人，避免写死 `GetPlayer` 等于皇帝。`CouncilWindow` 目标可能是正在查看的人物，而本地玩家另有身份，需分别处理。

原版人物头像模板通常自带点击和右键行为。先找当前人物列表实际使用的模板再复用；不要只画一张贴图，然后自己猜右键函数。没有持有人或人物死亡时头像安全退为空态。

## 建议的文件与作用域

拟新增：`gui/tca_guozijian.gui`、`gui/scripted_widgets/tca_guozijian_widgets.txt`、`common/scripted_guis/tca_guozijian_gui.txt`，配合独立卡片／行模板。HUD在已有覆盖基础上增入口；内阁文件若无可追加布局钩子，才作必要最小对象／文件适配并登记基线，不能因已经覆盖HUD就声称内阁无需兼容审阅。

打开窗口时显式记录“本地查看者”和“目标学校”，学校详情通过头衔读当前判监，学生行再建立目标人物上下文。按钮脚本以真实执行者为root，学校和学生作为显式scope；不可在学生行误把学生当作扣款判监。

展示数据可直接读取学籍名单，复杂统计由正式维护缓存；不在每帧遍历全国、不在悬停时发经验。需要刷新时只刷新显示缓存，绝不能调用季度结算冒充刷新。

窗口打开标记按本地UI机制优先；若沿用玩家变量方式，须明确其是否持久、多人游戏各自查看是否互相影响，不能把查看动作变成学校全局状态。静态参考只能证明已有写法，不证明新窗口的多人或保存行为。

## 关闭与失效情况

- 判监换任：学校目标不变，头像／教职在正式交接后刷新，不跳到旧判监宫廷。
- 学生离学：列表移除、本人摘要转已离学或关闭对应细节；不能因窗口仍开就继续教学。
- 官署销毁：关闭目标或展示不存在的空态，不对无效头衔取 `.holder`。
- 观察者、主菜单、无玩家、切换角色、HUD隐藏时分别检查安全可见条件。

实际布局、缩放、长中文／英文、头像右键、非迁宫学生定位、按钮权限、空缺和保存重载，均须未来实现后验收；本次不制作GUI或探针。
