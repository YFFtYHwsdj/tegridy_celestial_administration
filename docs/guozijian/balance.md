# 国子监首版参数草案

本页是所有学校数值的唯一维护位置。**除了明确标为“已确认规则”的年龄和冷却，以下新增费用、概率、经验、限额、评分、薪俸及适性公式均为建议初版、待用户确认，不是最终平衡，也没有游戏实测。** 接手者可以据此估算、集中配置参数，但不能将其称为已获确认或已验收。完整算法见[教育机制](education.md)，实施约束见[接手说明](implementation.md)。

数值应集中到拟新增的 `common/script_values/tca_guozijian_values.txt`；不要把本页变成 Python 业务规则副本，也不要在事件里四处写常数。公式只表达设计，能否使用相应脚本运算必须查原版接口。

## 统一单位

- 已确认：6至25岁可申请，30岁离学；已实际进入当届会试／殿试者等本届结束，不能凭可能参加未来考试无限延期。
- 时间草案：90个有效培养日为一个教学单位，360日为四个教学单位；只是计算单位，不声称 CK3 一年恰好360日。校龄按日期／实际经过日数计算，不混用日历生日与360日配额。
- 已确认：四项教学改革共享五年改法冷却；游戏的 `years` 时间参数沿用原生定义，不手工换为360日。
- 计量单位建议为90个有效教学日，区别于原生季度脉冲日期；下文“四单位”是360有效日的比较口径，不声称任意日历年必定恰好四次。
- Q为教师的教学系数，按原生五档适性暂取0.50、0.75、1.00、1.25、1.50。无有效教师为0，不以判监默认替代教师。
- 对口教师缺位：取允许代课者中最高有效适性，系数再乘0.50；对口教师即使适性低也优先，不挑满校教师的最高分反向架空专职。代课者不包含监丞、主簿；武艺不接受文科代课。
- 下文概率均为Q=1、一个完整教学单位的概率。乘时间权重和其他系数后截断至0至100%，不是随机权重直接当百分比。

## 朝臣预算与判监契约

用户已确定国子监是正常无地朝臣官署，取朝臣预算，另写国子监契约，不照搬三省六部。建议初版独立职务契约提供朝臣预算基数系数0.25、判监每月固定Merit 5；二者仅在实际持判监官署时有效，排除同领取普通大臣职务待遇。

系数0.25表示相对原生朝臣预算权重／基数，不是直接拿皇帝总预算25%，也不是固定每月0.25国库。个人俸禄另沿正常官品薪俸，不从这份固定Merit推导。首版不另设学校预算法律，不自建资金托管和离任全额转账。新契约的原生预算收入与排他资格须未来集成验收。

## 招生、访求与AI

### 收费

- 每次实际录取扣判监国库30。申请发送、拒绝、失效不扣钱；不从家长或学生收钱。
- 监丞减费按适性五档为5%、10%、15%、20%、25%。实际费用为基础费用乘剩余比例；向上取整为国库整数，最低1。
- 正常录取后不退还费用；入学处理尚未成功且费用已暂扣，应精确退回这次实际支付额，不退教师薪资等无关款项。
- 访求生徒每年一次，暂收判监10威望，不另收国库；展示至多5名真实候选供选择，接受录取仍付正常招生费。没有合格人选也不生成天才填池。
- 访求名师每年一次，暂收判监20威望，返回至多3名真实合格人选。邀请／迁入仍须正常同意；不会直接任命或保证接受。

### AI运行节奏

- 判监季度至多主动邀请2名学生，所有资格、同意与付款仍逐人复核；这是一次批次工作量，不是学校学额。
- 邀请前国库建议保留所有现任教职未来12个月薪资，加本次招生费；主动搜索不必等同审批一份已经收到的申请。
- 无在任直讲时AI暂不主动扩招。玩家可以在教学暂停提示下自行申请／录取，但不能凭空获得教学收益。
- 申请／候选评分草案：起点0；最高先天聪慧档分别+5／+10／+15；专业适合的能力达到10为+5、达到15改为+10；判监与学生好感每10点折算1分，限制在-10至+10；朋友+5、仇敌-15；成年学识达到10再+5。聪慧只取最高档，能力阈值不累加。
- 审批分数达到10且财力有效时AI接受；有家世不额外保证录取，不排除低出身。儿童用当前教育重心对应能力，无重心时不凭空给专业能力分。
- 家长／本人接受主动招收的意愿草案：基础+10；判监好感项同上；已有优秀正式监护人-10；幼儿年龄不足10岁-5；学生没有合适教育支持+10；战争／旅行不可用时直接暂不能接受，不靠高分绕过硬条件。
- 候选搜索按学校所属政权登记范围批量收集，不每个监生每季度扫描全国。分数只用于学校录取，不加到考试成绩或任官分。

## 教职资格、适性与薪俸

以下是实施初值，不是历史官阶断言。判监正式任命继续走现有官员体系，不用教职资格冒充官署任命。

### 直讲

- 建议成年、至少25岁、无实际正式官职、非在籍监生、非囚犯、非无能；普通廷臣与仅持世族者是否能经原生界面任用，须静态核对并保留游戏验证。
- 经义／治事／辞令／兵学／察事的相关能力至少12，且学识至少8；武艺勇武至少15、军事至少8；儒学学识至少12且儒家经验至少20。
- 单人不兼任两个直讲，也不兼任本校行政职位，避免用同一个高适性人物填满全校；这是未确认的兼任草案，不是额外教学容量。
- 五科直讲适性草案：相关能力每点3分、最高60分；学识每点1分、最高20分；对应教育等级每级3分、最高15分；相关可培养特质存在加5分；合计截断至100。经义相关能力与学识两项有意同时取学识，但各自封顶。
- 儒学适性：学识每点2分最高40，儒家经验每点0.5分最高50，耐心／勤勉各5，合计最高100。
- 武艺适性：勇武每点2分最高60，军事每点1分最高20，剑术最高经验每点0.1分最高10，竞技三条武艺轨道的最高经验每点0.1分最高10；智慧轨道不计。无特质不扣固定分。
- 五档分界沿用原生20／40／60／80：低于20、20至不足40、40至不足60、60至不足80、80以上。实际原生适性等级数值映射需核对，不能误把1至5档当作引擎枚举。
- 薪资草案：儒学／经义用 `medium_court_position_salary`，其余直讲用同公式；不另收按学生人头费用。支出为判监国库，教师实收个人金币，薪资威望项沿用匹配级别原生公式。不能把原公式基数0.25解释为所有人在所有时代实付0.25。
- 固定功绩草案：每位直讲每月0.25 Merit；使用职位本身的雇员 `modifier`，原版天朝职位已有 `monthly_merit` 依据，不另建季度学校成果分成；实际到账与品级归一化仍待后续验证。

### 行政属官

- 监丞、主簿建议成年且至少20岁，管理至少10、学识至少8；其他底线同直讲。
- 适性：管理每点3分最高60，学识每点2分最高40。主簿后续可调整权重，但首版先共用。
- 薪资草案：原生 `minor_court_position_salary`，国库支出／个人金币实收，匹配原生威望薪资。两职每月固定0.10 Merit。
- 主簿首版不提高考试录取率，不增加学额；其作用先体现为资格整理、失效学籍通知与办学事件发言人，不为凑数再加一项隐形收益。
- 判监固定功绩统一按本页朝臣预算与判监契约节维护；必须核对现有官员契约的赋值方式，不能与普通大臣或其他契约重复领取。个人俸禄继续随实际官品的原生薪俸，不另发学校工资。

## 儿童隐藏分

- 建议6岁起计，16岁后停止。无合法教育重心时不发隐藏分，不强制替玩家选重心。
- 每完整单位累积0.20×Q隐藏分，学校终身累计最多6点，跨重心合并封顶，不是每个方向各6点。
- 原版接口若只适合整数：学校先存小数余额，累计到1才向当时方向调用正式加分效果；小于1的余额保留，不每季向下取整丢失，也不提前发1点。
- 变更重心前将已产生的整数余额结到旧方向；方向归属要单独记，不能把多年旧科余额全部转给刚换的新科。
- Q=1完整四单位期望0.8分；Q=1.5为1.2分。10个360日的常态培养理论8分，但被终身6分限制；其他教育来源不扣学校账。
- 该草案只约束学校额外分。原版半年度教育成功分支已有+2，宫廷教师另有+2／+3／+4等分支；调用时机与全过程结果仍不能仅凭这些片段推算为“学校与优秀宫廷教师完全等效”。若用户希望学校更强，先调总培养而非盲目倍增隐藏分。

## 成年生活方式与教育升级

- 正常成年每单位提供对应方向25×Q生活方式经验；Q=1四单位100经验，优秀教师150经验。不改变角色当前生活方式重心，不直接授予perk。
- 儒学不额外给一份学识生活方式经验，避免公共儒家培养又暗中重复专业经验。
- 成年教育升级首次要求累计720个有效成年培养日，此后每累计360日最多尝试一次；失败也消耗本次检查，不在下季度连续重抽。
- 1升2概率20%，2升3为12%，3升4为6%，4升5为2%，乘Q后最高30%。成功只升一级，保留专业；缺少教育特质作为必须处理的边界：跳过专业经验与升级，不由学校凭空生成首个专业，也不中断整校结算。
- Q=1下，已经满足首次门槛后连续三次4升5的成功率约5.88%，不是每季度2%。教学不能保证五级。
- 学生从童年转成年时，成年培养日从实际成年日开始，不能把童年年限直接充抵720日。

## 直接能力成长

- 建议外交、军事、管理、谋略、学识各单项学校直增最多3，勇武最多4，六项合计最多10。所有年纪、学校任期和再次入学共用终身额度。
- 每单位先在有效五科里抽一个能力，再以8%×该候选教学暴露系数×能力递减系数判定，最多+1；总限额满则不抽。不能先滚8%再乘一个可大于1的递减系数。对口方向权重5，其他已开且有教师／有效代课的方向各1；未开放学科首版不进入低权重成长池。
- 若对口学科尚未开放，其他有效学科仍可作通识候选，各权重1；不把缺课视作自动改教育重心。五科全无教师则不抽取。
- 拟采用能力递减：所选能力低于8乘1.5，8至不足12乘1，12至不足16乘0.6，16至不足20乘0.3，20以上乘0.1。该系数作用于此次候选能力的最终成功率，不再二次抽别项补中。
- 同季度武艺另检查勇武：基础6%×武艺Q×方向参与系数，再乘同样能力递减，最多+1；它与五科成长共用总额度，先五科后武艺。只剩1点总额度时不能两边各发1。
- 非军事方向参加武艺暂要求军事≥10且勇武≥10，参与系数0.25；军事方向系数1，不设入门能力门槛。教师缺位武艺Q=0。
- 例：Q=1、所选能力10时，五科完整四单位期望约0.32点；同能力18时约0.096点。十年累计也不等于自动取得10点上限。勇武10的军事学生每四单位期望0.24点，非军事合格学生约0.06点。这里是忽略数值变化的静态期望，不是游戏实测。

## 儒家培养

- 候选方案：未成年不直接授成人儒家特质，存儿童儒学培养；累计360有效培养日后可在成年时取得特质，儿童储备最多20经验。该年龄接入方案仍须用户确认。
- 儿童每单位储备1.5×儒学Q经验，Q=1四单位6，最低6岁入学到成年足以触及20上限，不会在儿童阶段堆到60。
- 成年首次获得要求累计360有效儒学培养日，授特质初始0经验，不能既免费起始20又同时领取儿童储备；有儿童储备时在成年入口转入至其上限，之后正常累计。
- 成年当前经验不足20，每单位+1.5×Q；20至不足40为+0.75×Q；40至不足60为+0.375×Q；学校停止于60。发放跨阈值时截断至下一阈值，本期余量不按旧高速率冲入下一档。
- 儒学缺位的代课Q已含0.50折扣，不再重复减半。没有任何有效直讲，不增加儒家储备或经验。
- 成人Q=1完整四单位各段增长约6／3／1.5；从20到40约需6.7个360日，从40到60还需约13.3个，不能把20到60解释为每个成年学生都能在30岁前完成。
- 其他来源达到60以上不回退；学校累计贡献不是把人物总经验锁死。

## 学者、诗人与武艺特质

### 共通

- 首次取得均须成年，并累计对应有效培养至少720日；强壮要求1440日。儿童仍可获得基础成长，不提前授予这一组成人特殊成果。
- 每个单位最多进行一次“新特质”检查：先从符合条件且尚未拥有的候选按权重抽一种，再滚该特质成功率；失败不补抽。避免同时滚五种概率抬高总体。
- 暂不加“终身只能学两种”的跨特质总限制，以低概率、年限和各自经验上限控制；此为待用户确认的简化建议。
- 教师本人没有特质也可教；拥有相应特质时首次获得概率与经验量乘1.25，教师相关经验≥50改乘1.50，只取一个档。竞技选手取此次增长轨道教师经验，不读智慧轨道替代。无相应经验的强壮存在只给1.25。
- 特质授予要求原版合法，检查互斥、年龄和已持有；失败不删其他特质。学校不移除人格或先天特质为它腾位置。

### 学者与诗人

- 经义对学者为主，治事提供半效代课；辞令对诗人为主，经义提供半效代课。别科不自动教授这两个特质。这里的代课范围是特质教学，区别于五科基础教学的通用代课。
- 新特质抽选权重：学者3、诗人2；命中后首次获得概率分别2%×Q与1.5%×Q。
- 已有且经验不足50者每单位基础+0.5×Q；到20之后乘0.5，到40之后乘0.25，停止于50。对应教师拥有特质的加成另算，单次跨界截断。
- 每单位已有经验特质最多选一项推进：学者权重3、诗人2、剑术3×武艺参与系数、竞技选手整体3×武艺参与系数。先排除不合格／满额项，再抽特质；竞技作为一项选中后，再从三条未满有效轨道按各1抽轨道，不让竞技因为三轨获得三倍份额。之后只发所选项经验，不同时给其余项。

### 武艺

- 新特质抽选权重：剑术3、竞技选手3、强壮1；武艺方向折扣只在成功率乘参与系数，首次抽选不再重复折扣。无武艺教师完全不参与。
- 首次取得剑术与竞技选手各为2%×Q×参与系数；强壮为0.2%×Q×参与系数。强壮不是每季度对全校都滚0.2%。
- 剑术经验基础每单位+0.5×Q；20后减半、40后减为四分之一，学校止于49，避免学校直接培养到50节点的正式剑术大师层次。
- 竞技三轨每次只抽一条，步战／骑术／弓箭权重各1；每单位基础+0.5×Q，20后减半；各轨止于30，智慧不发。已有某轨满额即从候选里排除，不把该次余额转为智慧。
- 军事方向的武艺新特质与经验均按系数1，其他合格方向按0.25。强壮只授一次，不发“强壮经验”。
- 特质本身会附带勇武、健康等属性；不消耗直接属性额度，但必须计入总体平衡，不因没扣直增额度而忽视总增益。

## 功绩、改革与冷却

### 成果功绩初值

- 最低培养：教育成年／升级奖励须累计360有效日；考试成果也须累计360有效日，避免临时收生。达不到不延后补发同一既成成果，不影响学生自身成绩。
- 成年首次取得四级教育+3、五级+5，只发其一；成年升级至4级+2、升至5级+3，低级升级先不发判监额外功绩。
- 若先在校成年四级领+3，再在校升五级，可另领五级升级+3；同一五级升级不再领“成年五级+5”。各具体成果终身防重。
- 会试+6、殿试+6、三甲额外+3，学校不奖励乡试。学生同届三项都符合可合计15；不把每个三甲学生加分再重复记成合并事件奖励。

### 改法

## 有效培养日与重入的统一口径

建议所有已完成有效培养日、未消费的小额余额、未消费教学单位与终身限额跨退学保留；离学期间不积累，重新入学接着尚未消费的进度，不重新发“首次取得”包。成年升级等待、特质首次取得、强壮门槛、儒家首次取得都按相应渠道的终身有效培养日，不要求连续在籍；只有实际有合格教学来源的渠道才累积其有效日。

每次新学籍的入学日期用于显示本次在学时间，不能代替上述终身培养日；过去已经消费的升级尝试／随机单位不因重新入学恢复。判监成果最低培养时间也按本校实际有效培养日，不把未在籍年数算进去。此统一口径为接手者可实施的建议细则，尚待用户整体审阅。
