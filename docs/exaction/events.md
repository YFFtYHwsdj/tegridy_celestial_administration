# 私征苛敛：事件情境与组合

本页拥有具体事件情境、选项意图、前后呼应及组合示例，不写完整正文和最终双语选项。主流程与权限见[模块入口](README.md#事件网)，金额、效果强度和抽取权重仍由[数值稿](balance.md)维护；下列短编号仅供设计索引，不是脚本标识。

## 组合方法

一次征敛固定三种做法之一，仍按同一轻／中／重模型结算。多样性分三层：

1. **地方收场**：每种做法有三个事件家族，每家族提供两个具体情境，共十八个情境。
2. **结果呈现**：同一情境按四档结果调整哪些事实已被外界掌握，不重抽犯罪结果。
3. **通判回应**：按此前默许、劝阻、索贿遭拒、实际分赃或事后才知情，以及知州如何收场，使用对应的后续场面。

每次仍只出现一个地方收场事件，以及原流程实际需要的通判交涉。不是把十八个情境依次串起来，也不为每个组合另开一份完整事件。组合示例是可发生的路径，不是必须逐个新增的事件对象。

E5 结算后选定本次收场家族与具体情境，固定至 E6 完成；回调和存读档不重抽。E2 尚未选择具体情境时，只谈做法本身，不提前引用某次尚未发生的停业、求情或争执。

不读取复杂的事前贫富、粮价、地方势力或运输任务来筛选情境，也不强制生成富户、商人和胥吏人物。当地群体可以作为事件叙述对象，但不能虚构某个现有人物的财富、立场或行为。涉及制度名目仍需历史核对，本页是玩法情境草案，不是历史结论。

## 事前通判场面

每种做法有自己的介入理由，仍共用 E2 的默许、施压、索取三个选项和 E3／E4 的回应规则。

### 巧立名目：名目之外

- **通判看见的事**：知州准备以地方事务名义额外收钱，理由与征取安排可疑；尚未取得已实施犯罪的证据。
- **默许意图**：不追问用途，避开正面冲突。
- **施压意图**：质问为何要向地方额外取钱，要求停手。
- **索取意图**：既然要借官府名目取利，要求自己分得一份。
- **知州退让**：撤掉这次额外征取；通判通过成功劝止推动天平。
- **知州坚持**：自行推进，不补写成通判签署批准。

### 折纳牟利：交纳之间

- **通判看见的事**：交纳条件拟被收紧，可能使知州从折算或收纳中取利。
- **默许意图**：不查问其中余利。
- **施压意图**：要求维持正常交纳条件。
- **索取意图**：要求从所得余利中分成，不虚构通判实际掌管全部收纳。
- **知州退让**：取消拟议的苛刻安排。
- **知州坚持**：继续安排；后续通判可以指出先前已经提出反对，但不会因此更容易生成秘密。

### 强征勒索：官威所及

- **通判看见的事**：知州打算向地方索财，并准备以官威迫使对方接受。
- **默许意图**：不愿出面维护被索取者，或不愿得罪知州。
- **施压意图**：要求停止以官威索财；这是施压，不是强制否决。
- **索取意图**：不反对搜括，转而索要自己的份额。
- **知州退让**：取消本次行动。
- **知州坚持**：继续索取，不据此自动推动天平。

接受分赃时，双方的场面是达成交易；拒绝分赃后继续时，留下的是利益冲突。两者的后续不应套用“通判一心为民”的同一段叙述。

## 巧立名目的地方收场

### A1：摊派难支

**情境 A1a：典卖凑钱。** 一些被摊派人户不得不变卖家用，地方请求减轻已经征取的负担。

**情境 A1b：替户垫付。** 有人替无力交钱的邻户垫付，实际负担集中到愿意或被迫出面的少数人身上，他们请求退还部分钱财。

两种情境都不要求事前读取具体民户财产，也不声称游戏生成了一笔可追踪的私人借贷。

- **退还部分所得**：减轻本事件引起的不满；采用统一退还效果。
- **维持已收数目**：留下民众积怨。不能写成又征一次，也不能再发放基础所得。

**后续呼应**：曾劝止的通判可以认为知州只是事后收敛；此前默许者可以把退还视为愿意纠偏；收过分赃者知道知州付出部分所得，但不会被自动追回自己已经拿到的钱。

### A2：名目遭疑

**情境 A2a：用处无人知。** 收钱时所称的用途没有令人信服的交代，地方开始议论。

**情境 A2b：各处说法不一。** 经手人对征收理由的解释互不相同，知州面临声名上的难堪。

- **出面周旋**：消耗影响力，向相关人户解释、收拾口径或承认处置不当；只处理本地余波。
- **任其议论**：承担额外威望损失，不付影响力。

**结果约束**：前两档只写用途存疑与口头议论，不写能够定罪的账证；第三档可以提到确有材料留下，但不能直接断言尚未察觉的通判已拿到；公开之后，周旋只是在收拾场面，不能再写成成功掩盖罪行。

**后续呼应**：此前索贿遭拒的通判可以借知州声名受损冷言相讥；不能把他的索贿动机改写成一直秉公查办。

### A3：经手者加码

**情境 A3a：重复催取。** 经手人利用此次摊派反复向同一批人伸手，导致额外盘剥。

**情境 A3b：借名自肥。** 经手人以知州名义另收一笔，未进入本次知州基础所得。

- **责令吐还额外索取**：消耗影响力，纠正经手人额外加码；知州自己的既定征敛不撤销。
- **容其取利**：留下额外盘剥 modifier；知州基础所得不增加。

**结果约束**：即使责令吐还，也不能把知州的全部行为变成合法征收，或把已有秘密转嫁给一个没有实际人物对象的“替罪羊”。

**后续呼应**：通判可以区分知州纠正了属下加码，还是继续纵容；共同参与者不因知州整顿经手人而自动洗清自己的责任。

## 折纳牟利的地方收场

### B1：变卖积蓄

**情境 B1a：急售存货。** 原本准备留用或择时出售的物资被匆忙变卖，以凑足交纳要求。

**情境 B1b：典当器用。** 部分人以家用、生产器具抵当筹钱，地方请求知州让出一点已经取得的利益。

- **返还部分所得**：统一退还效果，免除本事件新增的地方不满。
- **只问是否交足**：保留个人所得，留下民众积怨。

**后续呼应**：通判先前若针对交纳条件提出反对，后续可明确回应那些担忧如今如何表现。不得把“事先担忧成真”另算一次察觉或自动升级罪证。

### B2：商户求减

**情境 B2a：小铺代言。** 一批小商户请人表达难以承受的额外交纳负担。

**情境 B2b：众商陈情。** 多家商户共同请求放宽安排，但只在本地向知州求情，不触发上级告发或独立商人组织系统。

- **退让一些钱财**：统一退还效果。
- **以声望压下请求**：主动花威望，迫使或说服对方接受现状。
- **一概驳回**：留下交纳受阻 modifier，表现经营受扰与不合作。

**后续呼应**：曾默许的通判面对知州已经作出让步，可以选择不再插手；有秘密时仍可揭露，不把地方妥协视作证据消失。

### B3：交纳阻滞

**情境 B3a：反复退回。** 经手人借品质、规格等由头反复拒收，正常交纳受到阻碍。

**情境 B3b：迟迟不收。** 有人已经带来钱物，却被拖延办理，地方往来与经营一并受扰。

- **动用关系疏解**：花影响力要求恢复办理；不减免知州本次核心罪责。
- **拿出所得收场**：统一退还效果。
- **让他们自行设法**：留下交纳受阻 modifier。

**后续呼应**：通判若先前要求正常收纳，可以把知州恢复办理视作局部退让；这不是事前取消征敛，不再次推动天平。

## 强征勒索的地方收场

### C1：富户求情

**情境 C1a：合家筹款。** 被索取者以家中已在凑钱为由求减，事件不声称已发生一笔额外入账。

**情境 C1b：托人说情。** 被索取者通过地方熟人请求留些余地；不指定现有人物充当中间人，也不生成新人物。

- **退还部分所得**：让出部分利益。
- **维持要求，留些体面**：花威望周旋，使对方接受已经发生的索取。
- **不留余地**：留下民众积怨。

**后续呼应**：贪婪通判可以不在意求情，只关心自己是否实际得到钱；正直通判可以责难知州，但没有可用秘密时只能政治反应。

### C2：催征冲突

**情境 C2a：围门争执。** 被催索者聚集争辩，差役与民众发生对峙。

**情境 C2b：差役越界。** 执行者在索取过程中使用过度威吓，引发抗拒。

- **拿钱平息**：统一退还效果。
- **动用影响力约束执行者、疏散争执**：按本家族影响力费用收场。
- **继续强行索取**：即时损失控制力，表现官府与地方秩序进一步受损。

**事实边界**：默认只发生争执、威吓和抗拒，不自行写死人、放火、真实囚禁或发动叛乱；这些后果需要独立实现与授权范围。

**后续呼应**：曾默许者可能因执行失控而改变态度；若早已分赃，他仍是参与者，不能改套未收赃者的索取封口或无责谴责路线。

### C3：避征停业

**情境 C3a：闭门歇市。** 一些经营者暂时关门，躲避继续刁难。

**情境 C3b：藏货避索。** 货物不再正常拿出交易，地方经营因避让索取而受扰。

- **让出部分所得**：统一退还效果，为恢复经营留出余地。
- **动用关系促其复业**：花影响力收场。
- **任其停歇**：留下交纳受阻 modifier。

**后续呼应**：影响力收场与退钱收场可以进入同一个通判结果模板，但评价重点不同：前者是恢复秩序，后者是让出所得；都不等于取消已经完成的征敛。

## 四档结果怎样进入具体情境

四档控制外界掌握的信息，不决定百姓是否真的受损。E6 正文可以采用“地方情境＋结果短段”，不用为每个格子重写一篇事件。

- **天衣无缝**：已经收钱并造成地方损失，但没有可追责罪证。地方仍可求情、停业或不满；这些不能自动证明知州私吞。
- **风闻失节**：质疑与议论把地方余波同知州联系起来，但尚不足以形成犯罪秘密。不能写“账册已经坐实”。
- **授人以柄**：确有材料能证明本次私征，形成未公开秘密。只有实际知情者可据此行动，事件不透露谁必然会揭露。
- **罪证确凿**：罪行已公开，收场是在处理地方余波。退钱、周旋、约束差役都不能阻止这次首次公开或撤销合法理由。

强度文字另外随轻／中／重调整“涉及部分人／波及更广／负担深重”等范围，不为重度自动增加无实现支撑的伤亡与流亡人数。当前设计不维护具体受损人口数字。

## 收场选择怎样影响后续场面

只保留本次实际选择的收场类别，用于 E8 的衔接，不成为新的长期资源或概率修正：

- **让出所得**：A1、B1、B2、B3、C1、C2、C3 的统一退还。
- **出面收拾**：A2 的周旋、A3 的整顿、B2 的声望处置、B3 与 C1／C2／C3 的资源处置。
- **容忍地方后果**：接受民众积怨、额外盘剥或交纳受阻。
- **强行推进**：C2 的控制力损失选项。
- **任其议论**：A2 的额外威望损失选项。

这几个类别仅组织后续表达；仍沿用现有 E8 AI 评分，不因为多一个叙事类别新增概率、调查、天平或隐藏好感修正。通判只能评论其信息入口支持的外在处置，不会因此知道知州的余额、内心或未获知的秘密。

## 通判事后场面

下列“无证据”包括前两档，“有秘密”指第三档且此人已按正式入口获知，“公开”指已经形成公开罪行。实际分赃者优先走参与者路线，其余按此前经历分流；不能因同一人既曾介入又已收钱同时发送两个事件。

### 事后才察觉：迟来的消息

- **无证据**：地方反应让通判知道或怀疑这次征敛。选择不再插手，或私下责难。
- **有秘密**：掌握可用罪证。选择隐瞒、公开或要求封口钱。
- **公开**：无需事后察觉成功才能知情。选择责难或保持距离，不提供封口交易。

若知州已经退还一部分，通判知道的是地方收场，并不能据此断言知州早就知道自己会被发现。

### 此前默许：当初没有追问

- **无证据**：可以维持不干涉，也可以因地方余波私下责难。此前沉默不是参与分赃，不自动产生罪行。
- **有秘密**：可以继续沉默、索取封口钱，或因事情发展而决定公开。后两者的动机各有区别，不能都写作早有正义谋划。
- **公开**：可以与知州保持距离或责难；不追溯性地把此前默许变成已经收钱。

收场退钱时强调“是否到此为止”，纵容或强行推进时强调“是否还愿意沉默”；选项权限与既有评分保持不变。

### 劝阻遭拒：我曾经说过

- **无证据**：可以不再争执，或再次责难。没有证据时不能兑现原生揭露或索取封口钱。
- **有秘密**：可以公开、保留把柄或索取封口钱。若选择索取，明确表现为此刻转向谋利，不把此前劝阻自动改写成假意抬价。
- **公开**：可以表示自己此前已经反对，或不再与知州争论；不给检举奖励或额外天平收益。

知州事后退钱时，通判可以承认其有所收敛；他不会因此被迫原谅，也不会失去已取得的秘密。

### 索贿遭拒：当初不肯分

- **无证据**：可以压下怨气，或私下责难。文字允许体现不甘，但不能把抱怨当成证据。
- **有秘密**：可以再次要求这一次封口钱、公开，或暂留把柄。这是原有 E9 的一次交易，不是重开 E4 反复议价。
- **公开**：可以讥讽或保持距离，对方无须再付钱买沉默；自己因未实际拿钱而未被本机制认定参与。

知州已经让利给地方、却拒绝分给通判时，可以强调两人利益上的反差；不凭此新增敌对关系数值。

### 已经分赃：同一条船

- **无证据**：共同得利，没有本次犯罪秘密。知州如何收场可以令通判满意或不满，但不再索取第二份钱。
- **有秘密**：共同隐瞒，或决裂并共同承担公开后果。双方都知道这不是只有知州会受牵连。
- **公开**：共同败露通知；没有购买免责、把钱退给知州消除罪行，或再揭露一次的选项。

知州退钱不会自动扣回通判所得；整顿经手人不等于替两人洗白；已经公开后互相埋怨只作场面，不另外扣一轮共同犯罪损失。

## 封口交易的具体场面

E9 根据对方经历和知州收场方式变换理由，支付与拒绝的实际规则不变。

- **迟来的筹码**：事后首次察觉者带着秘密索取利益，强调由知情者变成参与者的选择。
- **沉默开价**：此前默许者原先没有拿钱，现在为继续沉默索价。默许本身不追溯成有罪。
- **立场转变**：此前劝阻者如今提出交易，强调人物此刻的妥协或贪欲，避免一开始就假定他始终在演戏。
- **旧价未成，新价又来**：事前索取遭拒者用现有秘密再开一次封口要求；不能称此前已经合谋。

知州可支付或拒绝。拒绝后通判仍有公开与暂留秘密两种结局，不保证拒绝必然公开。支付后通判这次沉默，并实际承担共同责任；不要再插一个随机“收钱后立即反悔”判定。以后的原生秘密行为另行发生。

如果第三方在待回应期间已经公开本次秘密，取消尚未支付的封口交易，进入公开反应；不让玩家为已经发生的公开再次买沉默。

## 十二组完整组合示例

以下各组展示具体前后关系，沿用同一套 E0 至 E10。轻／中／重都可使用这些情境，不将示例程度变成额外门槛。示例中的事后选择均须满足已定资格与可支付条件。

### 巧立名目

**组合 A：名目遭疑，但无把柄。** 中度 → 通判劝阻 → 知州坚持 → 天衣无缝 → A2b 各处说法不一 → 知州出面周旋 → 通判面对已收拾的场面，选择私下责难或结束。地方有疑问不等于已经留下秘密。

**组合 B：钱退了一些，议论仍在。** 轻度 → 通判未事前察觉 → 风闻失节 → A1b 替户垫付 → 知州退还 → 通判事后察觉成功，选择到此为止或责难。退钱避免本收场的民众积怨，不恢复主要繁荣、不退已结政治损失。

**组合 C：既拒分赃，又放任加码。** 重度 → 通判索取遭拒 → 授人以柄 → A3a 重复催取 → 知州容其取利 → 通判用已知秘密索取封口钱 → 知州拒绝 → 通判公开或暂留。不是再为罪证加一次概率。

**组合 D：整顿属下也救不了共同败露。** 中度 → 事前接受分赃 → 罪证确凿 → A3b 借名自肥 → 知州花影响力整顿 → 双方共同败露通知。经手人额外索取与知州本次征敛分开处理，不能用前者替两人脱罪。

### 折纳牟利

**组合 E：表面无事，民间承受。** 轻度 → 无适用通判 → 天衣无缝 → B1a 急售存货 → 知州保留所得，留下民众积怨 → 结束。地方损害可存在于无人介入的路线。

**组合 F：原先默许，后来不满。** 中度 → 通判默许 → 风闻失节 → B3a 反复退回 → 知州任其阻滞 → 通判私下责难或继续不干涉。态度变化由现有余波表现，不生成秘密。

**组合 G：地方让步换不来通判沉默。** 重度 → 通判劝阻遭拒 → 授人以柄 → B2b 众商陈情 → 知州退还 → 通判选择索取封口钱 → 知州支付 → 两人共同隐瞒。地方退还和给通判的钱分别扣算，双方责任保留。

**组合 H：声望压下陈情，罪行已经公开。** 中度 → 通判未事前察觉 → 罪证确凿 → B2a 小铺代言 → 知州花威望处置 → 通判直接进入公开反应。无需再抽事后察觉，也不能把压下请求写成压下了公开罪行。

### 强征勒索

**组合 I：拿到钱，却损了控制。** 重度 → 通判默许 → 天衣无缝 → C2b 差役越界 → 知州继续强索，扣控制力 → 通判选择责难或作罢。控制力下降不自动制造罪证，也不自动推动天平。

**组合 J：退钱息事，风闻不消。** 轻度 → 通判索取遭拒 → 风闻失节 → C1b 托人说情 → 知州退还 → 通判可压下怨气或责难，不能以不存在的犯罪秘密勒索。

**组合 K：先分赃，后因收场决裂。** 中度 → 事前分赃 → 授人以柄 → C3a 闭门歇市 → 知州任其停歇 → 通判选择共同隐瞒，或决裂并公开双方参与。决裂不再多收钱、不自动免责、不另做暴露判定。

**组合 L：无人预先介入，仍然可能公开。** 重度 → 无适用通判 → 罪证确凿 → C2a 围门争执 → 知州花影响力平息 → 结束，原生追责理由保留。四档中的直接公开不依赖通判存在，也不虚构发现者。

## 执行前终止的三种短组合

- **主动止步**：选做法、付成本 → 程度事件作罢。保留冷却和已付费用，没有地方收场、个人所得与犯罪秘密。
- **劝阻奏效**：选程度 → 通判施压 → 知州退让。除上述终止规则外，按既定规则推动天平；可用做法专属的短通知收尾，不再发完整 E6。
- **交易谈崩后退出**：选程度 → 通判要求分赃 → 知州不愿成交而收手。没有实际收赃者，不生成共同责任，不自动推动天平。

对上述终止，不再用“百姓已因本次征敛受损”的后续段落，因为核心执行没有发生。

## 内容组织与验收

地方收场保持九个家族入口，每个入口有两个情境段；选项效果引用同一家族参数。通判事前按三种做法区分开场，事后按证据权限与参与状态决定选项，再按此前经历和本次收场补衔接段。避免维护“十八个情境 × 四档结果 × 全部通判状态”的完整正文副本。

本次新增的最小临时信息仅为收场家族、具体情境和已选收场类别，随本次上下文结束清理；不对概率、天平或长期人物状态产生隐式作用。秘密保留的证据元数据不需要复制地方收场全文。

内容审阅逐项核对：

- 每个家族两个情境都能承载其既定选项，支付选项不可用时仍有合法出口。
- 每种情境可用于四档结果；完整文本创作时若某个具体细节与某档矛盾，改写该段，不悄悄改变结果概率。
- 退钱、花资源、放任、强索在通判后续中得到对应回应，但不额外结算一遍相同费用、好感、心理或天平。
- 事前仅有计划时不写已实施损害；前两档不写确证，第三档不写全世界已经知道，第四档不再出阻止首次公开的选项。
- 默许不等于收赃，未成交不等于同谋，实际参与者不套用清白旁观者选项。
- 已有旧案的秘密／罪行不因本次前两档或退钱而被删除；首次秘密结果与随后公开状态分开表达，不把原生揭露写成第二次 Duel。
