# 地方司法

提刑是独立于普通路主官的无地司法官职，通过皇帝的地方司法制度法律启停。官名选择与制度权限分开；[官制](../court/README.md)拥有法律分组和默认初始化说明。

## 从哪里读起

- [官署、任命与生命周期](offices.md)：机构对象、固定目录、路绑定、专职资格、原版任命、停用恢复与重要性。
- [辖区、位望与审批](authority.md)：统一法理管辖、身份评分及地方／中央审批路线；拘捕和详覆共用该辖区判定。
- [拘捕执行与公职囚犯](arrest.md)：真实审批、收押、拒捕战争、登记及换任交接。
- [详覆羁押](custody-review.md)：复核、牵制移交、费用、胜负及通知。
- [验证说明](verification.md)：自动回归分工、真实触发路径及人工验收。

## 当前实现边界

官署为公国级无地头衔，绑定王国级路；1066指定路优先使用固定定义，其他适用路动态创建。机构与历史人物分开维护，固定历史中的 `holder = 0` 表示尚未填入任职者，不是史实空缺断言；研究见[1066提刑考证](../../research/song/1066_tidian_xingyu/README.md)。

普通地方主官在自身实际行政辖区发起拘捕，提刑按统一路法理辖区行使权限。审批不产生拘捕理由、不免暴政、不保证成功；成功由实际发起人关押。只有登记的公职囚犯随提刑换任交接，私人囚犯不随官署转移。

司法制度关闭时交接登记者、撤销官职持有状态并退出真实路法理树；对象和双向绑定保留，恢复复用原ID。法律的当日维护位于原生 `on_after_pass`，`on_pass` 只设置冷却，次日复核继续保留，避免法律替换前读取旧状态。

## 设计与兼容

采用原生头衔、任命法、互动审批、战争和囚禁回调，不建立独立案件资源、无罪判决或另一套继承池。普通拘捕入口对纳入机制的地方官员受限，避免绕过审批；皇帝与中央原版权限不据此扩大。

旧设计中的处置权、专属政治玩法及阶段计划不作为当前实现。司法法理整合不承诺完整旧存档迁移。覆盖原版的入口及完整GUI兼容范围以[覆盖清单](../../tools/upstream_overrides.json)为准，更新游戏先做[上游审阅](../development/upstream.md)。

官职待遇由[无地官员契约](../office_funding/contracts.md)维护，地方国库拨款由[官署经费](../office_funding/README.md)维护；共享身份评分由本模块拥有。不要在契约或经费文档复制另一份辖区和权限规则。
