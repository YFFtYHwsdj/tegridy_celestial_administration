# 任命与进身特质图标原图

本目录保存“荐举入品”方案已选定的两张透明PNG原图，规则与实现边界统一见[方案](../../appointment/recommendation_design.md)。

- [吏事进身](traits/tca_clerical_origin.png)：束起的纸质文卷、细绳与朱印。
- [兵事进身](traits/tca_military_origin.png)：半展开军务图与两根木筹。

原图均为1254×1254 RGBA。两图按原版特质的青蓝底板、灰米色纸面、深褐阴影及细腻手绘质感统一制作；底板与主体外部保留真正透明，不以黑色背景替代透明通道。

已完成图稿选择和120、60像素预览对照，已从原图等比缩至120×120，保留完整构图与透明留白，输出同名RGBA DDS并接入正式特质；不得从缩略图或DDS反向放大作为原图。输出后已重新读取核对尺寸、透明度与缩放像素一致性；特质列表、提示及界面缩放仍需专用游戏局验收。

预览审阅不代表游戏显示、效果或保存重载已经通过验收。
