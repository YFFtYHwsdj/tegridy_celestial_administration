# 文武宫廷图标原图

本目录保存已审阅图稿拆分后的独立透明 PNG，按游戏原生图标目录分类；文件名与正式职位或任务标识一致。尺寸、游戏接线和显示验收边界由[宫廷差遣模块](../../court_positions/README.md)维护。

图稿使用内置图像生成工具制作，以实际原版图标为画法参照；职位采用器物构图，任务保留粗糙彩色圆环，主体允许局部越过圆环。已审阅稿转透明版时使用以下提示词约束：保留原有器物、画法、颜色、比例和圆环，删除预览底色及文字标签，将器物间隙与圆环内部空白转为透明，不重新设计或增加装饰。透明提取可能轻微改变笔触，维护时须与已审阅造型及缩小后的实际图标对照。

拆图只裁切透明空白并补齐正方形留白，不另行重绘。缩放使用 `sips`，RGBA DDS 使用 Pillow 输出，再重新读取并与缩放 PNG 比较像素。PNG原图保留较高分辨率，不以游戏内小尺寸DDS反向放大作为后续源图。
