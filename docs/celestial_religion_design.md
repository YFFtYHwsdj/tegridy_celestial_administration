# 天朝宗教：核心理念与机制分工

状态：设计总纲，2026-10-17 整理。本文件记录已讨论的核心方向与拟复用的原生机制，不代表相关玩法已经实现或通过引擎验证；具体数值、事件、政策选项与技术接口留待后续设计。

## 核心理念

> 让儒家思想活在人物里，让佛道活在领地宗教、修会和地产里。

人物的思想身份、地方的宗教生活和国家的宗教政策，应当彼此关联，但不互相替代。儒释道不必成为三个完全对称、要求人物三选一并在地图上相互替换的体系。

优先重新解释和分配 CK3 现有 Faith、Rite、Doctrine、Tenet、Personal Tenet、Monastic Order、Lease、County Religion、Popular Opinion 与 Control 的职责，不以重做 religion 底层为目标。

## 一、儒家承载人物的思想与政治伦理身份

士大夫可以保持儒家身份，同时礼佛、崇道或赞助寺观。一般的佛道接触不必通过改变主要 Faith 表现；改信佛道则可用于表达更强的公共身份转变，具体社会评价后续再设计。

儒家内部允许不同学统，同一学统内部也允许个人思想差异。新学、洛学、蜀学、关学、朔学等优先作为内部学统考虑，不预设为彼此敌对的 Faith。

拟采用的原生分工：

- **Faith**：人物的基本思想身份。
- **Rite**：儒家内部的学统归属。
- **Doctrine**：学统的共同立场与判断原则。
- **Tenet**：学统提倡积极践行的主张。
- **Personal Tenet**：具体人物的思想倾向，容纳同一学统内部的差异。
- **Rite Leader**：学统宗师与传承代表，强调授业、认可与学术声望，不赋予其绝对教权。

当前只确定职责，不要求每个学统填满一套对称的教义配置。

## 二、佛道通过地方社会与宗教组织延续

佛道的发展不依赖大量官员改信，而由僧道、寺观、地方信众、施主及其社会联系共同承载。人物的主要 Faith 可以与所在地的宗教归属不同。

拟采用的原生分工：

- **County Religion**：当地主要的宗教传统，不解释为全县百姓只有一种信仰，也不排除其他寺观存在。
- **Monastic Order**：承载僧道组织及其延续。
- **Temple Holding / Lease**：承载寺观及其掌握的地产与资源。

地方宗教存在与寺观地产相互支持：地方传播可以推动寺观制度化，寺观也可以反过来促进地方传播，不规定哪一方必须先出现。

## 三、神殿地产是一种可以安排不同用途的地方资源

神殿地产代表寺观田产、依附人口、组织网络及公共功能等资源，而不只是某个 Faith 的普通地产。

同一类资源可以用于：

- **国家财政与礼制**：纳入国家直接经营和行政安排。
- **佛道寺观**：交由宗教组织经营，支持宗教生活与地方社会活动。
- **儒家教育**：用于学校、学统传承与士人培养。

优先借用神殿男爵领作为实体载体，以直辖与 Lease 表达资源由谁掌握、经营。直辖不预设为天然最优，不同用途应体现资源分配的取舍。

学校与国家礼制能否直接纳入同一地产框架，仍是待验证的设计方向，具体转换方式暂不规定。

## 四、赞助佛道与改信佛道是独立维度

皇帝与官员可以出于个人修行、家族纪念、国家礼仪或地方治理等原因支持寺观，无须改变主要 Faith。

人物的思想身份与其佛道赞助、国家宗教政策应分别表达：前者主要使用 Faith 与思想体系，后者优先考虑人物关系、事件、修正与国家政策机制。国家政策采用何种具体入口，暂不决定。

这使保持儒家身份的皇帝和士大夫，也能成为佛道组织的重要支持者。

## 五、宗教组织通过地方治理产生实际意义

寺观既占用资源，也参与地方社会。国家与宗教组织的关系应产生财政与治理上的取舍，不预设寺观始终有益，也不预设收回寺产始终有利。

拟采用的原生分工：

- **Popular Opinion**：表达民众对统治的态度。
- **Control**：表达国家对地方的实际掌握。
- **地产收入**：表达国家与宗教组织之间的资源分配。

三者不必同向变化。具体影响条件与数值留待后续设计。

## 配套统计

已实现[儒家思潮统计](confucian_statistics.md)，作为后续生成倾向的数据基础。当前分别计算成年儒家人物的各 Rite 人数占比，以及基础、儒学教育、最高普通头衔、世族贡献相加得到的强度占比与排行。统计按本朝最高君主共享缓存，季度更新，首次读取及满90天时补算。窗口仅供debug诊断，显示分项以便核对权重并支持手动刷新；当前尚未接入生成。

## 后续设计边界

本总纲确定的是人物、地方、组织、地产与国家政策之间的分工。学统教义清单、宗教传播规则、寺观扩张、优免与检括等具体机制，暂不在此定案。

上述原生机制均为拟采用的承载方向；跨 Faith 的修会赞助与租赁、组织延续、学统领袖行为、地产用途转换及县级效果，需要在后续实现前分别查阅本机原版，并通过最小原型验证，不能仅凭名称或界面相似认定可用。

历史依据另按[考证规范](../research/standards.md)保存在 `research/`；本文件中的设计取舍不代替具体历史结论。
