# 路级法理司法辖区与验证记录

## 当前实现

提刑绑定一项王国级路，官署为公国级无地头衔；有效在任时，其法理上级为这一路。废置、销毁或退出提刑司制度时移出所有真实路的法理树，恢复任职后重新挂回原路。官署对象及双向绑定保留。人物封臣关系另行维护，不建立第三套头衔隶属关系。未创建、没有持有人、转出适用制度或被明确废置的路不提供有效提刑。

辖区与拘捕审批采用同一成员判定：地方官职按主要官职头衔的法理归属，宫廷成员跟随宫廷主人的主要官职；必须处于同一皇帝治下。持有多个路的长官本人及共同宫廷仅属于主头衔路，其他路提刑仍管辖各自法理下的官员及其宫廷。拘捕长官始终请求中央批准，不因低评分而改为直接拘捕。

主头衔为世族时，族主与其宫廷成员按真实庄园所在县的法理路归属。不区分其实际领主是地方长官、刑部还是皇帝。主要头衔为行政官职时仍按主要官职法理归属，庄园不覆盖行政官职。缺少有效庄园或庄园县没有对应法理路时，不沿实际领主推测归属。共同帝国范围限制仍保留；不能拘捕皇帝，也不能详覆皇帝关押的囚犯。

皇帝持有路时仍设提刑，法理属于路，实际臣服于该皇帝当前内阁中可任职且等级高于公国的刑部尚书；没有可用刑部时直属皇帝。任职、离任、换任、囚禁与释放回调维护隶属。原版囚禁会使尚书失去内阁职位；释放不等于重新任职。真正重新取得刑部职位后再恢复隶属刑部。

取得路头衔与内阁变动合并安排次日维护。囚禁/释放回调只立即同步已有提刑隶属，再请求完整维护，避免在囚禁事务内创建机构或任命。刑部原生取得职位回调也请求维护，覆盖保留刑部头衔、因而没有头衔取得回调的重新任职。

皇帝直属的地方官员只要主要官职法理属于有效路，也接受这一路提刑的司法权限。拒捕的军事支持人采用目标实际领主；原版拒绝领主要求战争因此以皇帝为防守方。胜利后的实际拘押再通过原生战争结束/拘押回调移交提刑，并登记公职囚犯。

本次不设计旧存档迁移，也不阻止原版AI把皇帝持有的历史路重新授予长官。
