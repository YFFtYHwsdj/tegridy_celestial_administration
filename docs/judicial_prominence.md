# 提刑重要性

## 当前实现（2026-10-10）

提刑重要性反映路级司法官职的吸引力，用于原版同级调任比较，不替代功绩等级、候选评分或近期任命冷却。

初始公式：

```text
提刑重要性 = 250 + 8 × 所属路法理县月收入合计
                 + max(0, 500 − 0.0001 × 路所在地与最高领主首都的距离平方)
```

经济项为原版文官经济权重 24 的三分之一（权重 8）。路是王国级辖区，通常包含多个公国；按三分之一折算，再加固定官职分，允许部分提刑职位高于部分地方公国，同时保持不同地区的差异。基础分 250 与经济权重 8 是当前平衡选择，尚未依据游戏内职位分布校准；不保证所有提刑都高于或低于地方公国。

收入采用绑定路的 `every_de_jure_county` 和 `title_province.monthly_income`，不是提刑自身收入、俸禄、办公预算、国库税收或实际司法案件数量。法理辖区可能与实际控制的司法范围不同；本版沿用原版法理经济口径，包括路的法理范围中不在本国实际控制下的县。距离使用引擎内部单位，不是公里。

例如，路的法理县月收入合计为 80，距京项为 400，则提刑为 1290。一个月收入合计为 20、距京项同为 400 的地方文官公国为 880；另一个收入合计为 40 的同位置公国为 1360。仅从重要性看，前者可调任提刑，提刑可调任后者；实际资格仍由原版任命系统决定。

## 实现入口与作用域

- `common/script_values/tca_judicial_appointment_values.txt`：`tca_` 前缀的基础分、经济权重及完整提刑公式。ROOT 始终为被评估的提刑头衔；收入与距离切换到 `var:song_judicial_circuit`。
- `common/script_values/zz_tca_judicial_appointment_values.txt`：对象级覆盖原版 `appointment_title_value`。有 `tca_judicial_title` 标记的头衔直接执行提刑公式，不依赖持有者的原版文官契约标记；无标记的头衔执行完整保留的原版算法。
- `localization/english/tca_judicial_prominence_l_english.yml` 与简体中文对应文件：重要性分解中的官职基础分和辖区经济项；距离项复用原版文本。

缺失路绑定时只有基础分；有绑定但无持有者或缺少定位时，只计算基础分与辖区经济项，不读取不存在的距离目标。正常生命周期仍应修复绑定和持有者；这些保护不是头衔状态有效的证明。

计算在读取脚本值时执行，不把分数写入存档。经济变化和最高领主首都变化会影响后续计算；候选池及界面何时刷新仍由引擎决定。本次没有增加维护扫描或改变任命资格、冷却及补位流程。

## 原版依据与兼容

参考本机 CK3 1.20.0.4：

- `game/common/script_values/tgp_values.txt` 的 `appointment_title_value`：文官收入权重 24、距离项、武官与中央大臣公式。
- `game/common/script_values/10_ach_values.txt` 的 `oath_reconquest_value_1`：脚本值内切换变量头衔作用域并遍历法理县的原版写法。
- `game/gui/window_title.gui`：头衔页通过 `GetScriptValueBreakdown('appointment_title_value')` 显示分解。
- `game/common/succession_appointment/celestial_governor.txt`：文官允许同级候选，启用近期任命冷却。

引擎与 GUI 使用固定的原版脚本值名，因此仅新增 `tca_` 值不能接入，需覆盖该原版对象。未覆盖整份 `tgp_values.txt`；非提刑分支保留原版函数体和 ROOT 语义。与其他覆盖同一对象的 mod 存在冲突，不能自动合并。游戏更新后需复核保留的原版分支，现有拘捕更新检查工具不覆盖此对象。

后续平衡校准及边界回归可复现步骤：

1. 重启并加载模组，打开江西、河南等提刑头衔的重要性分解。应显示基础分 250、辖区经济项以及距京项；检查日志无新脚本值或作用域错误。
2. 选择相应路内的法理县，按各县 `title_province.monthly_income` 合计核对经济项为合计×8；不要用角色净收入或国库税收替代该字段。
3. 对照一个普通地方文官公国、一个武官职位和一个中央大臣，确认其分解仍为原版项目，没有提刑基础分。
4. 在测试存档选择冷却已结束、其他资格合格的文官公爵，分别测试地方公国→较高分提刑，以及提刑→较高分地方公国。记录候选顺位、原职位交接、旧县保留情况和次日维护；低分或同分的新职位不得仅因本改动通过同级重要性条件。
5. 保存重载并复查分数与分解；收集多个路与地方公国的实际分数分布，再判断是否调整基础分或比例。
