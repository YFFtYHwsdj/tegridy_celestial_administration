# 无地官员契约

2026-10-10：已实现脚本及中英文文本，静态验证通过；尚未完成本次游戏内验证。

## 适用身份

持有标记官职的无地天朝封臣，以该官职为主头衔。当前只纳入带 `tca_judicial_title` 标记的提刑头衔。世家头衔不纳入，提刑为文官；武官判定当前固定为否。未来扩展其他官职时，应同时实现身份登记、判定与回归测试，不保留没有实际设置入口的变量分支。

## 界面与数值

- 官员义务：无、文官、武官。按身份自动选择，不能手动改变。
- 文官：每月功绩 +20，朝臣预算基础系数 +1；关闭头衔兵士。复制原版朝臣数值。
- 武官：文官同额功绩及朝臣预算，军事预算基础系数 +2.5，兵士招募及维护费用 -50%；开启头衔兵士。复制原版枢密使数值，预留给未来武职。
- 官员俸禄：复用 `celestial_salary` 五档及隐藏的 `celestial_salary_rank`。提刑沿用公爵基础系数 0.75，另叠加原版功绩和其他修正。
- 官员预算：低、中等、高。基础系数修正 -0.5、0、+0.5；低档好感 -15，中等无修正，高档 0。与 `celestial_ministry_budget` 数值、默认档和 AI 权重一致。

低、中等、高的办公预算基础系数合计 0.5、1、1.5，不是固定月收入。接入原版 `monthly_treasury_from_ministry_budget_base`，由原版中央预算系统处理；本次未实现从所属路国库另行扣款的自定义转账。引擎是否将路属无地官员列入朝臣预算收款方，必须游戏内核实。

## 加载与兼容

覆盖 `celestial_vassal` 对象，在原有项目中加入官员义务和预算；覆盖 `celestial_treasury` 对象，仅对标记官员隐藏税收发展金选项；覆盖领主侧原版行政契约互动，仅在原有有地／内阁条件旁加入标记官员。

这些对象级覆盖可能与同样改写它们的其他模组冲突。没有覆盖原版整份政体、契约或互动文件。

新任命及既有提刑维护都会修复身份义务，保留已选择的俸禄／预算档位。既有存档可在重启游戏载入后执行现有提刑维护测试决议，或等待周期维护。

## 游戏内核对

1. 所属路领主对提刑官能打开修改行政契约互动；界面显示官员义务、官员俸禄、官员预算三项，文官自动选中。
2. 低、中等、高预算对基础系数分别形成 0.5、1、1.5；俸禄变化进入个人金币，办公经费进入国库。
3. 查看皇帝预算收款方及提刑国库收入明细，核实实际发放和付款方支出；只有契约按钮出现不能视为财政机制成功。
4. 调整预算后执行维护、经历交接并保存重载，核对预算档位是否保留。
5. 普通地方官与九个中央大臣保留原版契约界面。
