# 功绩升品正式实现计划

> 状态：首版实现及维护性能优化已接入，已取得完整同局通过；当前结果、其他轮次出现过的间歇失败与未覆盖边界见[接口验证](merit_verification.md#正式实现同局回归)。本页保留接入顺序与覆盖地图；下列 `[ ]` 表示尚无专门用例／真实路径证据的细节边界，不表示未实现，也不按文件存在认定验收完成。阅读顺序仍为[设计](merit_design.md)、[数学模型与参数](merit_model.md)与[接口验证](merit_verification.md)。

**目标：** 将新开局天朝的原生功绩积累接入核定锁品、年度文武竞争及中央例外授品，保留原版收入、资格与合法回调。

**架构：** 持久核定状态拥有品级真值；全局只读冻结后分国同步配额；共享授品事务在同链成功点记账；异步原生回调只负责副作用与审计。初始化、退出和考试资格先于年度工作器实现。

**技术：** 原生CK3脚本、现有CLI测试框架；数学研究程序不作为业务实现或原生行为真值。不生成游戏测试源码；库内[数学研究](../../tools/merit_research/README.md)只检验模型，不作为原生业务规则的第二份正式测试。

## 全局约束与文件职责

- 首版仅新开局；不迁移任意旧存档，同版本已采用功绩状态的基数缺陷仅按[定向修复规则](merit_design.md#廷臣上限基数修复)处理；不加履历/年龄/人脉评分，不新增连续资源；荫补不纳入本轮新功能。
- 文武分池但共用员额/反馈/抽选参数、九→三、冻结来源、逐级从高到低、每年最多一次普通升品；不得靠改制/转轨/换君主获得第二次。
- 初始化/资格刷新/未升品调任不截功绩；只有成功普通或中央授品归一化；保留贤能制及原版低Merit中央任命后果。
- 所有原版覆盖逐对象登记 `tools/upstream_overrides.json`，先审阅、后手动更新基线；不自动消除差异。
- 新标识`tca_`，玩家文本双语与BOM，注释中文；不覆盖已有无关改动。
- 原生回归在独立可丢弃局，保留红/绿及未执行；现有全组绿不替代新业务验收。

建议新增文件按责任拆分，具体对象加载范围在首个结构探针确认：

- `common/scripted_triggers/tca_merit_triggers.txt`：制度、人口、候选、实际中央持职及提交条件。
- `common/script_values/tca_merit_values.txt`：原版门槛引用、带、资格上限、需求系数、压力、配额及权重；正式值放根目录，避免复现任命类型对子目录值的加载问题。
- `common/modifiers/tca_merit_modifiers.txt`：核定上限；原版考试修正的条件scale以审阅后的独立覆盖对象维护。
- `common/scripted_effects/tca_merit_effects.txt`：初始化、资格刷新、核准、提交、审计与清理。
- `common/scripted_effects/tca_merit_annual_effects.txt`：全局冻结、需求、分国工作账、配额、抽选及实际成功提交。
- `common/on_action/tca_merit_on_actions.txt`、`events/tca_merit_events.txt`：真实初始化/改制/年度/中央入口及必要延迟；不把年度配额跨日分批。
- `events/tests/tca_merit_test_events.txt`及独立模块登记：调用上述正式对象的行为回归。

数值脚本的`min`是下界、`max`是上界，不能照数学函数名称机械翻译。反复getter不得多次抽随机值；先求q并保存，再做一次名额取整。

## 最先关闭的接入边界

### 1. 原版初始化与锁品切换屏障

不能直接在加载时对所有天朝考试修正scale=0，再到after-lobby读取品级。原版同一时期还在发考试与Merit，on_action文档不保证追加effect/events顺序或异步等级刷新完成。正式接管位于原版 after_lobby 效果末尾，真实新局切换由 `tca_merit_lifecycle_test.1` 核对，当前结果与边界见[接口验证](merit_verification.md#当前复测状态)。

接入方案是“尚未激活核定状态者保留原版考试倍率 → 在可证明的原版初始化完成边界冻结现有品级、余额及身份 → 普通人物同级／中央现任按职位下限核定 → 保护刷新相关修正”。初始化不调用授品归一化、不发正常升级奖励、不记录年度获选；中央现任核定只补等级经验，保留原版生成的 Merit 余额，规则由[开局现任核定](merit_design.md#开局现任核定)维护。开局屏障按原版调用顺序确定；后续跨日检查只确认原生等级更新与释放奖励保护，不能代替初始化边界。

新生成、真实0→1入品、首次奖励及首次进入天朝必须有同步准入入口；不能让未激活者长期自动升级，也不能一律核定0而锁死九品入品。若现有原生入口无法保证，应停在该技术任务，明确原因，而不是先写全国循环掩盖问题。

### 2. 国家锚点、名单作用域与唯一归属

全局年度没有人物根。须确认临时名单能否按体系隔离，或改用稳定政治头衔的持久变量列表；用两个体系的小型原生结构探针证明同名list不会串池。不能仅把已结算年份存君主而在继承后丢失幂等，也不能硬编码所有国家为h_china。

建议一次全人物扫描冻结归属与人物状态，并维护本轮体系目录，再逐国执行。稳定国家key或具有等效覆盖证明的全局轮次记录是正式年度接入前置，不能以尚未确定身份的全局记录兜底。仅赢家人物年标记不能阻止换君主后重抽原落选者；目录清理与政权灭亡语义必须写清。无地廷臣不得被封臣遍历漏掉。分类异常者沿最后唯一合法路线占额并暂停参选；从无合法分类者进入U诊断账，启用前证明自然开局以及生成、首次0→1入品、迁入入口U为空，或补清明确归属，不靠静默排除让人口消失。

### 3. 同一人物的连续事务与中央年界

同一人物同时只允许一项已提交待审计事务。中央实际获职即登记pending/职位/请求年；成功关闭普通机会写实际提交年，两个年份不能混用。普通候选排除pending。中央目标在执行前按仍实际持有的职位重算，而不是保留已经失职的最高目标。

若普通已提交但原生合法gain尚未审计，随后又获中央职，先排中央待授，待前项异步审计完成后再执行下一项；不得两次刷新cap合并后仍宣称恰两次正确gain。连续中央任命也要合并待授信息、重新核对实际职位，不手工补发回调。延迟审计事件必须携带预期TOKEN，只有匹配当前活动事务才可清锁或推进pending；旧TOKEN晚到/重复只能忽略，不得覆盖新事务。该串行化边界目前未验，需新用例；若审计延迟失败不撤销已提交核定品级，而是留下可诊断状态。

## 分任务实施

### 任务一：初始化、资格与退出状态

**入口：** 现有原版开局、生成/入品、实际考试、代办考试、免试、舞弊、改制、退休/辞谢/恢复；完整对象清单以[接口验证](merit_verification.md#正式接入前的原版入口清单)为准。

**输出：** `tca_merit_approved_level`、激活状态、理论资格读取接口及退出状态；初始化与刷新不改余额、不发奖励、不降核定等级。离开天朝恢复原制度上限；再次进入先采纳入境时合法等级，不能用多年以前的a强行压回。

- [x] 原生红用例：真实新局高品、九品新入品、初始化重复、首次奖励、真实考试原版与代办、双向改制、撤销资格不暗降品。
- [x] 验证上述屏障，再建立核定修正与实际入口覆盖；刷新保留身份、持续时间及余额，区分受领者与主持人。
- [x] 退休三年离散状态不被考试清不足一年timeout误清；普通任命冷却仍计入人口及候选；真实恢复清退出标记。
- [x] 单项、同模块及受影响科举/任命/经费回归通过；前置未满足明确未执行。

### 任务二：正式双账事务与合法回调

**候选接口：** 人物作用域`tca_merit_begin_grant_effect`，参数`REALM`（最高领主人物scope）、`SOURCE/TARGET`（原生等级）、`MODE`（1普通、2中央）、`YEAR`（自然年）、`TOKEN`（单人物单调事务序号）。TARGET的基准在内部引用原版；调用者不传BASE。初始化使用另一接口。

**提交结果：** 持久事务状态明确核准、已不可撤销提交、失效取消、无须升品；同步结果只有“已提交”允许工作器改人口与成功数。清理活动事务时保留最后TOKEN/YEAR防重复，不能删除phase后任由旧事件再次结算。

- [x] 红用例覆盖余额低/高、隐藏经验分离、同链目标读回延迟、重复TOKEN、失职/退出/迁国/转轨失效、同级或低目标不截余额。
- [x] 将受保护归一化正式化，限定回调抑制窗口；不手补合法gain。
- [ ] 验证普通后中央、中央后更高中央、同年重复任命及待审计重载；补组合用例：年末普通提交待审计→中央pending→跨年→两项分别完成→旧TOKEN审计重复/晚到，并覆盖保存重载。串行前后各次资源、副作用及实际授品年标记正确。
- [x] 不仅数回调次数，还核对师门/庄园及五品触发亲属分享的代表路径；伪降品不得改变关系或奖项。

### 任务三：冻结、需求与守恒账

**输出：** 年度冻结人物记录包含round/year/realm/route/source/Merit/资格；各体系各路线四带D、N、Ñ及逐等级人数，需求唯一头衔集合。

- [ ] 两国名单隔离、无地廷臣、未成年人计人口但不参选、分类异常沿最后合法路线占额、U诊断、重叠登记、错误反指针、储备槽、停用/外国官署及中央持职不一致的原生用例。
- [ ] 先做确定性6→7成功后4→5补位，取消不腾空；同带不改带合计。
- [ ] 以正式提交同步改账，逐级校验`n'=n+in−out`、`Ñ=初始+已成功净流量`，不回读异步原生等级。
- [ ] 机构维护半事务与年度读取边界按有效在职口径验收：空缺/过渡暂持当次不计D，交接完成后才计；这是快照波动，不是永久裁撤。临时无收入不等于无需求，不复用带has_treasury门槛的支付资格作为完整需求条件。

### 任务四：配额、随机取整与加权抽选

实现已确定的[累计反馈](merit_model.md#累计人数反馈配额)，不再实现旧p/H。验零B、逐关来源可达性、E不足、同次冻结六Q、实际提交不重算Q、小池随机零年、极小正期望的原生量化范围及中央/迁入净流边界。正常供给回拉与无退出/极大入仕反例属于数学研究；正式脚本仍需原生用例。

**输出：** 固定来源池的一次q/Q、冻结剩余名单、attempts/success及未分配原因。参数由选定政策的主要维护页引用，不能把数学情景的增长/死亡假设写进游戏。

- [x] 零目标、缺员/超员分界连续性、有限超员下正期望、候选上界、缺员有候选与无候选、退出或中央净流；冻结后M变化仍按冻结M审议，硬资格撤销则取消。
- [ ] 单独验证随机取整的0/整数边界与0.25/0.5/0.75宽区间统计；极小可表达概率留精度结论。
- [x] 采用已验证非负幂倒数及剩余池顶，覆盖大差、全尾部、最后唯一者、取消补抽与尝试上限。
- [x] 统一冻结后算定六Q；抽选过程中不重算，所有获选提交完成后才继续低一级，失败不冒充成功。

### 任务五：真实中央入口与全局年度

**输出：** 九职实际任命/继任/罢免补位汇合的pending登记，统一自然年度工作器；人物普通年标记跨路线/国家共享。

- [x] 核对原版低Merit催化剂在补足前发生且不重复；高品调低职不降品、不截余额。
- [ ] 年界前后中央待授、待授期间失职、同年普通后中央、中央先授后普通均按模型处理。
- [ ] 两体系自然年度、国家换君主/主头衔、同年迁国与转轨、重复脉冲不二次抽选；特别构造两候选Q=1，首次结束后换君主/主头衔再入工作器，原落选者不得因重抽获授。全局先冻结后执行。
- [x] 对完整正式流程做保存重载；原排队事件续接，不重派发补救，不改正常存档。

## 验证矩阵

数学不变量可以先在理想研究模型检查；游戏行为必须调用正式trigger/effect进行原生验证。

- **入口：** 新局初始化屏障、新入仕、真实考试/免试/撤销、出生及原版直接变级的隔离边界、双向改制。
- **人口：** 三跨带关口/三带内、需求零/缩减/扩张、实际腾空、中央越H、转轨与迁移、退出恢复。
- **事务：** 阶段取消、已提交幂等、连续两项授品、异步原生gain代表副作用、审计期死亡/改制、保存重载。
- **随机：** 概率取整精度、不放回、有限差截断、最后一人、失效补抽、重复调用不消耗第二轮随机。
- **自然路径：** 实际yearly触发、九中央职位自然继任与玩家任命、长期AI、UI原生等级/核定状态一致性及卡顿。

相关单项与模块先行，共享接口扩展受影响模块，最后同局全组；核对同次冻结计划、terminal/result/debug/error。Windows、完整玩家界面、长期AI和旧档兼容分别报告；首版不做旧档兼容，不把新局重复初始化叫迁移通过。

## 年龄健康与四级占职的观察层

四级竞争槽J及核定品级×实际职位矩阵由[占职研究](../../tools/merit_research/occupancy/README.md)维护，老年健康/死亡来源由[生命周期](../../tools/merit_research/occupancy/README.md#年龄健康与死亡)维护。它们是校准的外部世界层，不是在年度Merit评分中加年龄或病理淘汰。

自然采样需记录：各级J/空缺、人物真实候选/冷却、全部任命/职务得失、升品但未换职的重标、health/traits/XP、死亡/实际退休/辞谢/恢复及原生死因。人口退出不能自动当岗位腾空，高品在任低职不能自动当抢走一个空缺。

新增验收应包括高官品无职者与高头衔在任者分别竞争低槽、仅升品不腾位、退休与辞谢分别处理、同槽排序对照与完整调任链；不将单事件排序代理相加成净岗位损失。代理演算不能证明原版真实概率或合理高配率，仍须自然入口与长局观察。
