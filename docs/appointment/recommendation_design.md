# 荐举入品与进身特质

本页集中维护通过实务经验荐举入品的方案、初版参数、进身特质及跨模块评分范围。互动、两种特质、通用选官扣分、双语文本与图标已接入。当前代码与实际验收分开，测试结果与剩余边界见文末。

## 目的与取舍

让尚未入品、长期承担吏事或兵事实务的人物，能够由实际任用自己的地方主官提携，取得九品身份，随后进入既有任职与晋升体系。经验体现办事经历，进身特质记录本次入仕途径，官品与考试资格继续分别维护。

采用一个“荐举入品”人物互动，不设具体核准人物，不增加审批事件链。朝廷录用作为互动所代表的制度过程，由资格检查与影响力成本体现；成功后直接入品，不自动授予正式官署头衔。

不采用经验达标后自动入品，保留主官是否花资源提携某人的选择。不设置五年或其他荐举硬冷却，也不设置每署固定名额；先以经验门槛、逐人费用及AI考虑节奏限制供给。自然运行确有过量荐举时再评估，不预设新的总量控制制度。

这是一套游戏映射，不表示相应经验数值、费用或荐举流程已经获得北宋史料证明。

## 互动资格与结果

### 荐举人与受荐人

- 荐举人是采用天朝制、实际任用受荐人的地方主官，包括地方有地主官、提刑和通判；共用[地方主官身份判定](../court/README.md#地方主官与地方有地主官)。不开放给中央部院、闲居家主或其他宫廷的主官。
- 受荐人须存活、成年、尚未入品，并在荐举人处实际承担符合条件的吏事或兵事事务。仅持有经验特质、曾经任职或只是同一国家的人物不够。
- 任职关系、实际头衔及家门身份的边界复用经验模块，不以 `is_landed = no` 单独代表无官署身份，也不额外要求必须是无家族的低出身者。
- 基本入仕资格、性别法律、退出仕途及文武路线合法性，应按现有正式入口核对；经验与影响力不能绕过这些条件。正式资格集中维护在 `common/scripted_triggers/tca_recommendation_triggers.txt`。

### 一个互动与两类经验来源

- 吏事来源：吏事经验至少50点，且荐举时仍在该主官处承担符合吏事经验资格的事务；成功授予“吏事进身”。
- 兵事来源：兵事经验至少50点，且荐举时仍在该主官处承担符合兵事经验资格的事务；成功授予“兵事进身”。
- 两类经验分别判断，不相加凑门槛。既有经验允许断续累积，不另建完整任职履历或连续任职计时器。
- 全部通过同一个“荐举入品”互动处理，不设置吏事／兵事路径选择或两套互动AI。对应进身特质根据实际符合资格的任事来源自动判定；若两类来源同时成立，按当前唯一文武路线决定，不提供路径选项、不强制换轨。
- 进身特质记录凭何经历入品，不等于强制文武换轨。“兵事进身”不表示人物一定曾任士兵或将领，也不自动提供武职硬资格。现有唯一文武路线及换轨继续由功绩模块维护。

### 初版参数与执行

- 每次花费荐举人100影响力，不向受荐人收费，不设置亲属、能力或官阶折扣。
- 不设置荐举人或受荐人的额外使用冷却，玩家可以连续支付费用推荐不同合格人物；已入品者不再满足资格。
- 成功后取得九品身份，并获得且仅获得实际任事来源对应的进身特质。已有吏事、兵事经验保留，不作为消耗品扣除。
- 不附送考试及第状态、升品资格、额外任官分或超过九品入品所需的功绩奖励；入品通过既有奖励前／后维护入口建立九品上限，再仅补足原生首级所需功绩余额；不强设官品、不抹去已有更高余额。
- 无考试、乡试等升品资格沿用[功绩设计](merit_design.md#目标与范围)，不为本互动另设一张上限表。后续考取资格仍可按既有规则升品。
- 提交时重新检查资格、当前任事关系与未入品状态；同一人物不能重复支付、重复入品或在失去资格后只扣费用。原生 `cost` 扣费，`on_send` 执行复验与实际入品；`on_accept` 仅显示确认页结果，不以预览修改人物。

50点经验与100影响力是当前采用的初版平衡参数；玩家无额外冷却是明确取舍。经验增长的主要维护位置为[经验模块](../experience/README.md#三种自定义特质的数值)，此处不另定义增长速度。当前基础速度下，50点需要34次季度结算；具体自然日期取决于实际任职、雇主脉冲及生效的经验倍率。

## 现有经验来源与本次边界

实际资格入口为 `common/scripted_triggers/tca_experience_triggers.txt` 中的 `tca_experience_clerical_eligible_trigger`、`tca_experience_military_eligible_trigger`，均通过明确的实际雇主参数判断。经验资格本身不重新要求入品或文武途。

符合经验模块身份条件的地方财政、外交内阁提供吏事来源，军事内阁提供兵事来源。因此兵事来源已有可能承接未入品人物的入口，不必先创造新岗位才设计荐举。

七项文武宫廷差遣的现行任用仍要求已入品，不能用它们作为未入品人物必须经过的培养步骤。本次不放宽这些差遣资格，不改变季度经验结算，不将旧经验持有人自动补授进身特质。实际自然任用能否稳定产生足量无品来源，需在自然AI观察中确认。

## 两种进身特质

最终显示名称采用“吏事进身”“兵事进身”，不再使用“吏职出身”“军伍出身”等讨论名称。脚本标识分别为 `tca_clerical_origin`、`tca_military_origin`，保留与已定稿原图文件名的一致性；正式定义见 `common/traits/tca_origin_traits.txt`。

- 仅本互动真正成功入品时授予，不因取得经验、调任、普通考试或其他入品来源自动添加。
- 永久保留、不遗传，后来科举及第、升品、转入另一文武路线或离任均不清除。
- 两种特质是互斥的首次荐举途径记录，不因后来取得另一类经验再次加特质。异常同时持有时，评分也只计算一份扣分，不能扣两次。
- 不提供属性、经验倍率、月度功绩或影响力，不降低实际任职后的称职度、任务收益或待遇。
- 与考试资格及其既有状态可以并存；考试不消除进身特质的长期评分影响。

特质描述说明官署任事与获荐入品的经历，以及选官时略受入仕出身所限；简中／英文分别在正式本地化文件维护。获得提示只写获得对应特质，兵事描述不预设从军或统兵经历。

## 通用选官评分影响

任一进身特质使适用的候选评分减5分，文武通用，不随官品加重，也不因考试及第取消。同一次评分只引入一次进身扣分；这项轻微劣势允许由能力、资历与政治经营弥补。

适用范围包括：

- 天朝正式地方文武官职的任命候选评分。
- 天朝中央正式文武官职的任命候选评分。
- 本模组通判、提刑等正式官署的任命与实际读取正式评分的补位路径。
- 七项文武宫廷差遣的共用铨选评分，包括初次补缺、跨署调任与同职迁转中对人选的评价。

不影响家族及普通世袭继承、非天朝政体的一般选官、官品资格与年度功绩晋升抽选、差遣重要度、迁转资格、实际称职度或内阁选席的独立规则。宫廷差遣中的影响必须落在铨选评分，不应误接到职位的原生称职度。

共用值 `tca_origin_selection_penalty_value` 位于 `common/script_values/tca_recommendation_values.txt`。正式头衔通过现有 `appointment_score_governor` 末尾的一次追加读取，宫廷差遣通过 `tca_court_personal_selection_value` 读取。只追加普通减5分项目，不增加倍率或特殊分支。

原版地方文武、中央与本模组通判／提刑均调用治理经验评分。复用既有单对象覆盖，不新增原版覆盖对象，原版基线保持不变；覆盖理由已在[登记表](../../tools/upstream_overrides.json)同步维护。非天朝环境的共用进身值返回0。

## AI使用规则

AI与玩家共用正式资格、费用、效果和无额外硬冷却规则；考虑频率及资源保留只影响AI，不限制玩家。

当前采用的初版节奏与资源参数为每12个月考虑一次，只检查自己实际任用的合格人物；至少拥有250影响力才考虑支付。不要求额外的真人核准，原生考虑频率也不等于每年必荐一人。

已确认的AI额外硬门槛为：荐举人对受荐人的好感严格大于0；对应实务能力门槛降至6。吏事来源按管理或学识至少一项达到6，兵事来源按军事至少6理解；这是同一互动内部的能力判断。好感为0也不通过；特质、能力加分不能绕过硬门槛。这些额外门槛不限制玩家。

AI意愿以负数为基础，由相关特质、对应能力和荐举人对受荐人的好感增减评分；满足资格不等于具有正的荐举意愿，避免AI对所有达标人选一概提携。当前初版公式由 `tca_recommendation_ai_score_value` 维护：基础−30，好感×0.5，对应能力超过6的部分每点加2、最高加20；受荐人勤勉+10、懒惰−10，荐举人慷慨+10、勤勉+5。吏事能力取管理／学识较高者，兵事取军事。这些权重是实施时采用的平衡初稿，未完成自然AI校准；关系与额外经验不另行计分，仇敌身份不另设硬门槛。

同次有多名合格人物时，交给原生人物互动AI按各人意愿处理，不另写最高分排序、加权抽人工作器或每轮最多一人的限制。互动AI从廷臣与封臣中考虑受荐人，正式资格再次过滤实际任事，不新增定时批量荐举流程。

不将诚实直接等同清廉或贪婪直接等同已有罪行，不因军务经历推定勇武、统兵或战场功劳。自然运行重点观察地方主官是否负担得起费用、合格人选等待时间、九品新增供给及文武比例；尚无这组参数的自然AI平衡验收。

## 正式入口与验收边界

- `common/character_interactions/tca_recommendation_interactions.txt`：唯一人物互动、100影响力费用、无额外冷却、原生AI调度与无副作用确认页。
- `common/scripted_triggers/tca_recommendation_triggers.txt`：实际任事与经验资格、入仕边界、自动特质归类、AI硬门槛。
- `common/scripted_effects/tca_recommendation_effects.txt`：真实发送时复验、进身特质与受保护九品入品。
- `common/script_values/tca_recommendation_values.txt`：共用扣分、对应能力与AI意愿。
- `common/traits/tca_origin_traits.txt`：两个非遗传进身特质；图标位于 `gfx/interface/icons/traits/`，简中／英文文本为各自目录中的 `tca_recommendation_l_*.yml`。
- `events/tests/tca_recommendation_test_events.txt`：资格、实际互动及无地地方官署用例，登记在既有经验模块的军事GROUP；前两例共用借县夹具并精确归还，AI技能5／6跨日读取；第三例自建无地官署与属员，核对提刑／通判身份、三类普通内阁经验和提刑实际荐举。

此前有地主官范围的两例已在独立1066天朝观察者局以K=4同局执行，18条断言、终局、冻结计划与同次日志核对通过，未检测到模组相关引擎错误。覆盖49／50经验边界、不合并经验、他署与离任拒绝、AI好感0及能力5／6、负基础意愿与高好感／特质加分、同次两次真实互动扣费、九品与对应特质、县级正式任命及差遣共用分、异常双特质不叠加、考试资格后保留及借县精确归还。

最小复测入口：

```sh
python3 tools/run_game_tests.py --case tca_recommendation_test.1 --case tca_recommendation_test.2 --case tca_recommendation_test.3 --parallel 4 --timeout 240
```

提刑／通判普通内阁经验和提刑荐举由 `tca_recommendation_test.3` 单独覆盖，包括普通无地官署拒绝、三类内阁经验、实土差遣边界与真实荐举。用例直接调用季度结算，不替代无地官署自然季度回调、界面或保存重载验收。

这两例不等于完整地方文武／中央／专职官署任命矩阵已逐项验收；相关类型共用入口已完成源码核对，其他实际候选界面与自然继任仍按真实路径另验。工具回归、并行登记、上游覆盖及文档检查均已通过；工具和静态检查不替代引擎行为。

人工界面、自然AI、长期供给、保存重载及旧存档仍待专用测试局验收。已入品的历史人物不追溯补特质；旧档中实际未入品且达标的任事者可按当前资格使用互动。需要核对实际确认页及结果、候选分浮窗、两图特质列表与不同界面缩放、自然荐举频率与九品新增供给、保存重载后的特质与扣分。

不以静态检查、缩略图对照或直接调用效果代替真实玩家路径、自然AI或持久化验收。普通定向运行产物保存在仓库外，不在本页追加逐轮通过流水。
