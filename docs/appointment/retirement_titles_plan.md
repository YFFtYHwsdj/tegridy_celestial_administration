# 退休头衔与契约剩余验收

正式实施与所选同局集成已经完成，已完成计划不再逐项保留。现行规则见[设计](retirement_design.md#已议定的头衔扩展与独立退休契约)，实际自动覆盖、失败理由及复现方法见[验证页](retirement_verification.md#正式实现与当前验收)。

## 未验证边界

- 外部转授：`.6`／`tca_test_retirement_external_transfer_probe` 保留完整候选、真实等待及失败断言并登记模块。单公国与另持家门对照均未实际改变持有人，尚未验证真实转授后的回收；正式 `.5` 只覆盖跨有效天朝迁属。原生UI限制不证明脚本引擎禁止转授，动态编号复用猜测也未获标记实验支持。
- 人工路径：简中／英文完整界面、失能玩家实际入口、完整玩家传家控制权、真实旅行路径、多人及Windows分别验收。旧档迁移未纳入当前实现。
- 自然运行：90日退闲与年度传家调度、长期收入与退休平衡、反复起复、继续本人后再次传家仍待观察；金额夹具的主动AI隔离不覆盖这些行为。
- 独立错误：自然司法重复宣战等既有问题仍按所属模块处理，不能以所选退休回归通过宣称全模组没有引擎错误。

后续只在实际执行后原地更新验证结论；不扩写运行流水，不将外部转授候选排除解释为整个登记模块通过。
