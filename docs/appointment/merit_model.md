# 功绩升品数学模型与参数

本页拥有首版确定的累计反馈配额、Merit抽选、参数、人口守恒和验证边界；玩法范围见[设计](merit_design.md)，技术接入见[计划](merit_plan.md)，原生接口证据见[验证](merit_verification.md)。首版数值已经用户确认，结束参数搜索，按本页接入正式系统；研究结果不代表原版实际人口预测或正式玩法已验收。

阅读时先看[累计人数反馈配额](#累计人数反馈配额)与[参数与校准](#参数与校准)；人物状态和事务约束供实现时查阅。旧比例/H方案与实验见[基线研究](../../tools/merit_research/baseline/README.md)，年龄健康和四级占职见[联合研究](../../tools/merit_research/occupancy/README.md)。这些研究不增加年度人物评分。

## 模型的边界：规则与外部世界共同构成系统

完整模型必须同时描述人物如何入仕、获得功绩、取得资格、升品、转轨、退出和死亡，以及机构如何增减。仅给出一次抽签的概率，或令每年固定比例人口自动达标，都不足以解释长期仕途。

这里把游戏世界的自然过程视为外部输入，把本系统的核定与抽选视为政策函数。给定初始状态、外部事件序列及随机数，就能逐步求得全部后续状态；尚未实测的外部转移率保留为情景输入，不能以“模型完整”为由假称已经知道其分布。年龄、在任身份、家族及健康可影响外部收入和死亡过程，但不因此成为新增升品评分。

更完整地，把机构、职务、财政、人物关系与待触发事件一并记作世界状态W。年度政策映射为`W⁺=T_π(W,ε)`，随后自然演化为`W_next∼K_ext(·|W⁺)`；π是参数/配额/抽选规则，ε是本次政策随机数。K_ext不必独立于已升品结果：升品可能改变任职、收入及之后的考试/战争机会，因此完整模型是耦合的受控随机过程。固定增长或固定事件序列只是其中的条件情景，不能当作政策改变后真实世界仍保持原轨迹的保证。若同一W不能决定未来分布，须把相关历史/事件队列扩入W，而不是强称过程无记忆。

## 符号、人物状态与唯一归属

原生等级记为 ℓ∈{0,…,9}，显示品级为 10−ℓ；0为未入品。普通竞争来源只有ℓ=1,…,6，即九至四品；普通最高结果为ℓ=7（三品）。四带为 `b(ℓ)=min(4,1+floor((ℓ−1)/2))`：九八、七六、五四、三二一。

人物i的状态记为：

`X_i=(所在体系c, 文武r, 核定等级a, Merit余额M, 隐藏经验Z, 理论资格上限L, 仕途状态s, 原生身份与职务o, 年度标记y, 待授事务v)`。

M与Z是原生两账，不新增连续资源；Z用于数学解释和验收，业务不读取未知隐藏经验。a是持久离散身份，不是自动随M上升的另一资源。L只约束将来的普通晋升，不因撤销考试身份而压低已经核定的a。年龄及收入状态是外部过程的观测量，不加进抽选权重。

每一时点人物只属于一个体系、一个核算归属。沿实际最高领主确定体系，按原生文武分类确定路线；不是按文化、住所或最高属性分类。原生两个trigger内部已处理override优先，不能指望在双真时再读一次override就消除歧义。当前已核定人物若双真或双假，保留最后一次唯一合法路线占额、暂停普通参选并诊断，不抹除品级；重新得到唯一分类时，路线变化按有符号流量记账。

从未有唯一合法路线的已入品人物记入未分类诊断账U，不参加抽选；U不是第三条仕途或新资源，而是防止全人口统计凭空消失的待解析状态。总人口守恒写为文+武+U，U与两条路线之间的解析/失效必须记流量。正式启用前须在真实新局和生成入口证明U为空，或明确其容量归属规则；不能把U静默排除后声称文武容量已完整覆盖。无教育的未入品者仍在外部人口，不因存在这个账而凭空入仕。

仕途人口P包含在任和待阙、已入品且仍属于该体系路线的人。普通任命冷却、考试超时不导致离开P；真实退休、辞谢等按离散状态退出，恢复后回流。人口与候选共用归属基础，不能候选在池外获授而不占人口。

## 时间轴与功绩的两次冻结

游戏的月度、事件和人物变动连续发生，年度脉冲是决策时点，不是外部过程的唯一更新时间。

1. 两次年度脉冲之间，处理实际月到账、官署实付、考试、建造、战争、负面事件、迁移、退出及中央任命。新生儿不等于新九品；只有真实入品/归属改变才进入仕途人口。
2. 年度工作开始时先核对本轮有效机构，取得明确时点的需求快照；不假定同名全局脉冲里的其他维护已经完成。首版建议读取本工作器开始时已完成维护的有效状态，之后新设/修复机构下年生效。
3. 同一年度先冻结所有适用体系的人物、路线、核定来源等级、资格、余额与人口，再依次结算各体系。冻结只读、不先归一化；人物第一次遇到初始化缺失不能默认为可按当前自动升级后的等级参赛。
4. 每国每路线按原生来源等级6→5→4→3→2→1处理。累计反馈在统一冻结后一次算定六关额度、不随同轮提交重算；旧p/H的另一时点仅保留在比较研究。池内逐人抽选、复核、提交并立即更新人口工作账。
5. 只在提交成功的同链边界记录新核定等级与年度成功。异步原生gain随后执行副作用，不再更新年度人数。副作用新增的功绩、考试身份不重开当年冻结候选。
6. 结束清理临时冻结数据，保留幂等与必要事务审计状态；跨日核对实际等级/回调，但不靠跨日读回等级来继续配额。

全局冻结不是因为已证实原版亲属奖励跨国：当前原版该奖励反而要求同最高领主。它是统一观测口径及隔离未来共享回调的设计选择，不能将这个理由写成已存在的跨国漏洞。

外部功绩过程可写为：

`dM_i = g_i(t)dt + dJ_i^+(t) − dJ_i^−(t) + dR_i(t)`。

g表示自然净到账，J表示离散奖励/损失，R表示成功授品的归一化跳变。g可随任职、拨款、月份和倍率改变；J可与资格、家族及战争关联，不能默认独立或人人同分布。正式月收入与官署实付已有各自来源，不在本模块复制发放。普通成功时`M_i^+=Z_i^+=θ_target`是数学事务目标；原生Z的实现由已验证的保护归一化组合完成。失败或落选`R_i=0`。

## 门槛与候选：先有资格，再分机会

原版累计基准θ依次为100、1000、2000、3500、5500、8500、12000、17000、23000。业务引用原版`merit_level_*_value`，不复制一组常数。成功后归一化，下一次普通升品须新增的差值为900、1000、1500、2000、3000、3500，不能把目标完整基准再作为新增成本。

冻结来源ℓ的候选集合：

`E_(c,r,ℓ)={i∈P_(c,r): a_i=ℓ, 原生is_adult, M_i≥θ_(ℓ+1), L_i≥ℓ+1, 本年未普通成功且未被中央授品关闭机会, 没有中央待授}`。

配额公式中的E_i表示相应冻结候选集合的人数，不是名单本身。

人口可包含已有功绩身份的未成年人，普通候选沿用原生成人条件；不另加30/40岁或任职年限。提交时重验存活、体系、来源核定、路线、退出、当前理论资格、pending及年标记等硬条件，但M按年初冻结资望审议，不因同链后续奖励/损失重算权重或重新排队。当前余额不足不另取消，成功仍按既定目标归一化；若将来要把当前余额作为复验条件，必须作为规则变更。

E的基数记为e。中央待授先排除本轮普通竞争，是候选政策：实际任命时登记pending，若随后失职取消，不追溯补发已经结束的年度机会。普通先成功、之后又实际获中央职仍可例外授品；中央先成功则关闭本年剩余普通机会。任命请求年与实际提交年分别保存，关闭普通机会用实际提交年；12月31日任命、次年授品必须关闭次年机会，不能清pending后漏过年界保护。这个不对称来自保留中央特授，不代表允许两次普通晋升。

现有全国探针的“功绩预候选”只证明来源等级和余额达标，不能直接当作包含全部L、退出及年度条件的E。新入仕、理论资格改变、退休恢复与改制会改变未来E；冻结后不动态增补本年名单。

## 累计人数反馈配额

### 运行时保留什么

文武分别计算，输入仅为四带员额K、九个原生等级的有效仕途人数n，以及六个普通来源的冻结合格候选数E。有效人口包括在任、待阙、尚未达本次Merit门槛者；真实退休等退出者排除。不能只数当年达标者，否则高品既有人口会从拥堵账消失。E另按现有成人、Merit、资格上限及年度条件计算，只用来限制能够实际授予的人数。

伯/公/王/帝四级竞争头衔数量先按统一口径得到K；本函数不再辨认头衔名字、年龄、健康或具体任职。四带仍为九八、七六、五四、三二一。原生等级a=1…9对应九…一品，普通关口i=1…6对应九→八至四→三。

将四带K转成目标人数：`T_b=(1+ε)K_b`。ε表示希望长期略高于常额的余量，不是硬上限。前三带各用一个固定比例φ拆成两品：`t_(2b−1)=(1−φ_b)T_b`、`t_(2b)=φ_bT_b`；最高带仅给三二一品合计目标T₄，普通机制不分别控制二一品。目标允许小数，不先向下取整丢掉小体系。

已确定前三带以φ_b=0.60为起点，即九/八、七/六、五/四各按较低品40%、较高品60%分配目标；三二一品只控制合计，不设三者内部比例。这是已选定的研究起点，尚未证明为最终平衡值。ε=0.10仍只是待校准建议。φ决定存量目标，和旧方案带内/跨带的晋升概率p不同，不另叠一套乘数。既有等分目标实验保留原始输入，不能改称已经验证四六分配；新联合研究已显式采用该比例，见[联合研究](../../tools/merit_research/joint/README.md)。

### 四级头衔怎样变成员额

候选输入J₁…J₄分别是伯、公、王、帝级可独立竞争的头衔数量；同一竞争单元只计一次。J不是当前持有人数，也不能由有效在职需求D=516直接替代。先算整带K，再按φ拆品，避免同一头衔被两个品各记一份完整需求。

本轮恢复逐带计算：`K_b=k_bJ_b`，四个k可以相同或分带，但文武必须使用同一组。没有全国预算再分配；同一头衔只计入所属带一次，两个品再分这个带的人口目标。此前总预算候选已撤回默认地位，原模拟仅说明另一种框架的表现，见[预算对照](../../tools/merit_research/budget/README.md)。

k不是天然等于1.5，也不能从开局N/J直接读出最优值。它与余量ε只通过`h_b=(1+ε)k_b`影响目标：若h完全相同，全部六个尾目标及普通配额完全相同。故本轮固定ε=.10作为常额/目标的解释约定，搜索k；不能宣称分别找到了最优k和最优ε。

第一带还有一项精确不可辨识：六个B都不含九品目标t₁，第一带仅通过八品目标`h₁φ₁J₁`影响配额。因此独立k₁和φ₁的乘积相同，普通控制器相同；若强制四个k完全一致，才是额外结构约束部分消除这项自由度。九品入仕由外部世界决定，不能因六个B贴近目标就声称九品也被控制。

**严格逐带映射的结构边界：** 中间J_b=0而上方有正目标时，中间目标人数为0，却要用真实在册中间人物提供向上流量；一年一升下无法使各品同时达到目标。增大任何有限k都不能令k×0变正。零中层是映射不可达压力组，不靠偷偷换总预算公式变成通过。

若以后采用周转储备，应作为独立机制明确选择：`K_b=max(k_bJ_b,η_bΣK_above)`，从高往低计算，额外人口单列；本轮纯逐带主实验默认η=0。旧递归储备及加厚反事实见[瓶颈研究](../../tools/merit_research/bottleneck/README.md)。必要候选比例随政策和年龄组成变化，不把入仕资格比例直接当年度存量候选比例来推出η。

### 为什么控制“这一品以上共有多少人”

对每道i→i+1关口，定义：

`S_i=Σ_(a=i+1…9)n_a`；`B_i=该关口以上各品的目标人数之和`。

例如九→八看八品及以上总数，八→七看七品及以上总数，四→三看三二一品合计。一次i→i+1只给对应S_i加一；其他普通关口都在这个集合内部搬动，或完全在其外，因而不改变S_i。这样每道关口的流量可以直接对准一个人数目标；上层拥堵自然影响下层，不必另加距离压力参数。

全部B同时达到时，各相邻差也达到对应单品目标；最高带仍只控制合计。只控制四个带的总数不能同时指定带内每品人数，因此φ不可省略为一个未说明的分配决定。

### 一个分段函数

以r>0为离线校准的年度补充系数，κ∈(0,1]为恢复强度，先令`q₀ᵢ=rB_i`：

```text
B_i = 0：  q_i* = 0
S_i ≤ B_i：q_i* = rB_i + κ(B_i − S_i)
S_i > B_i：q_i* = rB_i / [1 + κ(S_i − B_i)/(rB_i)]

q_i = min(E_i, q_i*)
Q_i = floor(q_i) + Bernoulli(q_i − floor(q_i))
```

正期望结论是实数数学性质；原生定点与chance精度可能把极小值量化为零，正式实现须验收可表示范围，不得以数学正数替代机器概率证据。

所有六个q按同一次冻结人数计算；同年最多一次普通晋升，来源保持冻结。提交失效仍沿用原事务契约，不把未成功者当实际流出。这个候选取消普通跨带H硬截断；没有再钳制`H−N`，也没有另设每年保底一名。

- 缺人时，补正常周转量，并按缺额的一定比例加快补充；实际仍受来源E限制。
- 在目标附近，仍有正常补充量rB，完全不需要先空出整数一席。
- 超额时，额度连续下降，任何有限S且B、E>0时仍有正的期望名额；越拥堵越小，趋向零。
- 两侧在S=B处同值且斜率都为−κ，没有一个人跨线便突然关闭整关的跳变。
- 无偏整数取整使额度只在相邻两个整数间变化；不额外放大年度总量噪声。名额内仍按冻结Merit随机抽选。

r、κ、ε、φ均为配置常数，运行时不读取人物死亡概率。研究对照r=.06、κ=.60，不是把原版真实退出率定为6%；r是配额系数，只有理想固定退出模型才满足r=d/(1−d)。

### 稳定性：能证明的部分

固定统计时点为“本年外部变动完成、普通升品之前”。在比例退出d固定、无中央/迁入等外部尾部净流、来源充分且所有升品成功的确定性简化中，下一年有：

`S_next=(1−d)[S+q*(S)]`。

令r=d/(1−d)，则q*(B)=rB，B恰为固定点。两段闭环导数都落在`[(1−κ)/(1+r), 1/(1+r)]`内；κ∈(0,1]、r>0时为非负且严格小于1。因此任何有限S≥0都单调趋向B，不会由这条确定性反馈自身产生往返振荡。

r不等于退出赔率时仍有唯一固定点，但不在B。令`a=d/(1−d)`、`x=S/B`，则r≤a时`x*=(r+κ)/(a+κ)`；r≥a时`x*=[κ−r+sqrt((r−κ)²+4κr²/a)]/(2κ)`。κ在(0,1]时更新导数位于`[(1−d)(1−κ),1−d)`，因此理想闭环单调收敛到自身固定点。不能把“回到固定点”说成“回到员额”。例如d=.04、r=.08、κ=.6时S*/B约1.10，再乘ε=.1的目标余量，约为1.21K。

当前函数在B两侧的局部斜率同为−κ；缺员快、超员慢主要出现在较大偏差，并非两套局部恢复参数。κ主要控制回拉速度，r同时影响周转与稳态偏移，两者不能混作同一种‘快慢’旋钮。解析网格、局部扰动与大冲击轨迹由[逐参数研究](../../tools/merit_research/parameters/README.md#补充与恢复的解析模型)维护。

若来源i在目标附近每年能参选的比例为c_i，则目标可达还要求`c_i t_i ≥ rB_i`（i=1…6），并有足够的总入仕支撑。目标中间品为零但上层仍有正需求时，这个条件不成立：一年一升必须保留中间周转人口。头衔数折算目标时应检查这种结构，必要时把上层需求所需的周转储备计入下层目标；不能对任意形状的K都承诺精确同时达到。

这是真正针对“没有硬H、却能从超额拉回”的证明。但它不保证恢复速度与初始偏差无关：高压下q接近零，超员主要靠真实退出消化。源品无人、Merit不足、考试上限卡住时，min(E,q*)会使补充不够，不能仍引用无限供应的精确收敛结论。

整数随机取整与真实随机退出保留条件期望反馈，却不保证每条随机轨迹永久停在一个狭窄区间。未截来源的q*为凸函数，随机稳态可能有向上的均值偏移；不能把确定性固定点B直接当随机稳态均值。小体系尤其应报告绝对偏差与零名额年比例，而不是只报百分比。

实际退出率不等于校准值时，固定点会偏移。只要实际退出在足够高人口时仍能提供正的回拉，超额区q*≤rB就不会因普通补充按候选人数无限放大而失控。若真实低退出率可长期趋于零，则不存在依赖此公式的统一有限人数保证。原版老年/死亡机制不能直接提供“所有年龄每年都至少有某个退出率”的已验证条件。

### 逐级管道与封顶占用

[零中层诊断](../../tools/merit_research/bottleneck/README.md)用同J同入仕的反事实验证：中间品人数接近目标，不等于有足够可继续晋升的人。资格封顶组仍在任/待阙、占用人口，却不能进入下一关E；可进阶者升走后，封顶者在存量中的比例会继续上升。因此入仕资格分布的比例不能直接替代各品存量的年度候选比例c_i。

在稳态或足够长、边界影响小的观察段，按资格组h分解进入品级i的流量I_(i,h)、在该品至升走或退出的平均停留W_(i,h)、生前成功通过下一关的概率p_(i,h)，有：

`N_i ≈ Σ_h I_(i,h) W_(i,h)`；`F_i ≈ Σ_h I_(i,h) p_(i,h)`。

封顶组p=0但W>0；较长等待会推高年龄，再降低后续通过概率。它们是离线校准的观察量，不加入游戏年度评分或运行时输入。

同带高/低品存量比由进入流量与停留共同决定。若用年度候选比例cL/cH临时近似，带目标T、带以上U满足必要条件`[(1−φ)cL−rφ]T≥rU`与`φcH T≥rU`；U>0时φ必须小于`cL/(cL+r)`。在这些固定人工比例下，最小所需储备对应`φ*=cL/(cL+cH+r)`，不是普遍60%或80%。旧合成cap集中在每带高品且终身不变，会强化高品留存，必须检验资格变化后结论是否仍成立。

新诊断中，四品约92%～94%人年资格封顶，实际候选仅约2%；原潜在高资格队列在八品人均累计达标落选约20次。仅加厚共同中间储备便能明显提早进阶、提高最高带人数，但该候选把总目标从约361推至516，实际人口约346，连第一尾目标383.625也高于全体人口均值。因此下一轮公式必须同时处理梯队分配与计划总量预算（不按当年实际人口缩目标掩盖冲击），不能只增设储备下限；该加厚臂没有自动成为政策；当前逐带映射及其结构边界见参数节。完整反事实、队列分母、死亡阶段和未解决限制由研究说明维护。

### 三个无法由配额函数独自满足的要求

**任意科举量下，各品包含九品都接近固定员额：不可行。** 普通晋升只搬动人，总人口恒等式为`P_next=P+入仕−实际退出+其他净流`。入仕长期十倍而退出方式不变，函数能保护八品以上的目标空间，但多余者会积在九品。若也要求九品不冗余，必须另有入仕规模、实际退出/退休、迁出或员额增长的反馈；不能只换晋升公式。

**每年每关至少一人，并对任意小体系不积压：不可行。** 例如最高带目标10人、年退出约4%，正常周转不足一人/年；硬保底一人会将规模推向约25人的数量级。B>0、E>0时q正，只能保证仍有抽到年度名额的机会，不能保证每年Q≥1。B=0时关闭该关是零需求的明示政策，不能同时承诺正机会。

**任意高品初态，都在固定几年内恢复：不可行。** 没有强制退出或降品，高品只能等待实际退出。以每年存活96%为例，从目标100倍降到1.2倍，即使普通流入完全为零也至少需约109年。若新外部特授长期超过目标的退出量，关闭普通入口也无法维持目标；正机会函数更不可能替代特授约束。

“无外部冲击”仍须保留正常自然退出和入仕。若连自然退出都为零，却一直有正晋升，最高带终将无限增加；把q压得很小只能减慢增长，不能改变守恒。

### 与原有配额候选比较

旧A按候选数扩大吞吐、以H硬截断；研究已经发现来源暴增会把机会与积压强耦合。这个候选将吞吐锚定目标人口和偏差，候选多只改变竞争激烈程度，超过E下限后不再抬高q；因此更符合本次“过量入仕不把高品冲垮”的目标。

代价是放弃“每位合格者拥有相对固定基础升品机会”，并取消带内无容量约束的旧政策。带内也按累计目标反馈，只是由φ和目标结构决定常态通量；上层过量可以使其明显变慢，但不硬封零。不能声称这只是旧p/h的无害调参。

合成压力场景、结果及复算方式见[反馈研究](../../tools/merit_research/controller/README.md)。

## 固定名额内的功绩抽选

同一来源池的剩余人物使用冻结余额，权重为：

`w_i=C·2^((M_i−M_max)/B_ℓ)`，`Pr(下一名=i)=w_i/Σw_j`。

B是权重翻倍差；建议比较`B_ℓ=τ(θ_(ℓ+1)−θ_ℓ)`与固定B。本稿偏向按阶段差归一化，含义是相同“阶段积累量”的领先有相同优势，不声称这是历史量化规则。每抽一人即移出，并以剩余池冻结余额重算池顶；共同缩放不改变理想概率。

两人一名额的领先Δ胜率为`1/(1+2^(−Δ/B))`；领先B、2B、3B时约66.7%、80%、88.9%。多人多名额的最终入选率不等于`Qw_i/Σw`，若Q=e则人人入选、温度不影响是否成功。温度不直接改变已经算定的本年Q，但会通过获选者不同、重置与未来增长改变多年后的候选组成及吞吐。

对固定有效集合、固定Q、精确实数指数，不放回顺序抽样与Gumbel前Q名等价，可用于数学研究仿真；理论参见[Kool等的原始论文](https://proceedings.mlr.press/v97/kool19a.html)。原生非负幂倒数、30翻倍差截断、定点量化及提交取消均改变机器分布边界，不能声称与理想模型严格相同。不为极小权重统一加正保底：大量尾部人物会合计稀释领先者。被截成0者可能待池顶移除后重新归一化才取得正权重。

## 守恒、收益反馈与长期可持续性

令x_ℓ为实际成功的普通ℓ→ℓ+1人数，x_0=x_7=x_8=x_9=0，则每一路线：

`n'_ℓ=n_ℓ+x_(ℓ−1)−x_ℓ`。

普通升品总人口守恒，带内流量在同带相消。中央特授用从实际来源到实际目标的转移，文武转轨用旧路线减一、新路线加一；两者都不凭空新增人物。加入外部入仕/迁移/退出后，`n_next=n'+A−X+J`，其中J是对称的内部转移净量。年度工作账应逐笔满足该恒等式，不等待异步merit_level刷新。

官品人口守恒不等于职位腾空；新增占职账`O_(a,t)`区分官品与实际头衔等级。年度升品只重标矩阵的官品行，除非另有真实职务效果，否则不释放低职；辞谢也不自动等于卸职。四级槽位J、填充、空缺、真实交接和占用年的分母另由[占职模型](../../tools/merit_research/occupancy/README.md#两种容量与一张占职矩阵)维护。

最高带没有普通向上流出。在固定需求的长期平均下，若人口稳定，必须满足：

`普通进入 + 中央特授净进入 + 迁入/恢复/转轨净进入 = 死亡 + 退休/辞谢 + 迁出/转轨净离开`。

需求变化会改变目标；若中央净进入持续超过最高带退出，普通升品即使全关也不能维持目标。累计反馈没有硬H，零退出时持续正机会仍会积累人口；具体反例和回拉条件见前节，不用旧H闭锁结论替代。

功绩重置形成反馈：高增长者更易达标并积累优势；成功后超额不结转，落选者保留，因此下一关不是“原先多的12000继续包办全部升品”。月增长、考试跃迁、在任收入和资格上限必须联合建模。均匀退出率只是数学情景，不能由退休决议文字推断原版AI普遍按年龄退出。

## 等待、死亡与不可达

若刚成功归一化于年0，每年抽选前增长g>0，阶段差为Δθ，则首次可抽年份`k=ceil(Δθ/g)`。在同质、稳定池、每年独立成功率s的特例下，下一次成功的历年期望为`k+1/s−1`；不能再加完整1/s而多算首次达标当年。若功绩在该年抽选后才到账，则改为k+1/s。已达标者的抽签次数均值1/s，与等待历年均值不是同一量。

六关从九品至三品至少需要六次不同年度成功；从九品基准开始、下一年度才首次增长，无事件奖励且每次归一化、固定正增长时，达标时间下界是`Σ ceil(Δθ_ℓ/g)`。有负面事件或随机增长时这是首达问题，不能用`Δθ/E[g]`当真实平均。

若每年先抽选、成功即记到达、再以概率d死亡/永久退出，固定成功率s时生前成功率为`s/[s+d−sd]`；若先死亡再抽选则为`(1−d)s/[d+(1−d)s]`。六关还叠加达标时间和资格限制，不能把每关平均等待相加后宣称多数人终能到达。真实世界退休可恢复，也不能当永久死亡处理。

只要每年有正概率并不保证最终获选；不断进入的更强人物可使弱者累计危险率有限，原生截断更可能产生阶段性零权重。本版接受“达到门槛不保证升品”，不暗加资历保底。若以后要保证某比例生前到达，须以独立目标重新校准，不是概率公式自动赠送的性质。

指标必须同时报告：全体与资格允许者的固定观察期到达率、未达标与达标落选、死亡未达、暂时退出/恢复、期末仍在观察者、成功者条件等待分位数。只报成功者平均，会掩盖大量从未成功者。竞争事件与期末观察结束分开处理；方法背景见[竞争风险与累积发生率的研究综述](https://pmc.ncbi.nlm.nih.gov/articles/4741409/)，这里只借其统计定义，不作医疗类比或医学结论。

### 固定首版值的小量核查

固定上述一组数值，不再做参数搜索。来源收入、AI初始化与原有健康/任命代理不变，新种子65/66的文武×参考/高收入8局，以及种子65的头衔收缩/死亡冲击4局，共12局120年；1440个年度状态的目标、原始额度、随机取整和六关守恒均复核通过。完整输入与源码在仓库外持久保存。没有用删除失败指标或调整收入把结果改成全绿。

补充率6%是累计目标的基础年流量系数，不是个人成功率或固定死亡率；κ=.9给缺员较快响应，在理想比例退出模型中闭环斜率非负且小于1，不由反馈自身产生往返振荡。以实际退出4%作人工例子，人口只有目标一半时一年进入目标±10%，初始两倍目标时约18年进入；恢复超额主要依靠真实退出，不能承诺一两年消化翻倍人口。

退出率2%/4%/8%的理想固定点约为常额K的1.221/1.130/1.070；因此ε10%不代表各种寿命下都恰为常额110%，长寿下仍可能超出两成。退出2%时从上方接近的固定点略高于目标B的110%，120年内没有进入B±10%不是计算失败，也不能改口说已回到目标。真实候选不足或有中央净流时，标量理想结论不适用。

τ=.5使两人一席、领先一个阶段积累量时理论胜率80%；固定20000次独立双Gumbel抽样为80.325%，符合预设误差范围。它满足优秀者明显更有机会的方向，不提供个人必升保证；每人每年仍至多一次普通晋升，名额取整仍限于相邻整数，不新增年度保底。

生涯结果保留供给失败：基准末40年平均最高带参考收入文1.875/13.2目标、武.5125/1.65，高收入文6.90/13.2、武.825/1.65。头衔收缩后的参考武官最高带在末40年无人，不能称恢复通过；部分中间带也缺员。上述结果含新种子、四六拆品和合成收入/任命条件，不能只归因于某一个改动，也不能拿理想反馈稳定性替代实际供给验收。当前数值可作为首版接入起点，长期平衡、真实收入与资格流及实际任命仍按验收边界处理，不再扩展数值搜索。

### 系数网格比较

按四个k各取`1.5/2/2.5/3/3.5/4`，完成1296个组合、两种子×两路线×两收入情景共10368个80年小规模局，再将10组代表放回完整规模，以新种子63/64完成80个120年局。小国采用共同初态和入仕口径，保留各最高带系数层代表；具体筛选规则、公开经济输入与复算入口见[来源收入下的全网格](../../tools/merit_research/income/README.md#四带系数全网格)。不是1296组合的完整规模穷举，也不称全局最优。

小规模与完整规模的诊断排序第一均为`[1.5,1.5,1.5,1.5]`：完整规模八条件中的最差带/尾平均跟踪误差为.5284，条件平均.2722；指定参考`[1.5,2,3,1.5]`为.6247/.3360；统一2.5为.6882/.4001；统一4为.8048/.5331。该误差只用于对照，尚不是平衡合格线；低目标更容易接近，必须同时看实际高品供给。最优落在搜索下界，也不能据此断言1.5是区间外的最优点。

以下都是完整规模末40年、两个新种子的均值，最高带目标在两组之间保持文13.2/武1.65：

- 统一1.5：参考收入最高带文2.75/武1.00，高收入文7.4625/武1.45；参考收入五四品文12.4375/24.75目标、武3.6625/4.95，高收入23.175/24.75与5.0375/4.95。
- 指定参考：参考收入最高带文2.8375/武1.2375，高收入文9.9875/武1.60；参考收入五四品文12.80/49.50、武3.625/9.90，高收入32.625/49.50与10.0125/9.90。
- 指定参考的总员额相对统一1.5，文697/645（+8.1%）、武143/129（+10.9%）；这是人口员额预算，不是财政支出。高收入下实际最高带人数增加文33.8%、武10.3%，参考收入下文仅增加.0875人，不能宣称普遍显著改善。

提高最高带k本身主要是抬高目标：例如其余三带均1.5时，k₄从1.5到4，参考收入文最高带2.75变2.4875，目标却从13.2增至35.2；高收入文7.4625变8.55，也远低于35.2目标。因此不能用更大最高带预算当作补足供给的保证。统一4在高收入下能得到更多实际高品（文14.4375/武3.3875），但总员额为统一1.5的2.67倍，且参考收入仍严重缺员；不能因绝对高品最多就判定它最好。

用户已据较低员额和较少高品下占，选定统一1.5；原指定组仍用于衡量多约8%～11%员额所换取的高收入上层供给。两者都未满足全部收入情景下回拉到目标附近的要求，选定k不等于正式玩法已验收。观察期末仍有明显种子差异与趋势，例如统一1.5的参考文官最高带在两个种子的末40年分别3.825/1.675，不能把均值叫稳态或置信保证。其后用户选定共同四六，剩余值的小量核查与当前建议见上节；本段网格数据仍是旧研究拆品条件，不用于替代当前配置的验收。

## 功绩增长：不能用一个平均月收入替代

当前生涯研究改用[来源账本](../../tools/merit_research/income/README.md)：`年度ΔM=12×基础月收入×max(0,1+月倍率)+税收贡献+兵池贡献+官署实付奖励+离散净奖惩`，授品归一化另记。基础月收入取当前实际职务与明确个人来源，头衔倍率取实际持有层级，不按功绩品级直接加薪；失职取消职务项。税额必须是实缴领主税，兵池必须是头衔兵士基础招募价值，不能用个人国库收入、兵员数或维护费替代。原生兵池乘区全组合仍不是引擎专项验收。

已核查的持续系数包括标准/工业/都会文职税额系数.8/1.2/2.4、军事/都护府兵池系数.024/.032、大臣20/月、通判2/月、提刑4/月及官署实付×.2。个人庄园、师门、特长、家族与限时修正按其实际条件单列。没有依据给所有在册人物无条件60/月。建造、任务、战争、考试及家族外溢均作为实际发生事件；尤其12000是特定考试AI分支的单次奖励，不是全国每年中奖流。创建时原生AI初始化按已有Merit分支补考试与一次性奖励；之后显式考试仍可提高资格，不再解释为终身潜能封顶。

保持当前员额与反馈参数不变，新增七个配对收入臂及四倍入仕/失地压力共32局、3840个年度状态复核。旧统一收入四个基准局的逐年序列、队列和统计与此前持久结果逐项相同，新增接口没有改写旧对照。新模型的税基、兵池、个人拥有状态、后续考试频率尚非自然采样；只按公开输入作低/参考/高情景，不冒充实测平均值。参考输入及各臂明确定义由来源研究说明维护。

末40年、两个种子：只换持续来源而保留旧资格初始化时，最高带文官从6.75降至2.175（目标13.2），武官从1.1125降至.9875（目标1.65）；同时改为原生AI初始化代理的参考臂为1.8625/.9375。参考贡献基数四倍时为9.0125/1.30，四分之一时两路均为零。参考臂中间两带文官104.4125/12.95（目标129.8/49.5），武官35.125/6.775（目标41.8/9.9），此前“中间带接近目标”的判断不稳健。这里的税基幅度是合成敏感性，不是对实际游戏的估计，不能据此重新选k。

显式建筑/后续考试时间表臂的最高带为文.8875、武.9875；假设人人另具2.5基础月收入及.2倍率的个人来源臂为.1875/.525。增加某些奖励不必提高最高带：它会同时改变候选组成、资格存量和上尾控制下的逐品分配。两臂仍是条件敏感性，不能反推真实AI考试或个人来源会降低上层供给。动态考试臂不使用期末cap当入仕潜能分母；完整输入、账目及局限由研究说明维护。

因此撤回旧收入假设下的平衡数值依据，保留用户指定系数作共同诊断基准；来源系数已可核查，实际经济规模、事件/考试频率和任命代理仍限制推荐。后续优先用自然收入分项与真实考试状态校准外部输入，不能靠扩大员额、提高任意固定增长或给人人补考试把模型调绿。无来源输入、无后续考试或无可任用梯队时，控制器不能凭空创造合格人选；这项供给边界与控制器本身的标量稳定性分别判断。

原版门槛是累计基准，正式模型使用相邻差。仅作量纲检查：从九品基准开始、下一年度首次增长、没有离散奖励/损失且每关成功即归一化，年净增24、120、480、1200时，六关最早达标时间合计分别为498、102、29、12年，尚未包含落选。固定24只相当于通判基础2/月的年化量级，绝不是通判实际总收入。

当前可确认的来源与耦合：

- 通判/提刑身份契约固定月Merit为2/4；官署经费按正式结算的实际到账额×0.2另发，30日防重，不套月Merit倍率。来源由[经费契约](../office_funding/contracts.md)及正式effect维护，本模块不重发。
- 原版地方契约有领主税收/兵士等动态来源，中央大臣有固定月Merit；师门、宫廷职位、庄园、特质和倍率还能改变自然增长。不同职位收入异质，不把全部条目系数相加成每个人默认值。
- 建造、考试、战争与人物事件有一次性奖励或损失。模组代办会试当前对特定非低出身AI分支有20%概率补殿试身份并给12000 Merit；该条件概率不是全国年发生率，不能设每人每年20%中奖。
- 理论上限与奖励分别变化：考试资格决定哪些关口可达，Merit决定何时达标。成功后超额截断，所以大额考试奖励不连续包办六次升品。
- 原版AI退休有资格/性格等条件，已有会试身份者的对应退职决议权重可为0，辞谢/恢复决议也不是普遍AI流。不能凭空加入60岁强制退休或认为所有人年退出率相同。

自然余额桥应是`年末M−年初M=自然月到账+官署实付+离散净事件+原生资源调整+授品归一化跳变`。不剔除归一化就估g，会把晋升成功者误判为负增长。死亡、临时退休、恢复、迁国、改制及转轨分别记账，不能全部合并成永不回来的同一种δ。
## 怎样校准到游戏

1. **输入识别。** 在自然、可丢弃新局采多种子连续数据：逐人年龄、核定/原生级、余额与经验、理论资格、职位、退出状态、路线、实际最高领主、实际竞争槽J与需求D（两者映射待定，不把既有在职快照直接冒称稳定建制员额）。先小规模试采确认字段，再延长到5/20/50年，不把固定局数当统计保证。
2. **流量桥。** 月度余额与官署收据分开；年度前后记录冻结E、q、Q、尝试/失效/成功、人口净流、归一化调整。首次达标、考试奖励和实际入仕分别记时，明确脉冲前后。
3. **自然状态转移。** 区分在任/待阙、临退/恢复、死亡、迁入迁出、改制转轨、中央特授。高品退出率按年龄/身份分组，不拿所有人平均替代；职务与增长关联保留。
4. **机制分解。** 先检验哪一关是L不足、M不足、Q不足；只有旧p/H对照另查V不足；报告等待与未到达原因，再调对应参数。增长不是本升品模块任意可调的补偿项。
5. **拟合与留出验证。** 用部分种子重放自然输入、搜索少量可解释参数，在未参与调参的种子检查；同时拟合人数、跨带流量、达标后等待和到达率，避免多个参数靠同一终局直方图互相抵消。
6. **压力。** 扩张/失地、官署裁撤、零需求小国、最高带长寿、中央连续净流入、收入高异质、资格撤销及转轨；扩张同时影响人口/需求/收入，不只改K。
7. **最终边界。** 自然完整年度、真实AI、玩家界面、正式事务保存重载与性能另验；研究仿真与静态检查均不代替引擎。

存档只读提取出生、余额、累计经验等已在测试产物中确认可行，但没有merit_level字段可供直接抄取；当前等级还受制度、修正与未来核定状态制约。解析需理解嵌套、人物/头衔/政府映射及格式，不能按累计经验单独反推全部核定级。测试局受污染，不能拿它冒充自然校准局。

## 实现与后续平衡边界

首版采用本页累计反馈及已确认参数，不再保留旧p/H或数值搜索为接入前置。四级竞争头衔的去重、路线归属与读取时点在正式统计中落实，按既定逐带换算计算K，不另加周转储备。

三品稀缺、达标不保证升品、九品入口积压、中央特授净流与高品超额依靠实际退出消化，均保留为机制边界。实现后用自然年度和长期AI检验实际表现；不承诺人人最终到达，不以放宽测试预期掩盖来源不足、零退出或小体系问题。上述验收不重新阻塞首版参数收口。

## 模型必须保持的不变量

- 每人每自然年普通成功≤1；文武转轨、迁国、君主替换不重置此约束。
- 所有当前普通成功来自同年同体系的冻结来源池；新升者不能进入下一个池。
- 成功数=实际不可撤销提交数；取消不改功绩、不释放空额，异步回调不重复增人口。
- 逐等级和逐路线人口流量恒等式成立；中央特授与转轨是内部搬迁。
- 只有真实成功归一化双账；资格刷新、初始化、调任未升品和落选均不得截断。
- 冻结后新增功绩或正向资格不增补名单、不重排；资格失效、退出、迁国、转轨、中央待授等仍按提交复验契约即时取消。同步范围之外的自然世界变化在下一统计时点通过外部流量桥解释。

这些是共同契约；配额另验正期望的机器可表示性、六Q冻结、候选数上界与目标可达性。数学研究可检验算法，真实脚本仍需[正式接入验收](merit_plan.md#验证矩阵)证明作用域、回调、保存重载和玩家路径。
