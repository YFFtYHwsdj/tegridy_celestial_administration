# 宫廷差遣与文武流转

本模块维护正式官署头衔以下的文武宫廷差遣，以及共用铨选、重要度与迁转机制的设计与实现。目的在于为已入品待阙官员提供任职成长机会，并使地方宫廷具有天朝官署风格；地方官生态、复杂政务事件与中央特殊选拔不在本阶段范围。

## 阅读入口

- [统一设计](design.md)：已确认规则、四个文官职位、现有军事差遣调整及初版数值的主要维护位置。
- [验证要求](verification.md)：接口核对、已执行定向回归及剩余人工验收边界。
- [现有军事差遣](../military/README.md)：当前生产实现、专项任务及军事内阁联动。共用规则由本模块维护，内阁任免与离任共用本模块入口，军事席位映射和专项任务继续由军事模块维护。
- [官职任命](../appointment/README.md)：入品、功绩晋升与正式官署头衔任命；本模块不另建入品或正式头衔继承体系。
- [官制与名称](../court/README.md)：州、府、监、军的分类与官名。

## 状态与维护边界

七个文武职位与十八项任务的透明 PNG 原图保存在 [图标原图目录](../assets/court_position_icons/README.md)，按原生的 `court_position_types`／`court_position_task_types` 分目录。文件名与职位或任务标识一致；游戏 DDS 使用同名路径，分别为70×70和140×140的RGBA图像。职位采用独立器物构图，任务采用原版式彩色圆环与事务主体；共用任务只维护一张图。知贡举图标由科举模块独立维护。

维护时从 PNG 原图等比缩放并保留透明留白，输出 DDS 后重新读取，核对尺寸、透明边缘和像素内容。文件检查不能代替游戏内的列表、任务按钮及不同界面缩放验收，具体边界见[验证要求](verification.md)。

新增文官职位、文武统一评分、同职迁转及地方总管限制已接入代码；代码接入与实际验收分开，范围与剩余项目见[验证要求](verification.md)。军事三职使用共用候选和迁转流程，其专用内阁验证边界继续由军事模块维护。

本模块拥有共用流转规则，军事模块拥有军事职位效果、官署准入、军事选席映射与任务；本模块拥有文官内阁映射及文武共用生命周期。职位资格、重要度和候选评分是三个不同入口，不相互替代。规则变化时原地修订设计，不追加逐轮讨论或测试流水。
