# 自动科举验证

## 自动检查范围

`events/tests/tca_exam_test_events.txt` 直接调用正式候选、评分、奖励、清理及结算入口。即时用例覆盖考试计时、功绩补算、普通池与优先近亲去重、规模估计、排序、跨届清理、零候选、真实国库扣款及迟到结算拒绝；延迟用例覆盖 pending 与常规任务切换后的继续结算。

```sh
python3 tools/run_game_tests.py --suite exam --timeout 600
```

工具测试另检查职位／任务接线、皇帝目标、双语键、活动覆盖边界及通知引用契约；不模拟消息送达和 GUI。当前实际范围以冻结计划为准。

## 人工验收准备

当前下列人工项目均待执行。使用仅加载本模组的专用1066中国debug测试局，由玩家持有中国皇帝；记录游戏版本和被测源码版本。不要在正常游玩档运行隐藏回归来准备场景。

准备一名有效知贡举、足以支付所选费用的国库，并确认自动任务、原版活动及自定义冷却均允许开科。检查任用边界时，分别使用合格廷臣和合格无地三省六部官员；某类候选无法在界面选中即记录实际限制，不能用事件授职代替界面任用。

每个需要不同初始状态的场景从独立测试局或未操作的可丢弃副本开始。无考生、无人取中、不同录取结果等边界没有可直接复用的完整玩家夹具；未准备成功或随机分支未出现时记未覆盖，不把其他分支的成功算作完成。

## 正式玩家路径

1. 在宫廷界面任用知贡举、启用自动任务并推进两日。预期：满足条件时收到一次请开科；记录实际收件人与主持者，没有重复弹窗。旧档测试重新切换任务后另行判断，不混作新局结果。
2. 请开科后暂停，记录国库余额和当前费用悬浮；选择一档代办，在同日核对仅扣该档费用、设置冷却，再推进至放榜和传胪。分别从干净副本测试各规模，核对数量、侧重、榜首和三甲，没有旧届结果或空白项目行。跨月后的余额不直接用于推算当日扣款。
3. 从另一干净副本选择亲自主持。预期：事件关闭并打开原版活动主办窗口；活动未结束时自动链不再启动。取消、开始活动和代办分别记录，不连续混用一个已付费场景。
4. 代办已付费后切换常规任务。预期：该届继续完成，奖励与费用不重复；重复worker的安全性由正式原生用例覆盖，人工不靠直接重复结算来代替玩家路径。
5. 保存退出重载，核对主持任务、已付费考试及冷却；皇帝继承、AI接管和五年边界分别单列，未走到对应时点不宣布完成。

任何一步出现错误文本、额外扣款、重复奖励或相关引擎错误均失败。正常完成一届只能证明该规模与场景，不自动覆盖零考生、无人取中或少于三甲。

## 家族通知

准备：玩家作为家主，至少有两名不同近亲实际进入本届考生范围，另保留无玩家近亲的对照考生；开科前记录人物姓名、头像和亲属关系。

操作：通过上述正式代办路径完成考试，按实际产生的落榜、会试及第和前十殿试及第分别检查通知。某种结果没有出现时保留未覆盖；不要用隐藏奖励测试通过替代该分支送达。

通过条件：家主收到适用的逐人结果；标题、正文、头像均对应实际考生，连续结算后回看旧通知也不变成最后一人；无关考生不产生玩家家族通知，及第奖励不重复。换为非家主近亲玩家，从独立副本重复；中英文分别检查姓名、关系词和会试／殿试措辞。

## 图标与事件画面

准备：分别使用简中／英文、当前支持的界面缩放，打开真实宫廷职位列表、任务按钮及科举事件。PNG来源在 `docs/assets/examination_icons/`，仅用于对照。

操作与通过条件：逐项查看职位和任务图标，确认原生环形构图、透明边缘及缩放后没有截断或底色；请开科和结果事件的人物应符合皇帝视角，考生人物与实际结果一致。70×70、140×140资源尺寸和DDS接线检查只验证文件用途，不能代替这些画面。

记录实际检查过的语言、缩放、规模和结果分支；通知、完整玩家事件链、图标与保存重载在执行前均保持待验收。
