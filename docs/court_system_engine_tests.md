## 用例

各项名称均以 `tca_test_court_` 开头，以下为后缀：

- `local_only`：地方宋制不改变中央因便及关闭的司法制度；维护后选择保留。
- `central_only`：中央宋制启用中央名称标记，地方与司法保持关闭。
- `minister_name_flags`（新增 `tca_court_test.13`）：自行设置中央宋制／因便，直接维护实际丞相、御史大夫持有者，检查标记启用及移除。官职空缺或前置不满足记为未执行。该测试不验证界面文字，需另做显示验收。
- `judiciary_without_song`：两组因便也能独立启用司法制度。
- `song_without_judiciary`：两组宋制不会开启司法制度，司法拘捕入口为否。
- `local_flag_roundtrip`：选取真实有地天朝属臣，宋制刷新获得地方名称标记，改回因便后清除。
- `sovereign_excluded`：最高领主即使残留地方名称标记，维护也会清除。
- `oe_takeover`：模拟东方王朝加载标记，清除最高领主中央及属臣地方名称标记；名称法律保留，司法制度仍启用；移除模拟标记后恢复名称判断和标记。
- `erg_takeover`：同上，使用礼法与治道加载标记。
- `migrate_song`：旧宋法律迁移为两组宋制及启用司法，移除旧法并保留已有冷却值。
- `migrate_tang`：旧唐法律迁移为两组因便及关闭司法，移除旧法并保留已有冷却值。
- `maintenance_idempotent`：在 1066 默认宋制的背景下，连续维护不覆盖玩家明确选定的地方因便、中央宋制和关闭司法。
- `missing_laws_default`：移除三组当前法律后，维护补齐 1066 中国的两组宋制及启用司法。

每项在测试内独立准备法律状态，不要求按文件顺序执行。涉及属臣的随机选取只决定测试对象，断言结果不依赖抽中哪位符合条件的属臣。
