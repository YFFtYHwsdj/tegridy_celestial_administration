# 一次性行贿

## 规则

向有品或实际任职的天朝人物支付个人金币，换取五年弱牵制；拒绝不付款，不生成秘密、犯罪或额外政治资源。无品基础价为零，无品无职者排除。地方主官复用共用身份入口，包含提刑、通判等无地官署；实际宫廷差遣亦可取得任职资格。奉祠、致仕人物不因身份被排除，但退休头衔不算实职或头衔加价；世族身份本身不提供资格。

基础价为四项相加：Merit每级25金（九品25、一品225、无品0）；伯爵／公爵／王国／帝国头衔加25／50／75／100金，只取最高有效头衔，排除退休、世族和营地；六部加25，宰相／御史大夫／枢密使加50，中央只取最高；非负影响力等级每级10金。

薄礼／厚礼／重金支付1／1.5／2倍，接受加0／25／50。设计者补齐：费用向上取整到整数金币；四项合计为零者暂不可交易，不以最低25金改写无品基础价。

成交后双方三年冷却；付款者仍持有对方任何牵制时不能再买，自然到期视为牵制消失。拒绝不加成交冷却。发送保存报价与金额；回复按当前资格、余额、冷却、牵制和价格复核。报价变化时取消，避免玩家在回复前被扣除未同意的金额。

## 接受评分

达到0接受，基础-40。贪婪正值乘0.5、封顶25，负值乘0.3、最低-15；荣誉正值乘-0.8、最低-40，负值乘-0.4、封顶20；对付款者好感乘0.25，限制±25。朋友／至交加10／20，仇敌／死敌减25／50，高档先判，互不重复；关系与好感叠加。不额外给特质计分或给官位扣分。

财务互斥：个人金币<0负债（+30）；其余存款<max(25,三个月个人收入)为拮据（+20）；存款>=max(300,两年个人收入)为富有（-10）；其余正常（0）。个人月收入取非负monthly_character_income，不计国库收入，不用月净结余。

## 主动AI

每12个月考虑一次，不绑定公务。候选限同朝合格人物，整体排除自己的最高领主；领主链只额外加权。自己负债或拮据不发动；费用不超过存款25%，付后保留50金。选择能说动对方的最低档，不另写公务请求链。菜单默认选中最低可接受档，无法说动时回退薄礼；玩家仍可切换。

设计者补齐的初版数值：发动基数10，野心+15，荣誉乘-0.1限制±20，正贪婪乘-0.05最多减10，个人兴趣限制0至50；目标层次权重为1+Merit等级+头衔加价/25+中央加价/25，上级链额外+10。以原生AI互动随机评估体现偏好，不声称等同对全朝人物进行一次精确加权抽签。候选兴趣及预算按最低可接受档计算，不依赖尚未建立的发送选项。原生AI没有显式选项时也按该档评估；发送时固化档位再保存报价，回复不重新择档；已有显式AI选项仍必须是最低可接受档。

## 接入与验证

友善行动分类；独立互动、hook、数值、trigger、effect、本地化和图标，不覆盖原版。显示检查双方成年存活、非自己及目标资格；可用条件显示外交距离、囚禁、行动能力、冷却、已有牵制和余额。AI拒绝由评分表达，不影响玩家资格。

实现已接入，聚焦原生回归及相关静态检查已通过。定向覆盖资格／价格、关系／财务／评分、付款／冷却／回复变化及AI预算／最高领主排除。厚礼／重金真实发送、待回复互动与脚本状态保存重载已通过，范围见下文；自然AI另有实际年度观察通过；玩家收信界面不以AI回复代替。复现命令见下节。

### 真实发送与待回复存档

专用可丢弃玩家局通过原生确认窗口打开互动，将薄礼切换为厚礼／重金，再调用原生选项点击及发送按钮；没有用成交effect代替发送。8项检查覆盖实际玩家身份、两次选项切换、厚礼精确付款与收款、弱牵制和双向限制，以及真实待回复重金请求的保存重载。

重金请求发送后保持暂停，执行原生保存；随后破坏现场的厚礼牵制和名单，停止旧进程并以新进程加载磁盘存档。重载先确认已成交厚礼状态恢复，再恢复时间，原有重金请求自行回复并精确成交，没有重新发送请求。两个进程、全部检查和冻结源码核对通过，未检测到相关引擎错误。

这条路径使用冻结测试适配层挂载原生窗口驱动，并自动关闭开局说明；临时窗口副本只存在独立验收目录，不进入正式模组。原生run_interaction没有指定报价选项的接口，因此不依赖它指定厚礼或重金。普通厚礼／重金用例继续独立核对最低档、预算和正式成交事务。

玩家收信并选择接受／拒绝的界面、中文布局及三年／五年自然到期仍须另行验收，不将本次AI回复与脚本状态恢复算作这些路径的证明。

### 自然AI

专用观察者局只准备人物、关系与预算，随后按原生年度调度真实等待，不调用发送、强制AI考虑或成交辅助。已观察到薄礼／厚礼／重金自然成交，并核对最低可接受档的精确入账、真实弱牵制、双向限制及最高领主／外朝排除；8项断言通过。AI也确实会选择三位专用目标以外的同朝官员，测试不将领主链设为唯一候选。

夹具给24名自建AI借用非首府县以保持有地身份，结束后归还借出的县与男爵，不回滚一年内原人物的自然升迁或领属变化。观察至少390日；三档未齐时最多等到780日，不能通过提高正式发送概率或强制指定交易获得样本。

原始日志与冻结源码保留。观察期间的一条原版比武事件add_courtier错误仅在人物显示字段含模组标识；完整执行栈均为原版。检查器按固定错误语法、完整人物ID和源码归属复核，将其保留为原版背景诊断；任何实际模组执行帧、未知语法或缺失源码仍阻断。不得把这种归属复核表述为游戏没有任何错误。

### 保存重载

独立观察者局执行真实保存、破坏现场与新进程加载。8项断言覆盖保存前事务、现场破坏、五年牵制及双向三年名单恢复、原有续接事件和报价saved scopes恢复、恢复后正式付款。续接在重载首日检查，避免等待期间自然升品或影响力改变报价；两个进程均确认观察者，日志和冻结源码检查通过。

这条探针验证脚本状态持久化；原生待回复互动队列由上节GUI路径独立验证。三年／五年自然到期未以多年等待专项验收。
