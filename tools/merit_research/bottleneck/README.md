# 零中层的逐级供给瓶颈

本组回答“中间通路已存在，为什么高品仍补不上人”。当前机制参数由[模型页](../../../docs/appointment/merit_model.md#首版确定参数)维护；本组只诊断与提出后续候选，不自动替换当前储备公式或修改正式玩法。

## 方法与复算

沿用冻结的联合生涯，文武共同k=[3,4,8,1.5]、r=.06、κ=.60、τ=.50、ε=.10。主要结构J=[100,0,0,5]，每年入仕8人。两路线/种子10、11成对比较，120年；每组同一批入仕人物的原资格、增长和健康冲击保持对应。初始人物沿原合成输入，不属于死亡保护对象。

```sh
python3 tools/merit_research/bottleneck/study.py diagnose --output-dir <仓库外的新目录>
python3 tools/merit_research/bottleneck/study.py bridge --output-dir <同一目录>
python3 tools/merit_research/bottleneck/study.py check --output-dir <同一目录>
```

- study.py：冻结依赖、逐项反事实、分阶段执行及结果验收。
- observe.py：只读四格分解、原潜在高资格队列、固定40年终点与退出记录。
- checks.py：四格不能混淆、观察终点后不能继续积累等待/成功。

联合研究新增可选observer和merit_gate；默认关闭时文武各120年结果与修改前冻结结果逐字节一致。observer接收深拷贝快照，不能改变模拟；merit_gate只供离线反事实替代M达标判断，保留真实余额、收入、抽选权重、成功归一化及其他资格。它不是游戏规则或测试引擎替身。

诊断28次、储备16次，共44次120年演算；5280个年度状态、六关四格/E/Q与人数账、来源封印和队列终点均核对。JSON、逐年记录、冻结源码在仓库外，不把未完成试算算作通过。

## 口径

人口/配额/年龄取80～119年。四格为“资格不足且M不足、资格不足但M足、资格足但M不足、两者都足”；每格包含人数，不把资格与功绩重叠重复归因。实际E在绕过Merit臂另算，四格仍按真实M分类。

队列为20～59年入仕者，统一观察到入仕后40年或此前死亡。原潜在高资格组按干预前同seed/pid的cap≥7定义，不随“资格全开”扩大分母。累计达标落选是40年内的决策时点次数，含未成功和死亡者；不是成功者条件等待均值。各路线两种子按队列人数加权。年龄按候选人次加权。

保护前/后阶段仅针对原潜在高资格的新入仕者，保留年龄/病理变化，只屏蔽指定阶段的健康死亡。前阶段在首次三品后停止保护，后阶段在首次三品前不保护；不保护初始高品。记录的是被屏蔽的死亡检查人年，不称独立获救人数。无普遍70岁强制退休假设。

全部干预都是整个耦合模型的对照，允许改变未来队列与竞争；不能把效应简单相加分摊为互斥百分比。两个种子只作描述，不是置信保证。候选核未覆盖持有人仍是未知，不能叫真实原生空职。

## 原状的两层瓶颈

**早期通量窄。** 原潜在高资格队列，在八品达标后的累计落选次数人均文19.76、武20.33；九品也有人均约13轮等待。高资格不意味着被优先抽取，仍沿真实冻结Merit竞争。

**封顶者长期占用中间存量。** 四品平均人数文4.55、武5.35，接近或超过目标4.64，但实际合格候选仅.0875/.10人每年。文四品人年约93.96%资格不够、4.12%资格够但M不足、1.92%两者都够；武分别91.59%、6.54%、1.87%。六品也有约87%人口资格封顶，后续来源已经很薄。

最高带目标8.25，目标处正常补充为.495/年；当前缺员时公式需求更高，末关约98%需求被来源截断。末40年四→三所有实际候选都获授；继续提高末关额度不能创造候选。

这里的25%原假设混淆了流量与存量：原始资格分布中，能够达到四品的人约40%，允许继续三品者约10%，两者比值为25%；但可继续者升走，封顶者留下，功绩等待又延缓进入。25%不是“四品存量每年能参加下一关”的已证实比例。观察到的约2%也随政策改变，不能直接换成新的永久常数。

## 单项反事实

以下均值按文/武报告，最高带目标仍8.25：

- 原状最高带.80/1.35，四→三流量.0875/.10人每年。
- 只绕过Merit门槛、保留真实M权重与重置：最高带1.45/2.1875。单独解除功绩达标不足以恢复目标。
- 资格全开：最高带6.90/7.00；资格与Merit门槛同时全开：7.475/7.525。总可进阶人群被扩大，不能解释为原有高资格者的生涯必然改善，更不是免除出身资格的政策建议。
- 首次三品前死亡保护：进入流量增至.45/.4625，但最高带存量.65/1.1625。实际新三品平均年龄已达约79岁，进入后很快退出；不能只看存量误判管道完全没有改善。
- 首次三品后保护：最高带存量3.7625/5.9375，进入流量仍只有.075/.10。留存有作用，但这种不死干预主要积累存量，未修好前端通量。

同总J、同最高J、同入仕的形状对照[75,20,5,5]得到最高带3.8875/4.425。它不同于普通世界基准，可减少总规模/最高带需求同时变化的混淆；最直接的储备效应仍由下面同J对照识别。

## 只加厚共同梯队

保持J、入仕、资格、Merit、健康/死亡及普通名额函数不变，将递归系数按低→高三个带分别设为[.9375,1.5,4]或[.9375,1.5,8]，从高到低递归。它们都是文武共用的离线候选。

- bridge4：最高带2.7125/3.3875。
- bridge8：最高带5.9125/6.35，四→三流量.50/.45，目标8.25不变。
- bridge8中，原潜在高资格队列的40年三品到达文34/62、武41/69；原状为3/62、8/69。八品累计达标落选降至8.77/11.87次，末关候选平均年龄降至约47岁。资格、收入与死亡没有修改，支持“改善上游周转可以提早输送合格者”的解释。
- bridge8再绕过Merit门槛，最高带8.10/7.8625；再资格全开则7.6375/7.675。加厚后剩余瓶颈组成已改变，不能用原状分解直接预测所有后续效果。

**加厚有效，但总目标不可行性同时暴露。** 原状K约[300,13.623,7.031,7.5]，目标合计约360.97。bridge8变为[300,101.25,60,7.5]，目标合计515.625，而实际合成人口均值仍约346.1。更强的约束是第一尾目标B₁=383.625也高于全体实际人口均值约346；即使九品清空，所有尾目标均值也无法同时达到。各品同时贴近新目标在总量上不可能。文武原状与加厚各臂总人口相同，不是增加了入仕或改变寿命换来的恢复。

## 结论与接续

主要机制是早期名额竞争、封顶组滞留和中间梯队不足共同拖慢通量，合格者进入上层偏晚；功绩达标与之后的死亡进一步限制存量。不能只归因“末关名额太少”“四品完全没人”或“高品死得特别快”。

本组的k/r/κ/τ及η属于诊断对照，两个加厚候选仅证明方向有效，未自动成为正式参数。后续[预算研究](../budget/README.md)已在总量约束内重新分配梯队，当前推荐值由模型页维护。预算不能每年跟随实际人口缩小以掩盖损员冲击，也不能把总目标持续抬高当作完整解决。整个研究不修改正式游戏或声称自然长局通过。
