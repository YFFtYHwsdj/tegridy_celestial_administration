# 逐带员额与逐参数校准

本组以逐带`K_b=k_bJ_b`为固定主框架，文武共用参数，六关冻结、每年最多一次普通晋升，最高带只控制三二一合计。全国总预算及统一二八不作为本轮前提。当前建议值由[模型页](../../../docs/appointment/merit_model.md#首版确定参数)唯一维护，本页记录推导、比较方法及结果限制。

## 先分清哪些参数能够独立标定

- 余量ε和系数k只通过`h_b=(1+ε)k_b`进入目标。不同组合若h相同，全部目标和配额相同。因此ε=.10是对常额与目标关系的解释约定，不称它是模拟独立证明的最优余量。
- 第一带更特殊：六个上尾目标都不含九品目标，k₁与八品占比φ₁只通过`h₁φ₁`影响控制器。以k₁=1.5、φ₁=.6作对照时，k₁=1.125、φ₁=.8与其相同，不能把它们当作两个独立政策收益。
- 严格逐带时，中层头衔为0而上方仍有目标，没有正的周转存量就不能持续向上供给；再大的有限k也不能修复k×0。该压力组只揭示框架边界，不为通过它暗加储备或改为全国预算。

## 补充与恢复的解析模型

在来源充分、授品必成功、固定比例退出d、没有中央/迁入净流的简化中，设`S_next=(1−d)(S+q(S))`、`a=d/(1−d)`、`x=S/B`。唯一固定点为：

- r≤a时，`x*=(r+κ)/(a+κ)`；
- r≥a时，`x*=[κ−r+sqrt((r−κ)²+4κr²/a)]/(2κ)`。

仅r=a时固定点正好为B。r较高会把稳态推到B以上，ε又把B设在K以上，两者会叠加。例d=.04、r=.08、κ=.6时，S*/B约1.10，若ε=.1则S*/K约1.21，不能称最终仅超员10%。

在0<κ≤1、0<d<1条件下，理想更新导数位于`[(1−d)(1−κ),1−d)`，所以单调收敛到唯一固定点；该证明不覆盖真实E截断、年龄、资格封顶、中央净流或健康反馈。函数在B两侧局部斜率相同，均为−κ；缺员较快、超员较慢主要是较大偏差下的非线性和真实退出，不能说目标附近已有两套恢复速度。

`scalar_study.py`比较r=.02/.04/.06/.10/.16、κ=.15/.35/.6/.9、d=.02/.04/.08，共60个固定点；从.5B、2B、10B出发共180条160年轨迹，另有固定点附近±1%的120条轨迹。分别报告回到自身固定点的时间、对B的稳态偏差及叠加ε后的偏差，不混称“恢复到目标”。极大初始超额主要靠退出消化，不保证任意冲击都在固定年数内恢复。

## 逐品比例的模型约束

某带较低品L、较高品H，按不同资格组分解进入流量I、停留时间W，有`N_H/N_L≈ΣI_H W_H/ΣI_L W_L`。二八要求该比值约4，四六约1.5，不能仅凭“高一品有封顶者”选80%。

若临时把两品年度实际候选比例设为cL/cH、带目标T、带以上目标U，必要供给条件为：

`[(1−φ)cL−rφ]T≥rU`，`φcH T≥rU`。

U>0时必须`φ<cL/(cL+r)`；在这些固定人工比例下，最小化所需梯队储备的分配为`φ*=cL/(cL+cH+r)`。这只是离线筛查；c会随政策、年龄和封顶组成改变，不能把入仕资格比例直接当年度存量候选比例。

旧资格代理把cap固定为八/六/四/一品，概率10%/50%/30%/10%，而且不会后续考试。这会强化每带较高品的长期堆积，故本轮必须另验证资格分布及后续提升，而不能据该假设直接定二八。

## 温度与整数随机

两人竞争一席，领先Δ个阶段门槛差时，Merit较高者胜率为`1/(1+2^(−Δ/τ))`。领先半阶段时，τ=.25/.5/1分别约80%/66.7%/58.6%。这是明确的玩法取舍，模拟不能替代“优秀者优势多大才合适”的价值判断。

固定候选池用同一10万组双Gumbel噪声验证12组温度/功绩差，不直接拿理论概率抽Bernoulli来循环证明。再用生涯模型改变τ，核对余额重置、候选组成与吞吐的间接反馈。

相邻整数无偏取整均值为q、方差为`frac(q)(1−frac(q))≤.25`，在所有整数且均值相同的分布中方差最小。它没有需要再拟合的随机幅度参数。六组q各10万次同随机数验证均值、方差及零名额概率；小池可能连续零年，不能以“减少零年”单指标推高r，更不加年度至少一席。

## 生涯实验与评价

复用联合模型完整的功绩、资格、年龄健康/老年代理、事件式职务承接及中央特授，不另写Python正式业务规则。单因素锚点为四带k=1.5、三带φ=.6、r=.06、κ=.6、τ=.5、ε=.1，默认储备为0。

训练种子40/41、文武两路、80年，共39组156次：共同k=.75/1/1.25/1.5/2/2.5/3；第二/第三带系数1/1.5/2/4/8；最高带.75/1/1.5/2；第二/第三带φ=.4/.5/.6/.7/.8，第一带φ=.5/.6/.7/.8；r=.02/.04/.06/.10/.16、κ=.15/.35/.6/.9、τ=.25/.5/1/2。每组只改变一类因素，其余保持同一锚点；第一带比例变化应解释为八品有效目标变化，不称独立识别了k₁与φ₁。

交互阶段依据单因素发现构造少量候选，使用训练种子42/43；独立验证使用44/45、120年。严格区分跟踪误差排名、预算取舍和用户偏好，不把“全四带人口贴合”当目标来奖励提高k。九品冗余单报；小于3人的目标另报绝对人数误差和零人年，不能让一个人的变化在百分比上压倒所有大池，也不能据宽绝对容差称无人小池已恢复。

留出覆盖基准、四倍入仕、长寿、领土损失、死亡冲击、空局、全高品、零中层、小体系、低增长、资格较宽/较窄、后续考试、职务收入反馈、上重结构、中央外部授品。资格较宽采用cap比例10%/30%/30%/30%，较窄15%/55%/27%/3%；后续考试沿原潜能上限、人工按30/40/50岁逐步开放四/六/一品上限，既有核定品级不降。它们是敏感性输入，不是历史依据或新增游戏年龄门槛。后续考试组不能用期末cap作为原潜能队列分母，相关指标置空，保留全体固定入仕队列到达率。

健康缓存每job仅复用同sk/health_pid/year、且完整输入状态相等的年度健康推进，返回深拷贝；不同输入直接失败，禁止静默忽略未来健康反馈。基准、长寿和死亡冲击、两个政策，共6组缓存开关完整输出一致；数学/编排检查不替代引擎验证。

python3 tools/merit_research/parameters/math_checks.py

python3 tools/merit_research/parameters/scalar_study.py --output-dir <仓库外的新目录>

生涯目录保存完整逐年结果、初始配置、候选组、种子、冻结源码和摘要。产物拒绝入库及覆盖，源码变化必须重新冻结，不以重签旧结果伪装复算。共同随机输入便于配对比较，两个训练或留出种子只作描述，不能称置信保证。健康死亡插值、年龄初态、每年入仕、资格与收入分布仍为合成代理；任命高配率受rank优先代理影响，只作诊断，不能拿它反推“真实合理员额”。
