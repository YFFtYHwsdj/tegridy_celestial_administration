# 累计人数反馈压力研究

配额函数、稳定性证明与当前参数由[数学模型](../../../docs/appointment/merit_model.md#累计人数反馈配额)唯一维护，本页只维护合成场景、研究结果及复算边界。从仓库根运行`python3 tools/merit_research/run.py controller`；产物隔离及依赖见[统一入口](../README.md)。

## 可复算压力研究

采用七个计数状态：九、八、七、六、五、四、三二一合计。合成目标为[120,120,40,40,15,15,10]，共360；研究目标已含余量，不是原版实测员额。每年独立退出4%、正常新入仕均值14.4人、每品独立50%有资格；这里只研究配额，不复刻人物Merit积累或考试上限。

20个情景，各做1次确定性与12种子随机演算，400年，共260次。比较空初态、全部低品/高品、最高带百倍、入仕量、退出率、资格供给、恢复强度、小国与外部冲击。第250～399年作后期观察，种子范围不叫置信区间。

- 固定正常条件下，空初态、全低品、全高品和最高带百倍均在确定性长局趋向同一目标；随机后期均值的八至四品接近[120,40,40,15,15]，最高带约10.3～10.4，存在小的随机偏移。
- 科举均值增为十倍，随机总人口约3597，但八至四品后期均值仍约[120.1,40.0,39.9,15.0,15.0]、最高带10.3。它验证高品反馈抗来源量，不证明总冗余消失。
- 科举降为四分之一，或资格比例降为1%，会发生不可供给的缺员；“总人数不少”不能替代每道来源都足够。
- 一次减半人口后，确定性六个尾部都恢复至目标±20%并连续保持5年的首次时间为7年；一次向最高带额外加入10倍该带目标，需57年。这体现缺员可加速补，高品过量只能靠退出消化的非对称性。
- 退出改为2%但r不改时，确定性后期最大尾部相对误差约10.2%；退出8%还会使固定入仕量不足，最大误差约36.1%。因此不能把校准退出和入仕均衡条件藏在“各种情况都稳定”的宣传里。
- 小体系保留有名额机会，但年度整数零年、单人的相对波动会显著增加；不以硬保底掩盖。

这些均为数学代理，不是游戏引擎、自然候选池或真实入仕过程验收。结果、来源摘要和运行日志按统一入口保存在仓库外；本页的合成目标与频率不是发布默认。
