# 分带缓冲与拥堵传导研究

从仓库根执行`python3 tools/merit_research/run.py buffers`，执行方式见[统一入口](../README.md)。

本页保留旧p/H缓冲与压力传导的比较依据；当前简化年度配额的待审方案见[累计反馈](../../../docs/appointment/merit_model.md#累计人数反馈配额)，不叠加两套约束。

本页研究“高品带统一超员20%是否过紧”，拥有整数缓冲、对照方法、解析例子和研究结论；旧参考数值由[参数设计](../baseline/README.md#分带缓冲与轻度上层影响的新增候选)维护，旧政策方程由[旧配额方程](../baseline/policy.md)维护。本页不是正式玩法验收，也不将人为增长/退出分布称作游戏实测。

## 先分开四个问题

1. **常额K是否合理：** 它决定机构背后容纳多少在任与待阙人口，是长期规模问题。
2. **缓冲S有几个人：** 它决定普通准入界线H，比只写百分比更重要。
3. **本地收紧有多快：** 本带从K到H的机会如何衰减。
4. **向下输出多少压力：** 上层超额对低带跨带/带内机会有什么影响，不应随扩大缓冲悄悄消失。

增大h同时扩大S、减缓本地收紧，仍不能替代k校准、创造达标候选或保证长期流动。它增加的是允许占员的空间，不是每年永久新增同样多的名额。

## 百分比要转换成整数席位

旧p/H比较方案为`S_b=floor(h_bK_b)`、`H_b=K_b+S_b`。计算hK时明确有理比例，研究程序避免二进制浮点临界误差；正式原生定点仍须单独验证。

对给定整数K，h在`[m/K,(m+1)/K)`内给出同一个S=m。若压力使用实际整数S，传导尺度又与h分离，则该区间内整个政策没有改变，不存在“每增加1%都平滑改善”。

- K=1时，20%、30%、50%缓冲均为0人。
- K=3时，三者缓冲为0、0、1人。
- K=4时，为0、1、2人。
- K=20时，为4、6、10人。

因此高品小池确实需要独立检查，但“高带改50%”不等于有50%额外可用的分数席位。实际缓冲比例应显示为`h_effective=S/K`；K=0时不定义比例且H=0。

### 三种取整是不同政策

- **向下取整：** S=floor(hK)，没有暗含最低储备。
- **向上取整：** S=ceil(hK)，任何正的非整数缓冲都多取一席；K=1时即使h只有20%，也变成100%的有效缓冲。
- **最高带最低一席：** K>0时最高带S=max(1,floor(hK))，其他带仍向下取整。这是公开的小国最高带储备政策，不等于每年必升一人。

三者在K=0都保持H=0。最低一席不是floor再加一，也不与ceil等价。当前候选保留floor，另两种只作可见的政策对照，不称“修复取整”。

## 本地拥堵与向下输出分离

本地压力`z_local`按实际S归一化，控制该带的准入收紧；输出压力`z_up`按独立α尺度归一化，α不跟随h变化。两者精确公式见[模型](../baseline/policy.md#需求软常额与普通准入界线)。

例如K=20、实际N=24：h从20%改50%，H从24变30，z_local从1变0.4。若旧公式让同一个z向下传导，在λ=0.25且只有一个紧邻上带时，下方跨带的远端乘子从0.75变0.90；上层仍超额4人，下层却额外宽松20%。这可以有意设计，但不能把效果全归为“最高带多了6个位置”。

本轮建议固定α=20%作传导参照。在相同N/K下，扩大h不自动降低z_up；只有实际超额减少或修改α/传导参数才减轻外溢。这样能够单独比较容量、收紧坡度与远端影响。

### 带内的上层影响

本地修正G_local仍最多收紧20%；上层再乘W，W∈[0.9,1]，距离越远越轻、合计封顶。一个紧邻上带压力饱和时可以达到这10%上限，远处单个最高带对基层的影响依距离衰减。

最终最低倍率为`0.8×0.9=0.72`，即最多合计收紧28%；不是30%，也不是减10个百分点。不得乘完后重新套0.8底线，否则本地已经严重超员时上层影响会被全部吞掉。最高带没有更上层，W=1；普通晋升仍止于三品，不因此增加二一品带内竞争。

## 对现有开局尺寸的机械影响

下列只代入独立1066快照及两组既有k/p参考，不把N/D当合理k，也不包含完整资格。顺序均为九八、七六、五四、三二一。

- **常额优先文官：** K=[870,88,22,24]。统一20%的H=[1044,105,26,28]；分带20/20/30/50%的H=[1044,105,28,36]。最高带原有29人，静态空间从0变7。
- **常额优先武官：** K=[157,28,4,3]。H从[188,33,4,3]变[188,33,5,4]。五四带原有10人、最高带8人，六→五和四→三仍没有静态空间。
- **机会扩展武官：** K=[189,38,6,4]。H从[226,45,7,4]变[226,45,7,6]。五四带原有10人、最高带8人，这两个入口同样仍关闭；30%在K=6上与20%具有相同整数缓冲。

在K=3、N=8时想立即有一席普通空间，必须H≥9，即h至少200%；H=N仍没有空间。这个反例说明若长期规模不合适，应重新评估k、需求与自然流量，不能不断放大h来保送开局解冻。

## 空间开放与实际升品是两种等待

只为识别容量影响，设初始最高带N0人、每年独立永久退出概率δ，完全没有进入、恢复、特授或需求变化。则`t`年后`N_t~Binomial(N0,(1−δ)^t)`，首次有空间T满足N_t<H。

`Pr(T≤t)=Pr(N_t≤H−1)`，`E[T]=Σ_(t≥0)Pr(N_t≥H)`。

若H=0，永不开放；若初始N0<H，T=0。退出为0且初始关闭时同样永不开放。不能用平均人口轨迹首次过线的年份替代随机首次开放时间的期望。

例：N0=8、δ=3%时，H=3的首次开放平均约40.48年、中位38年；H=4平均约29.54年、中位27年；H=6平均约14.77年、中位13年。因此增加一席确有作用，但未必足以解决开局长时间关闭。

这些只是“第一次空出位置”，还不包含出身、Merit达标、当年配额取整和加权抽选。真实退出有年龄与身份异质，退休还可能恢复，不能用该3%例值预测自然游戏。

## 缓冲怎样影响长期平衡

取最高带的连续条件模型，候选供应与远端倍率固定，令`a=p·e·F_up`，S>0、抽选前N处于[K,H]，此时缺员U=1。考虑V钳制后：

`q=min(a(H−N)/S,H−N)=c(H−N)`，`c=min(1,a/S)`。

令X为上次抽选后人口，下轮先按确定比例δ退出、再普通进入、最后有中央净进入J，则该线性分支：

`X_next=(1−δ)(1−c)X+cH+J`，`X*=(cH+J)/(δ+c(1−δ))`。

固定点要求分母`δ+c(1−δ)>0`。δ=c=0时，J=0对应任意人口均为固定点，J>0则线性增长。只有本次抽选前`(1−δ)X*∈[K,H]`且候选供应等假设成立时，这个固定点才适用；分支外须回到完整min/U/F方程。随机退出跨过分支时也不能把这个解当精确随机均值。

这个式子显示：无退出、无特授且c>0时，扩大S只是让人口往更大的H积累，并不产生永久流动；有退出时，增加容量可通过增加长期占员与之后的腾换提升吞吐；候选供应不足时，扩容可能闲置。若中央净进入足够大，普通入口全闭后的条件模型为`X_next=(1−δ)X+J`、`X*=J/δ`（要求δ>0），其来源不受普通h控制。

## 分层实验与结果

### 固定其他输入，逐层改变机制

逐人物实验保持两组k/p各自不变，在文/武、年增长均值240/720的假设下，比较统一20%旧版、加入带内10%、分带共用压力、分带独立传导、统一50%、分带40%最高带、ceil与最高带最低一席等对照。共80组、960次逐人物演算，每组12种子、100年；用途分离的计数器随机数使潜在死亡、禀赋和入仕冲击在政策间保持一致。

功绩增长、退出率、入仕与资格分布继承[第一轮假设](../baseline/README.md#理想情景演算及其结论)，不冒称新采到游戏数据；中央特授在另一独立最高带实验研究，没有悄悄混进微观结果。完整每关记录包括候选人年、无空间暴露、配额倍率、成功者条件等待、死亡未达与期末未达，不用结算后碰H的年份冒充入口关闭。

候选加权无空间占比定义为：该关口处理时V=0的候选人年，除以全部合格候选人年。它不是日历年关闭比例，也不是每个人的平均等待；政策改变候选组成后，分母也会变化。

### 可以支持的发现

1. **分带放宽能降低容量阻断，但不保证整条仕途明显变快。** 在常额优先武官、平均年增720的假设中，统一20%且已有带内轻度传导时，六→五无空间暴露约90.5%、四→三约55.1%；分带20/30/50%并分离传导后约87.0%与38.6%。阻断下降，但这批入仕队列40年内仍没有观察到三品成功，不能把零样本解释为真实概率为0。
2. **中层可能比最高带更约束最终到达。** 同一文官对照，六→五无空间暴露约32.6%降至23.8%，40年三品到达率却均约0.128%。最高带50%改40%在该参考与机会文官情景下到达数相同，不能据此识别唯一最优上限。
3. **取整的一席有时比百分比微调更重要。** 机会武官五四K=6，20%与30%的floor都只有一席缓冲；graded ceil把H从7改8，改变的主要可能是中层。不能把其效果全部归于最高带。
4. **最低一席需要真正有差异的情景。** 分带50%时当前最高K=3/4已有至少一席缓冲，最低一席政策与floor逐人逐年相同；不能把零差异说成保底无效。因此另在统一20%下比较最高带最低一席：参考武官四→三无空间暴露约55.1%降至46.6%，机会组约44.6%降至31.0%，但两组40年三品到达数均未改变。不能把容量约束有所改善误读为整条仕途已疏通；另保留K=1～20的解析台阶。
5. **上层影响不是单调的生涯成功开关。** 固定状态下W只收紧；多年间谁先获选、何时重置会改变后续候选。少数额外成功或失败不说明轻度传导本身有益或有害，更不能用稀有三品样本给微小差异排优劣。

成功者的合格后等待只统计在40年窗口内成功的子样本，不当作全体人的期望等待；死亡未达和截至终点仍未达分别报告。12种子范围是描述性范围，不是置信区间。

## 长期容量与中央特授

另作最高带的独立受控链：恒有20位候选，基础跨带比例40%，先独立退出，再普通补入，最后中央净进入。每条件100种子、400年，报告第200～399年平均；预热并不自动证明精确稳态。

K=20、无中央净进入、退出率3%时，H从24增至30，普通进入平均约从0.735增至0.903人/年。多6个容量位置，不等于每年多6个人：额外占员还要等退出再腾换。

若退出率仅1%、中央净进入均值每年0.5人，H=24与30的上述观察期普通进入均接近0。扩大缓冲不能消除持续外部净进入压过退出的风险。最高带的净进入来自其他品带，同一人物转移不创造全国新人口；这个独立链只研究最高带边界。

所有有限期结果都应满足`N_end−N_start=普通进入+中央净进入−实际退出`。近界线、供给充分时可用“退出率×占员−中央净进入”理解可持续普通吞吐，但不能把它当所有非线性随机情景的精确公式。

## 当前建议与不可识别部分

- 保留分带缓冲这一方向，20/30/50%作为可解释候选，不直接宣布为发布最优值；最高带40%与50%在若干情景中尚不能区分。
- 保留floor并显示整数S/H；ceil或最低一席若采用，应公开为小规模政策，单独评估。
- 将本地拥堵与向下压力尺度分离，带内加入独立封顶10%的上层乘子；不能用扩大h顺便抹去超额外溢。
- 若武官仍长期关闭，先看各带k、实际需求与退出/特授流，而不是继续堆h或调整抽选温度。
- 正式原生定点、需求生命周期、自然AI与长期玩家体验仍待正式接口接入后验收。本轮只修改研究与设计，不增加正式游戏行为。
