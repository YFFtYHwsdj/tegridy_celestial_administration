# 四六目标的员额与完整生涯联合研究

本组按顺序完成：头衔到员额的结构审计、累计反馈接入合成生涯/健康/占职、独立种子压力验证。当前规则与参数主文见[数学模型](../../../docs/appointment/merit_model.md)；本组不执行游戏引擎或改变正式玩法。

## 复算和源码职责

从仓库根执行`python3 tools/merit_research/run.py joint`。入口冻结本组和buffers/occupancy/controller的Python依赖，仅执行新联合研究，不重复旧长实验。结果、冻结源码及逐步日志均在仓库外，见[统一入口](../README.md)。

- capacity.py：独立竞争槽→四带K→四六目标→六个尾部目标，以及必要候选供给条件。
- mapping_audit.py：先比较统一系数、旧分带系数、上层周转储备及等总量形状对照。
- succession.py：按死亡、实际离任、调任释放等事件承接；核无人可选时记未覆盖；迁任子事件用父标识摘要，避免长链递归转义膨胀。
- study.py：固定候选先导、选择诊断、独立种子留出验证与汇总。
- 各checks.py：映射边界、事件幂等、中央例外、冻结来源与人数守恒。

不修改原四组研究的源码和已封存结果。合成资格/收入/健康来自旧代理，年度配额替换为当前反馈，前三带固定低品40%/高品60%，最高带只控合计。

## 第一阶段：员额换算

每个可独立任命/继承的竞争单元只归一个带，先算整带K，随后拆40/60，不能对一个职位的两品各记完整需求。旧516对象是有效在职需求快照，不是已经确认的独立职位J。

比较统一1.5J、2J、3J，旧分带[2.5,1.5,1.5,3]J，以及统一2J加上层周转储备。若上层目标合计U、中间带目标T、下/上品候选可用率为c_low/c_high，必要条件为：

`0.4c_low T ≥ r(0.6T+U)`；`0.6c_high T ≥ rU`。

候选比例只是离线人工供给条件。中间J=0但上层仍需补人时，可建立待阙/晋升梯队储备；这不创造中间头衔。若供应过低导致无有限储备解，明确报不适配，不自动膨胀员额或改变四六比例。J最高带为0时不偷偷新增最高带名额。

人工12种规模与结构×5映射，另做同总K的形状对照。60组映射、1034项恒等检查通过。例：J=[20,0,0,4]时，统一2J得到[40,0,0,8]，逐级通路断开；周转储备得到约[40,6.91,4.44,8]。上层偏重的武官人工结构[3,5,10,12]中，统一1.5J/2J/3J连“全部源品都能参选”的必要条件也不能满足，而周转映射满足人工25%候选条件。统一倍增K不能修复结构比例，这一点不依赖动态模拟。

必要条件通过不等于真实Merit、资格和自然退出已满足，也不等于动态收敛。当前映射实现只支持正分母（全零J除外）；它也会拒绝“分母恰为零、仅最低带有槽”的可解退化情形，不能将该拒绝解释为数学无解。本轮r=.03～.06、c=.25均在正分母范围。

## 第二阶段：联合先导

9配置×文武×2种子×80年，比较五个映射及周转/恢复敏感性；ε=.1、功绩温度=.5固定，φ=.6为用户选定起点。映射的总规模变化与结构变化分别看，不把更多后备人口自动叫更优。

逐人保留原生相邻Merit门槛、成功归一化、资格天花板、异质增长、每年最多一次普通晋升、健康代理与真实职务指针。新入仕18岁、增长均值720/年、每年文26/武8人、资格分布及逐人初态均为合成输入；不是自然游戏测量。

同一次年度先完成外部变动与任命事件，再冻结人口、功绩、资格及来源，统一算六Q后从高到低抽选，不因同轮内部晋升重算Q。普通升品只改品级，不腾出职位。

先导筛选预先采用字典序：已编码在线断言零失败（不等于所有引擎机制正确）、各路线最差四级候选核覆盖、最高带尾部误差。它是公开的工程筛选偏好，不是福利或公平的综合最优。全部配置的各品人数、缺来源、到达、Merit优势与任职结果均保留，不隐藏不利指标。数值等同的2J与周转修正要标明等同，不能宣称额外收益。

## 第三阶段：独立种子留出

先导种子为0/1，验证种子为2/3，每情景120年，不根据留出情景逐个重调r/κ。19情景包括基准、空/全低/全高初态、扩招4倍/缩招、长寿、永久岗位收缩、一次损员、外部越级压力、高层扩展、临退恢复、任职收入反馈、增长高低、零中层、小体系及温度对照。

第60年移除部分竞争槽、在任者留在原体系并转待阙；这是岗位供给收缩，不是完整模拟失地时的迁国/归属变化。损员按人物死亡释放职务；外部越级压力只搬动源→目标品级、不凭空加人。该输入不是原版中央实际任命路径。临退恢复是明确的人工状态压力，基准没有假设原版AI普遍按某年龄退休。

固定40年队列终点保留死亡在分母，另分资格允许者。入仕10～29年队列用于前冲击生涯，60～79年队列完整观察至119年，用于冲击后新人；不把前队列的少量冲击暴露冒称后队列结果。人数/岗位指标取末40年，配额不足与Merit竞争指标取20年以后全段，时间窗分别标记。Merit优势比较同一来源、同一Q下的高/低冻结Merit半组入选率，不把高收入者生涯结果当作排序公平的因果结论。成功者等待只报条件样本。

## 职位承接与不完整覆盖

本组不是“年度扫描真实空职”模型。每个死亡/离任/迁任释放生成承接事件，按事件id幂等；同一槽同一年发生新的合法事件仍可处理。正常帝级槽不会自动授二品；只有明确标记的中央示例槽在实际获任后特授，并计入人口。

文官帝级示例中的前2槽授一品、其后至第8槽授二品；武官首帝级槽授一品，其他帝级不特授。这是受控身份映射，不把四级槽数称为已测得的真实中央列表。军政仍使用局部文官评分近似。

候选核未覆盖时，持有人记为未知，不能叫原生长期无人持有。未知者未虚构加入已知人物人口，因此只能检验合成已知人口的反馈，不能声称原版全体人口已闭环。报告已识别持有率、高配条件比例以及未知者对全部槽高配比例的上下界；这项限制也约束参数推荐强度。

健康代理的精确死亡插值、老年绝对发生率、完整候选评分、引擎兜底承接、兼领与真实AI退休未复刻。所有参数推荐仅为首版试跑起点，不能替代引擎与自然长局校准。

## 补充诊断复算

完成统一入口后执行`python3 tools/merit_research/analyze_joint.py <仓库外产物根目录>`，stdout为只读JSON。它核对冻结源码封印，另报20～119年的有候选零名额年、无候选年，以及存在适品候选的同次竞争中高品获任比例。

高品占低级槽存量还包括原任者升品留职，不能全部叫竞争挤占。恢复诊断采用第60年以后第一次连续5年处于目标±20%，同时报告六尾部和最高尾部；这是公开比较线，不是游戏规则或已确认的验收标准。观察期内未达到返回None，不解释为永不恢复。

## 结果状态

先导已完成36次80年演算。按事先声明的覆盖→最高尾误差排序，统一3J居首，但这不构成最终推荐：它增加员额目标及计划后备规模，不能修复零中层结构。普通结构中统一2J与transit2的结果完全相同，未发现储备修正在不触发时凭空改善结果。

先导末40年，统一3J下帝级槽已识别持有率约文52%、武50%，最高带平均绝对相对目标误差约文79%、武73%。20～79年中四→三的需求额度未被候选供应满足的比例约文93%、武87%；该关无候选年约文56%、武83%。这是联合合成输入下的供应障碍，不能据此反推原版真实资格或收入，也不能把原生职位说成长期空缺。缺员且候选不足时，增大κ会增大未满足的需求，不保证增加实际获授。

独立留出完成76次120年演算，19情景×文武×种子2/3。连同先导共112次；31项研究检查全通过，冻结版本为joint-proxy-v2。事件标识长链修复有失败/通过回归，在线守恒断言均未失败；这些是研究代码验收，平衡目标并未因此自动通过。

留出基准末40年，最高带平均人数文8.41/目标26.4、武1.50/目标3.3。四倍扩招后相应为5.31和1.11，九品平均积压约3598和1198人；基准九品约106和143人。没有出现高品随候选数直接膨胀，但高品供应反而恶化，说明“高品不爆炸”和“过量入仕仍不缺人”不是同一结论。不能用只看最高人口上界的合格标准宣布稳健。

60～79年入仕队列的40年内三品及以上到达率，基准约文1.9%、武2.2%，四倍扩招约文0.5%、武0.2%；它包含中央例外进入，保留死亡在分母。资格允许者的基准到达率约文21.5%、武19.4%，扩招后约5.0%、2.2%。同一后队列40年内首次任职率从基准文73.8%/武61.3%降至扩招文26.3%/武18.4%。这只是合成人群，不是原版玩家生涯概率。调低/高温度没有消除最高带缺员，不能靠抽选更确定来补造候选。

基准下，高品持有伯/公级槽的已知存量比例约文52%/48%、武77%/35%。在有适品候选的成功承接事件中，高品获任比例约文58%/49%、武84%/32%。后者是本研究词典序任命假设下的竞争结果，前者还含升品留职；两者都不能直接称为升品政策造成的净机会损失。该程度明显，尚无依据认定合理可接受；真实J、兼领和完整原生评分确认前，不据此改写原版任命。

小体系允许随机零额度年：例如基准武四→三在有候选时约38.5%的年份Q=0，另约80.5%的年份本来就没有候选；分母不同，不能混在一起叫“配额锁死”。小体系仍按原26/8年入仕且沿用大体系初始人口，是显式过载压力，不代表按国土缩放后的正常小国。

基准从第60年开始，四条路线/种子轨迹都未出现连续5年六尾部同时处于目标±20%的窗口；最高尾部也未达到该窗口。多数冲击情景同样未达，不能报告统一恢复年数或声称全部恢复；个别小池偶然进入窗口也不证明此后持续稳定。完整逐年诊断保留在可复算JSON中。岗位收缩实现按全局槽id奇偶删除，因此武官唯一最高槽在该种子布局中保留、目标仍3.3；不能将该情景一概称为“四带均匀减半”。

## 统一映射对照的筛选决定

自动先导胜者是统一3J，但**不作为首版默认**：它仍有最高带长期缺员，且零中层情景缺少必要周转储备。研究没有找到同时满足回拉、不过度积压、不缺人及合理挤占的可定稿参数组。

继续保留累计尾部反馈作为主候选，并优先研究带递归周转储备的员额映射；统一2J是易解释的比较起点，不是本轮已证明的最优系数。r/κ/τ保留研究起点，ε/c固定假设不冒称已筛定。用户已选择继续按合成数据校准，J作为动态变量，不以真实槽数测量阻塞试用建议；自然数据以后再复核外部假设。诊断仍应分开统计“未达门槛”“资格封顶”“达标后落选”和升品留职；再判断要调整计划后备结构、入仕政策还是接受更低的目标达成率。不得先调高额度或改原版收入，使代理结果变绿。

所有结论受合成输入、两种子、未知持有人及不完整原生任命核限制；不构成自然长局或正式玩法验收。


## 定向合成校准与试用选择

旧分参对照源程序[calibrate_split_reference.py](../calibrate_split_reference.py)沿用冻结的联合生涯、健康、资格、功绩及任命核，只替换K映射；没有改变原版收入/资格或功绩排序。10组方案在种子4训练（文武20次80年），自动选择后用新种子5/6作8情景×文武×两种子共32次120年留出，不按留出逐组改参数。

候选包括统一3J控制、压低最高带目标、扩大中高梯队、文武最低带差异及恢复强度对照。ε固定.10，避免与k乘积的不可辨识；τ固定.50，不把温度当吞吐修复。统一3J控制与新方案使用同一合成人群。文武分开最低带基数，源于固定合成入仕26/8与头衔结构不同，不意味着游戏需要读健康或死亡概率。

先导最差四级核覆盖→六尾误差排序曾选择balanced48-fast；该分参建议已撤回，保留数据作对照。当前共享试用参数的唯一维护位置是[模型参数节](../../../docs/appointment/merit_model.md#首版确定参数)。它优先改善最差路线，不是每路线及每个目标都最好。比如训练中五四系数8比6改善文官上层覆盖，却降低该种子的武官上层覆盖；高配低职也更明显。

留出基准最高带文11.475/目标13.2、武1.4625/目标1.65；四倍入仕仍为11.3625/1.6875。帝级核已知持有率基准文87.7%、武81.3%，扩招文88.6%、武82.5%。高品未随扩招明显减少或爆炸，改善了此前统一3J对照中暴露的供应脆弱性；不同研究轮次种子不同，不能把两轮均值差当作配对因果估计。

基准60～79年队列40年内三品及以上到达文3.56%、武2.19%，首任80.9%/59.7%；扩招后三品到达1.03%/.47%，首任28.6%/19.8%。扩大入仕仍会降低个体机会及积压九品，年度晋升只搬动人口，不能抹除总量约束。

已知高配存量基准伯/公级文94.6%/65.9%、武100%/59.6%，明显高于统一3J的前述参考。此处保留当前任命排序作为研究外部世界，不能将存量全部归因普通晋升，也不能称低品职务机会已经得到保护。这是优先上层供应的明确代价。

零中层结构[J=100,0,0,5]中，最高带目标8.25，而末40年实际文约.75、武约.89；必要供给储备远非完整生涯供给的充分条件。小体系、永久岗位收缩同样未全面达到目标。不以这些失败阻塞一组明确试用数值，也不宣称所有极端输入已稳健。

旧分参对照复算：`python3 tools/merit_research/calibrate_split_reference.py --output-dir <仓库外的新目录>`。该版曾核对20训练/32留出、5440个逐年状态、唯一矩阵、四六目标、人口/职务账及源码摘要；当前校验器以共享版元数据为契约，不套用到旧版。原始结果、冻结源码与自包含配置都在仓库外；未完成的试算不计入通过。正式玩法未接入，本次没有引擎验收声明。


## 共享参数校准

文武共用所有机制参数已确定为框架约束。当前程序[calibrate_joint.py](../calibrate_joint.py)删除路线覆写分支，显式拒绝military_low；输入相同J时两路K与目标完全相同。J/n/E及实际外部流量不同仍可产生不同结果，不再拟合路线常数来抹平。

8组候选共16次80年训练（种子7），选中shared-3-8后作32次120年留出（种子8/9）。参数唯一维护在[模型页](../../../docs/appointment/merit_model.md#首版确定参数)。基准控制单位头衔入仕强度为.075，整数文32/武6；旧26/8为fixed_intake，标称四倍强度为entry4，另有长寿、岗位收缩、零中层、小体系和上层扩展。小体系明确1人/年，避免四舍五入成停招。初态、中央示例身份与随机轨迹沿原模型，仍属不同外部条件；没有宣称两路完整外部世界相同。

当前统一试用k=[3,4,8,1.5]，r=.06、κ=.60，其他共同常数未变。基准最高带均值文12.225/目标13.2、武1.5375/目标1.65；旧入仕压力为11.85/1.3375。基准后队列40年三品及以上到达约文3.0%、武2.9%，首任71.3%/74.6%。武最高尾平均绝对相对误差仍41.7%，均值接近不保证每年稳定在窄区间。
