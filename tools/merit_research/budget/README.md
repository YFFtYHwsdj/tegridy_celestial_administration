# 员额预算与晋升梯队粗筛

本组为已撤回默认地位的全国总预算对照，不代表当前逐带员额框架。它检验较低总员额预算是否足够，以及此前强制每带K≥本级头衔J的假设是否抬高了预算。高品可以竞争低级头衔，因此单带K≥J不是供给的必要条件。当前推荐值由[模型页](../../../docs/appointment/merit_model.md#首版确定参数)唯一维护；这里保存研究方法、比较理由及适用边界。

## 映射与实验

四级独立头衔J每个只计一次，总计划预算P=kΣJ；最高带K₄=J₄，无最高级头衔时为0。候选pipeline将前三带分为本地基数和共同周转池：

`R=P−J₄−β(J₁+J₂+J₃)`，`K_b=βJ_b+w_bR`，`w=[.1,m,.9−m]`。

本轮推荐m=.6。w是共同周转池的分配假设，体现中间长期封顶者需要周转空间，不是原版推导出的自然人口比例。总预算严格守恒、映射只依赖J、规模齐次；允许各带K<J，意味着接受高配低职。β=0还会使前三种头衔的细分形状不再影响结果，必须明确这一信息损失。目标T=1.1K，前三带再按φ拆品；最高带只控制三二一合计。

上一轮在每带K≥J限制下，比较k=1.25/1.5/1.75/2/2.5/3、φ=.6/.75、r=.04/.08，共24组、192次80年演算。它偏好高预算，但没有解决零中层缺员；第一带含不能由升品控制的九品流入，若以全四带贴合度排序，会机械奖励提高目标。

去掉该限制后，先比较k=1.25/1.5/2、β=0/.5、φ=.6/.75、r=.06/.15，共24组、192次80年演算；随后β=.25，比较k=1.5/1.75/2、φ=.75/.8、r=.08/.12，共12组、96次。它们显示原周转池第二带偏小、第三带偏大，故最后只比较8组：k=1.5/2、m=.6/.7、r=.08/.12，β=.25、φ=.8、κ=.6、τ=.5、ε=.1固定。两结构、两路线、训练种子32/33、80年，共64次。独立留出使用34/35、120年，筛选后不再改参数。

文武始终使用同一映射和同一参数，只允许头衔、人口、候选及外部世界输入不同。最后8组中，在公开误差档与预算偏好下选择k=1.5、m=.6、r=.08；k=2、m=.7、r=.08的平均偏差更低，但总预算高三分之一，保留为较宽预算的取舍，不称1.5为全局最优。

粗筛先数第二至第四带均值/目标落在[.65,1.5]外的数量，再将最差相对偏差按25个百分点分档，同档优先较低预算，最后比较平均偏差。这是明确的工程取舍，不称福利最优或统计置信结论。第一带仍完整报告，但不因无法用升品消灭的入仕积压而奖励增大k。

## 留出与供给上界

留出覆盖基准、零中层、薄中层、同总量形状、上层扩张、四倍入仕、长寿、领土损失、大量死亡、空局、全九品、全高品、小体系、旧固定入仕、低增长、上重、纯最高级和无最高级，共18种情景、两路线、两个种子，72次120年演算。

其中10种结构另作“全候选即授”配对，共40次120年演算：只取消名额竞争，保留真实功绩达标、成功归一化、资格、健康/死亡、每年一升及中央特授。这是固定外生收入和健康下的最快供给包络；如果连它也补不上目标，应报告输入供给不足，不能改小实际目标掩盖冲击。它不证明实际游戏耦合收入下的绝对上界。

每年核对人口守恒、Q≤E、预算及目标恒等式、零最高需求的末关额度、随机小池，以及供给包络。年度目标不随当年实际人数收缩，头衔变动才改变J。

## 独立验证结果与保留限制

最终候选完成72次政策留出及40次全候选即授，共13440个120年实验年度；加最后粗筛64次80年，共18560个年度状态。人数守恒、Q≤E、预算、拆品比例、零最高需求和逐年供给包络检查全部通过。计算检查通过不等于全部平衡目标通过。

结果按末40年、两种子合并报告，以下顺序均为文／武：

- 基准第二带均值/目标1.14／1.14，第三带.95／.99；最高带8.925/8.8、1.3125/1.1。最高带10%～90%分位为目标的.91～1.14／.91～1.82，小武池的均值不能称逐年稳定。
- 空局、全九品、全高品三种极端初态，最高带末40年均值文8.59～9.14、武1.25～1.31，与基准接近；这里只支持这三种初态，不证明所有初始状态的全局收敛。
- 四倍入仕最高带8.4125/8.8、1.2375/1.1，第二带1.02／1.01、第三带.83／.85；前五关有候选时未出现零名额年，末关仍允许随机零年。第一带实际人口达到其计划目标约33～35倍，说明冗余留在九品，绝不能宣称全体人口过剩已解决。
- 零中层最高带4.9125/5.5、4.0375/5.5；最快合格即授为13.54／13.19，因而剩余缺口仍有竞争等待因素。提高预算可改善，但不为填平这一压力组再次把k推到3。
- 领土减半后，最高带首次连续5年进入目标±25%的时间，文8／24年、武2／9年；大量死亡为文1／1年、武2／8年。这只是首次五年窗口，可能再偏离，不能叫永久恢复期限。小武池中央任命也会影响最高带，死亡当年全体人数明显下降不等于最高带必然同步下降。
- 小体系J=[3,1,1,1]、明确每年入仕1人：最高带.775/1.1、.45/1.1，零人年35%／59%。其最快供给3.12／2.62高于目标，不能把偏缺全归为资格不足。当前不通过固定加人或每年一席掩盖小数随机问题。
- 低增长最高带3.55/8.8、.4625/1.1，最快供给6.97／1.88；文路在这组即使取消竞争也达不到目标，武路还有明显竞争损失。两路不能一概归因。
- 上重J=[15,25,40,40]最高带7.26/44、5.60/44，最快供给15.34／13.97；纯最高级J=[0,0,0,5]、年入仕1人也低于目标。这些输入的资格/寿命/功绩供给确有不可达性，且政策还有额外损失。不能声称任意头衔形状皆能回到目标。
- 基准有实际竞争的人次中，Merit较高半组选择率约.167/.160、较低半组.046/.035，支持优秀者明显更有机会；这是混合竞争池的描述，不是某一人物的因果概率。高配低职仍明显：伯级已知持有人几乎全部高配，公级约90%／85%；本轮没有更改原生任命偏好，不能宣称已解决挤占。

本组曾给出低预算候选，后因改变逐带员额前提且统一二八证据不足，撤回默认建议；保留作为另一种框架的实验。它同时明确保留小池、低增长、极端结构、九品积压和高配低职限制。不是再等真实采样才能给数值，也不是将未通过的目标改成通过。

## 复算

```sh
python3 tools/merit_research/budget/checks.py
python3 tools/merit_research/budget/study.py pilot --output-dir <仓库外的新目录> --workers 6
python3 tools/merit_research/budget/study.py validation --output-dir <同一目录> --workers 6
python3 tools/merit_research/budget/study.py shadow --output-dir <同一目录> --workers 6
python3 tools/merit_research/budget/study.py check --output-dir <同一目录>
```

`study.py`拥有冻结、粗筛、留出和摘要，`budget_mapping_candidates.py`拥有独立数学映射；`checks.py`检查既有边界和随机小池报告口径。产物与冻结源码仅写仓库外，拒绝覆盖阶段结果；当前源码与冻结版本不符则拒绝复核，不重签旧结果。

本组不是引擎、自然AI、真实玩家路径或正式年度功能验收。资格分布、每槽入仕强度、收入、健康和职务竞争仍是合成外部输入；最高带小到1人左右时，要看零人年及分位数，不能仅看均值接近。升品不减少官员总人口，任何有限k都不能独自消除任意大入仕下的九品冗余。
