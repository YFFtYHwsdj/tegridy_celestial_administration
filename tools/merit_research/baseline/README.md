# 旧配额与生涯敏感性研究

本组拥有旧方案参考系数、合成输入及对照结果；不是当前发布默认。旧公式见[policy.md](policy.md)，当前函数、基线与校准见[数学模型](../../../docs/appointment/merit_model.md)。从仓库根执行`python3 tools/merit_research/run.py baseline`；产物与环境要求见[统一入口](../README.md)。

## 首轮试跑参考，而非发布默认值

以下k/p/h/压力数值及结果保留作旧方案比较，不是当前反馈方案的运行参数。两套算法先作选择，再校准；不得叠加。

为让后续实现有一个具体、可解释的起点，建议首先比较以下三组，而不提前宣称唯一最优。

- **常额优先参考**：文武均采用四带k=`[2.5,1.5,1.5,3]`，`p_within=0.60`、`p_cross=0.25`。允许历史开局高品超额自然消化，不为消除冻结反推系数。
- **机会扩展对照**：文武均k=`[3,2,2,4]`，`p_within=0.75`、`p_cross=0.40`。同时改变容量与机会，是组合情景，不能据此单独归因某一个参数。
- **武官最高带容量诊断**：保持常额优先参考，仅把武官最高带k从3改8，其他不变。用于区分上游供应不足与最高带容量不足，不是推荐将所有军事高品按开局人数保送解冻。

第一轮三组共同取统一`h=0.20`、`β=0.50`、`λ=0.25`、`ρ=0.50`、`A_max=0.50`、`η=0.20`、`g_min=0.80`、`τ=0.50`，并以`B_ℓ=τΔθ_ℓ`取权重翻倍差。

第一轮这些数值的可解释性：软常额到普通准入界线约留20%余量（小池取整可能无余量）；严重缺员时基础跨带机会最多乘1.5；最远压力逐层减半；远端合计最多扣一半，不单独完全冻结；带内本地最多收紧20%（第一轮未加入上层小幅影响）；两人一席且领先一个阶段差时，高功绩者胜率约80%。这些是数学含义，不是实测平衡证明。

首个参考组只是结构回归/采样起点。现有理想情景已经提示其军事高品及基层跨带可能很严，不应未经自然采样直接发布。若用户希望多数优秀者终至三品，需要重定目标，并联合修改容量与机会；不能仅将τ调小就许诺解决。

### 分带缓冲与轻度上层影响的新增候选

将四带缓冲率独立为`h_b`，旧方案重点比较`[0.20,0.20,0.30,0.50]`与统一20%；首项只影响九八带的本地压力，没有普通跨带进入九八带。实际S仍向下取整，最高带改50%不等于立即为所有历史高品解冻。

新增独立传导尺度`α_b=0.20`，避免放宽h时同时减轻向下压力。带内上层额外扣减上限候选`ω=0.10`，按距离衰减、叠加后封顶，与本地G相乘：本地底线0.8时最终底线0.72。不是减10个百分点，也不保证每一带每年都扣满10%。

这组h/α/ω是旧方案重点研究的候选扩展，不把第一轮的456次结果冒称其运行结果；新对照、整数容量、首次开放和长期流量统一见[缓冲参数研究](../buffers/README.md)。文武的k/p参考不因h实验随意改变，必须在固定k/p组内比较。

### 参数域与极端输入

k≥0，每带h_b>0，α_b>0，ω∈[0,1)，β≥0，λ≥0，ρ∈[0,1]，A_max∈[0,1)，p_within/p_cross∈[0,1]，g_min∈(0,1]，η∈[0,1]，τ/B>0。对照B的μ≥0，对照C的γ∈[0,1]。非法值应诊断并拒绝该配置，不能悄悄套默认数继续宣称按设定运行。

建议研究范围：k在参考值的0.75～1.5倍间比较、p_within=0.4～0.8、p_cross=0.15～0.5、h_b按七六0.1～0.3、五四0.2～0.5、三二一0.2～0.75分别比较、β=0～1、λ=0～0.5、ρ=0～0.75、τ=0.25/0.5/1。不要对所有维度一次穷举后只挑漂亮结果；先做单维与机制诊断，再比较少量组合。

K=0不跨带进入；H=K没有隐含一人储备；严重超额z饱和而不无限向下放大；q始终钳制e与V。需求先去重求和、再乘系数取整。文武可共享系数但绝不共用人口或余量；是否给予武官不同系数属于政策选择，不是纠正统计误差。

## 理想情景演算及其结论

此处第一轮研究使用逐人物整数模型，不再靠“以后每年固定e比例自动达标”推算生涯。各关按冻结来源和余额高到低结算，成功重置到目标基准；先产生年度外部死亡/入仕/增长，再进行抽选，新入仕当年不白送全年增长。理想抽选用精确实数Gumbel排序；它没有模拟原生定点、双账、回调或实际职位改变。

比较包括三档增长、三档组合政策、温度、全员高资格、文武共用系数、需求减半及A/B/C配额，并补上述三个参考情景。每场景重复12个种子、100年；同人物ID/年份/用途分别生成随机冲击，政策改变抽选次数不会改变潜在死亡或入仕禀赋。重复次数只是探索规模，种子最小/最大值是描述范围，不是置信区间。

外部输入全部是假设：所有模拟人物均为成人，文/武每年新九品26/8人、统一永久退出概率3%、入仕资格上限2/4/6/9的比例10%/50%/30%/10%、固定人物增长服从对数标准差0.5的对数正态分布，算术均值分别60/240/720年功绩；没有中央特授、暂退恢复、迁移和一次性事件。初始人数/预候选来自实测，但逐人初始M、增长及L均是人工构造；预候选再经人工L筛选，不等于真实完整E。

在第10～39年进入的队列中，比较入仕后40年内达到各品的比例。模拟截止距各人入仕至少60历年，40年终点不存在行政删失；死亡终止个人风险期，作为竞争事件计入未达到。另报资格允许者分母；成功者条件中位数只限40年内成功者，不是所有人的平均等待，不将不同随访长度的成功者混为一组。

可复核的结构发现：

- 在“常额优先参考、平均年增720”的假设场景中，文官队列40年内到八品约92%，到七品约9.8%，到五品约1.0%，到三品约0.11%；武官这批有限样本未观察到40年内三品。这个零样本不是概率严格为0，更不是游戏预测。
- 同一假设下，文官第100年的七六带均值约105、五四带约25.9，接近普通准入界线105/26，而最高带约7.8、低于软常额24。说明瓶颈可以首先出现在中层，不能看到三品少就只放大最高带。
- 仅提高武最高带系数，在该假设场景仍未产生足以支持“解决拥堵”的证据；上游门槛、资格、死亡与中带容量可能更早约束流量。温度变化也不能直接突破V或制造达标候选。
- 全员高资格、需求减半、不同增长等情景会改变未来人数、竞争与截断次数。固定同池Q时温度只改人选，但长期并不必然只改人选；中选者增长禀赋不同会反馈到后续候选与人口。

这些结果否定了“单凭开局18个预候选就认定长期候选轻量”“名额比例就等于生涯机会”等过强推论，但不足以定出发布参数。没有为追求某个三品比例而反向修改自然增长、死亡或出身分布。

### 对照政策的统计时点

情景B的μ可用真实退出量作量纲参考，但必须固定观测时点。先死亡后抽选、记录抽选后人口时，在充分候选、无拥堵且只补死亡的理想条件下μ≈δ可使该时点靠近K；μ=δ/(1−δ)对应抽选前人口在K附近。两者不能混在同一张稳态图里声称都“精确回到K”。真实退出非均匀且有特授/迁移，不直接套这个例值为默认。
